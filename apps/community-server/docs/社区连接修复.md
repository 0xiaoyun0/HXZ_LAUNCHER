# 修复 0.10.0 的社区连接

适用于从 0.9.2 升级后后台能打开、启动器却连不上社区的服务器。旧版配置中的 `HXZ_ORIGINS` 可能缺少 Windows 和 Android 客户端的来源。

## Windows

1. 在服务器上把修复包解压到「启动社区服务.bat」所在的目录。这里应已有 `.env`。如果服务已通过后台更新，仍使用当初启动服务的根目录。
2. 双击「修复社区连接.bat」。工具先在同一目录备份原来的 `.env`，然后将 `http://tauri.localhost` 和 `https://appassets.androidplatform.net` 加入已有名单。两个来源都已存在时会直接提示。
3. 选一个可以短暂中断聊天的时段，停止整个社区服务，再用原来的启动方式启动。使用 Windows 服务管理器或任务计划部署时，重启原来的服务或任务即可。
4. 双击「检查社区连接.bat」。看到 Windows 和 Android 的接口、聊天握手四项都通过后，在启动器社区页点「重新连接」。

也可把服务端根目录拖到任一批处理文件上。

## Linux 和 Docker Compose

使用 Node.js 24 或更高版本，在服务端根目录执行下列命令。第一条写配置，第二条在重启后检查运行中的服务。

```sh
node community-connection.mjs repair .
# 按原方式重启社区服务后执行
node community-connection.mjs check .
```

随包提供的 Compose 服务名是 `community`。宿主机已安装 Node.js 时，可在修复后运行 `docker compose up -d --force-recreate community` 让容器重新读取环境变量。如果服务管理器或 Compose 的 `environment` 单独设置了 `HXZ_ORIGINS`，请把两个来源也加到那里，保留已有网站。

## 核对公网和恢复配置

本机四项通过后，可以在服务器或另一台装有 Node.js 24 的机器上运行 `node community-connection.mjs check . https://qqbot.hxzmc.top`，查看公网 HTTPS 和 WebSocket 是否也通过。自建社区请换成自己的地址。检查只读取健康状态、发送接口预检和打开匿名聊天握手，无需管理员或玩家密码。

恢复时，把工具输出的 `.env.before-community-…` 备份复制回原位置并命名为 `.env`，再按原方式重启。备份含原服务配置，请和原文件一起保管。
