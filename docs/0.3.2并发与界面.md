验证：实际GameInstaller.libraries下载队列确认默认64、配置128并发均到达对应同时请求数；实际mrpack文件下载验证64/128，设置验证五档保存和非法值拒绝。类型与静态检查通过。打包Electron检查默认64、五档选项、保存128到磁盘，以及亮暗两种主题五页签计算样式一致、刷新与后退。没有重复完整游戏安装。截图在docs/screenshots/032-*.png。
