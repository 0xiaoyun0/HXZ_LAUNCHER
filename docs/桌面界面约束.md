# 桌面界面约束

适用于 0.10.0 主程序与装进同一窗口的社区插件。判断一个界面能否交付，先看玩家能否在正常窗口、最小窗口和大字号下完成原来的操作。

| 边界 | 约束 | 验收方式 |
| --- | --- | --- |
| 原生窗口 | 默认 1250 × 825，最小 780 × 540。顶栏 70 px，底栏 36 px。中间工作区使用剩余高度 | 逐页测量三者相接的位置。增大字号后，导航、角色和三个窗口按钮仍分别可点击 |
| 普通页面 | 内容居中，最大宽度 1600 px，普通窗口两侧留 18–38 px，紧凑窗口两侧留 15–22 px。标题、正文与操作都属于这个页面。长页由中间工作区纵向滚动 | 在宽屏检查左右留白。滚到页面中部和底部检查内容与按钮的边界 |
| 卡片和表单 | 一组任务一个容器，新资料的卡片默认间隔 20 px，紧凑布局默认 16 px。升级保留已保存的间距。玩家可将宽窗间距设为 8–24 px。正文内边距 17–26 px，紧凑窗口为 14–19 px。卡片根据内容定高。主操作最小高度 36 px，随字号增长。同一行的搜索框和操作按钮等高，内存输入框与保存按钮使用同一高度下限。长名称或路径换行，操作组空间不足时另起一行 | 检查实际按钮在卡片内且互不遮挡。空列表、错误和加载提示留在原来所属区域 |
| 首页 | 经典工作台的左列放角色、默认服务器和实例详情，右列放实例与日历。实例控制台把长列表放在左列，游玩手记把日历与最近游玩日期放在右列。宽窗的两列各自从上到下连续排列。工作区不超过 54 个当前字号宽度时改为单列，阅读和键盘顺序均为实例、角色、默认服务器、日历、实例详情。上次实例的启动按钮在首屏可用 | 16 px 时分界约 864 px，22 px 时约 1188 px。逐张核对位置，直接测「继续游玩」的底边是否在可视区内 |
| 设置 | 宽窗保留左侧分类栏，右侧只显示当前分类及其表单。与首页同一分界下，分类入口移至表单上方，空间不足时按行换排，表单使用完整宽度 | 用键盘切换分类并修改值。长游戏目录、大字号和保存按钮均在表单边界内 |
| 导航 | 图标始终标识入口，空间不足时收起文字，图标有可访问名称。窗口按钮保有独立操作区域。主导航与快捷导航合计只高亮当前归属的一个入口 | 同时启用社区、协会、LINKING 和音乐后，逐个宽度检查 |
| 阅读、聊天与弹窗 | LINKING 正文使用导航下方的剩余高度。聊天记录和档案可独立纵向滚动。弹窗在窗口内至少留 16 px 边距，过长正文在弹窗内滚动 | 测档案正文占工作区至少 55%，打开周榜与实例管理弹窗，检查关闭及主要操作 |

尺寸使用 WebView2 的逻辑像素。安装器、网页及移动端有各自的窗口条件。未加载社区插件时，游戏、默认服务器、联机大厅、播放器和设置仍可分别进入。

## 文字与边框

留白从边框内缘量到实际显示的文字行。左右、上下分别验收，任意一边都需要达标。卡片之间的可调间距单独计算。

| 带边界的内容 | 左右下限 | 上下下限 | 适用场景 |
| --- | --- | --- | --- |
| 正文卡片、设置分区、日历工具栏 | 14 px | 10 px | 标题、正文、开关说明、多行文字和按日期展开的记录 |
| 文字按钮、导航和分段选项 | 8 px | 4 px | 标签与图标并排时也检查文字，长操作名可换行 |
| 设置行、卡片标题与操作栏的横向分隔线 | 由所在卡片提供 | 距可见分隔线 6 px | 只测绘有分隔线的一侧 |
| 输入框的编辑区 | 10 px | 4 px | 原生输入框、选择器以及由外层绘制边框的实例搜索框 |
| 有边框的错误、空状态提示 | 10 px | 6 px | 检查恢复操作出现后和错误详情展开后的布局 |
| 弹窗 | 16 px | 12 px | 滚动到开头和结尾都检查可见文字。实例配置与卡片整理共用独立的底部操作区，保存和完成按钮始终完整可见 |

设置卡片自身提供左右留白。带整行分隔线的标题、表单行可以延伸至边框，但文字仍与正文对齐。新增正文、提示或开关直接放入分区即可继承边界。纯图标按钮沿用各自的点击区域。样式与回归检查分别维护，测试用实际换行后的文字矩形和输入区计算距离，失败时给出入口、方向、实测值和下限。[共用内边距](../apps/desktop/src/launcher/insets.css) · [文字边界检查](../scripts/desktop-insets.mjs)

设置页的独立任务使用同级卡片，相邻卡片至少相距 16 px。下载策略与启动器版本分别成组，更新公告和帮助入口与版本说明放在一起。社区服务地址与 HXZRE 各自成组。字段标签和输入框至少相距 8 px，同一行的输入框与按钮上下对齐，操作之间默认留 10 px。宽度不足时，按钮组换行。回归检查也会从这两个链接进入目标页，并实际编辑、保存、还原隔离资料里的服务地址。

## 材质与卡片编辑

| 玩家操作 | 约束 |
| --- | --- |
| 更换外观 | 工作台决定卡片位置，窗格方案保存明暗、强调色、卡面底色、圆角和不透明度。新资料默认使用经典工作台、小镇微光窗格和纯色背景。三个选择分别保存。 |
| 选择壁纸 | 可选纯色、项目原图、本地图片或静音循环视频。布局切换、材质还原和重启均保留壁纸。取消选取保留原设置。文件损坏时显示底色，设置提供重试和重选。 |
| 选择模块 | 在「工作台」开关焦点、焦点卡封面、快捷入口、顶栏快捷导航和底栏音乐控制。「整理布局」允许从选择列表移出或重新添加某套布局，保留其卡片排布。 |
| 调整材质 | 卡片圆角 4–20 px，不透明度 20–100%。卡片、按钮和弹窗分别设边界。系统启用减少透明度时使用实底表面。自选颜色按卡面明暗调整字色。 |
| 游戏库与音乐 | 游戏库可随工作台使用卡片或紧凑列表，也可单独指定视图。实例控制台在宽窗音乐页并列显示播放控制与曲库。玩家保存的音乐卡片尺寸优先。 |
| 表单与工具栏 | 短选项平铺，选中态与键盘焦点可见。字号、动画速度和下载限速显示滑杆与实际值。账号、版本和存档等长名单用选择器。卡片编辑器仅展开当前卡片的尺寸与移动操作。 |
| 整理卡片 | 页面右上角「卡片」或卡片标题的「…」打开编辑器。可用指针或按钮改顺序、宽度和高度。锁定后先解锁才能移动或隐藏。固定高度的长内容在卡内滚动。 |
| 窄窗与恢复 | 每套首页都分别保存宽窗和窄窗布局。经典工作台沿用原有存储位置。窄窗卡片独占一行，拖动宽度不会挤压正文。显隐与顺序由玩家决定，即使所有卡片都隐藏，选择卡片和恢复默认仍可用。 |
| 接回旧设置 | 首页沿用 0.9.2 的五个卡片 ID。旧布局可在设置中单独预览、合并和撤销。玩家可以分别接回旧版窗格或壁纸。缺失的源文件会给出说明，保留当前壁纸。 |

外观借鉴了 Windows 对面板和控件的圆角分级，以及应用内亚克力材质的使用方式。透明效果绘制在启动器壁纸之上。[Windows 几何规范](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry) · [Acrylic 材质](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)

源码中，窗口、页面与组件的尺寸由共用桌面样式提供。自动检查通过原生启动器打开各入口，用实际控件坐标判定结果。页面截图另用于判断文字层次、空白和操作次序。[桌面共用样式](../apps/desktop/src/launcher/workspace-layout.css) · [桌面布局检查](../scripts/desktop-layout.mjs)

2026 年 11 月 20 日在本机 Windows WebView2 复验。x64 检查 39 个页面入口与状态、6 组窗口与字号及 18 次弹窗边界，宽度从 780 至 1920 px。x64 和 ia32 分别用隔离的测试账号、328 个实例条目和 Java 17 测试程序走过启动与停止。本机 0.9.2 资料另行验证，识别 56 个实例条目、53 个已安装实例和 11 天游玩记录，切换界面、接回旧视频和导入卡片前后，受检查的源文件哈希一致。
