# 桌面界面约束

适用于 0.10.0 主程序与装进同一窗口的社区插件。判断一个界面能否交付，先看玩家能否在正常窗口、最小窗口和大字号下完成原来的操作。

| 边界 | 约束 | 验收方式 |
| --- | --- | --- |
| 原生窗口 | 默认 1250 × 825，最小 780 × 540。顶栏 70 px，底栏 36 px。中间工作区使用剩余高度 | 逐页测量三者相接的位置。增大字号后，导航、角色和三个窗口按钮仍分别可点击 |
| 普通页面 | 内容居中，最大宽度 1600 px，两侧内边距 16–30 px。标题、正文与操作都属于这个页面。长页由中间工作区纵向滚动 | 在宽屏检查左右留白。滚到页面中部和底部检查内容与按钮的边界 |
| 卡片和表单 | 一组任务一个容器，卡片默认间隔 14 px，紧凑布局默认 10 px。玩家可将宽窗间距设为 8–24 px。正文内边距 14–20 px，卡片根据内容定高。主操作最小高度 34 px，随字号增长。同一行的搜索框和操作按钮等高，内存输入框与保存按钮使用同一高度下限。长名称或路径换行，操作组空间不足时另起一行 | 检查实际按钮在卡片内且互不遮挡。空列表、错误和加载提示留在原来所属区域 |
| 首页 | 宽窗使用两列，左侧角色、默认服务器和实例详情，右侧实例与日历。工作区不超过 54 个当前字号宽度时改为单列，阅读和键盘顺序均为实例、角色、默认服务器、日历、实例详情。上次实例的启动按钮在首屏可用 | 16 px 时分界约 864 px，22 px 时约 1188 px。逐张核对位置，直接测「继续游玩」的底边是否在可视区内 |
| 设置 | 宽窗保留左侧分类栏，右侧只显示当前分类及其表单。与首页同一分界下，分类切换占一行，表单获得完整宽度 | 用键盘切换分类并修改值。长游戏目录、大字号和保存按钮均在表单边界内 |
| 导航 | 图标始终标识入口，空间不足时收起文字，图标有可访问名称。窗口按钮保有独立操作区域。主导航与快捷导航合计只高亮当前归属的一个入口 | 同时启用社区、协会、LINKING 和音乐后，逐个宽度检查 |
| 阅读、聊天与弹窗 | LINKING 正文使用导航下方的剩余高度。聊天记录和档案可独立纵向滚动。弹窗在窗口内至少留 16 px 边距，过长正文在弹窗内滚动 | 测档案正文占工作区至少 55%，打开周榜与实例管理弹窗，检查关闭及主要操作 |

尺寸使用 WebView2 的逻辑像素。安装器、网页及移动端有各自的窗口条件。未加载社区插件时，游戏、默认服务器、联机大厅、播放器和设置仍可分别进入。

## 材质与卡片编辑

| 玩家操作 | 约束 |
| --- | --- |
| 更换外观 | 默认使用小镇微光。三种内置方案各自保存明暗、强调色、卡片底色、圆角、不透明度和壁纸。字号、卡片间距与排列属于工作台，可跨主题使用。 |
| 调整材质 | 卡片圆角 4–20 px，不透明度 20–100%。卡片、按钮和弹窗分别设边界。系统启用减少透明度时使用实底表面。自选颜色按卡面明暗调整字色。 |
| 整理卡片 | 页面右上角「卡片」或卡片标题的「…」打开编辑器。可用指针或按钮改顺序、宽度和高度。锁定后先解锁才能移动或隐藏。固定高度的长内容在卡内滚动。 |
| 窄窗与恢复 | 宽窗和窄窗分别保存。窄窗卡片独占一行，拖动宽度不会挤压正文。显隐与顺序由玩家决定，即使所有卡片都隐藏，选择卡片和恢复默认仍可用。 |
| 接回旧设置 | 首页沿用 0.9.2 的五个卡片 ID。旧布局可在设置中单独预览、合并和撤销。旧动态壁纸由玩家确认后存入自己的本机方案。 |

外观借鉴了 Windows 对面板和控件的圆角分级，以及应用内亚克力材质的使用方式。透明效果绘制在启动器壁纸之上。[Windows 几何规范](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry) · [Acrylic 材质](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)

源码中，窗口、页面与组件的尺寸由共用桌面样式提供。自动检查通过原生启动器打开各入口，用实际控件坐标判定结果。页面截图另用于判断文字层次、空白和操作次序。[桌面共用样式](../apps/desktop/src/launcher/workspace-layout.css) · [桌面布局检查](../scripts/desktop-layout.mjs)
