# 幻想镇官网社区接口 v1（0.5.1）

社区服务端升级至 0.5.1 后启用。基础地址为管理员部署的社区 HTTPS 域名；以下路径均相对于该地址。官网只需调用公开接口，不应保存管理员密码、皮肤站密码或发布令牌。

## 接入与限制

将官网的完整 Origin（协议、域名、非默认端口）追加到服务端 `.env` 的 `HXZ_ORIGINS`，逗号分隔，保留已有客户端来源。例如 `HXZ_ORIGINS=null,file://,https://www.example.com`，重启服务生效。Origin 不含路径或末尾斜杠。不启用带凭据的通配 CORS。也可由官网自己的后端代理这些公开查询。

公开接口全部为 GET，不需要 Authorization。JSON 使用 UTF-8，时间为 Unix 毫秒，积分是十进制字符串，前端不能转换为浮点数进行记账。展示文本必须按纯文本渲染，不能直接插入 innerHTML。最多每个来源 IP 每分钟 240 个 HTTP 请求；反向代理应按现有部署说明配置可信代理，不能随意相信客户端转发头。

列表默认 `offset=0&limit=20`，limit 范围 1–50，offset 0–1000000。响应为 `{items,total,offset,limit}`，最后一页由 `offset+items.length>=total` 判断。榜单独立遵守下面的分页规则。公开响应允许缓存 15 秒，建议官网每 30–60 秒刷新。接口无效返回404，不支持的方法返回405，来源拒绝403，参数错误400，超限429。错误体统一 `{error:"说明"}`。

## 公开内容

| 路径 | 参数 | 内容 |
| --- | --- | --- |
| `/api/public/v1/overview` | 无 | apiVersion、九款游戏的 id/name/tag、公开帖子和已审核蓝图数量、公开资源链接 |
| `/api/public/v1/notices` | group 可选 survival / mod-1 / mod-2；分页 | id、groupId、title、body、author、updated；不混合替换不同服的分组标识 |
| `/api/public/v1/forum` | q ≤100字符；sort=newest/oldest/likes/replies/active；分页 | id、name、title、正文前180字符、category、created、updated、pinned、likes、replies；置顶优先 |
| `/api/public/v1/forum/{id}` | 回复分页 | `{post,replies:{items,total,offset,limit}}`；正文、公开回复及 parentId，不公开隐藏帖和隐藏回复 |
| `/api/public/v1/blueprints` | mc 精确游戏版本；分页 | 仅审核通过的蓝图；id/name/title/description/category/mc/loader/create_version/dependencies/cover/size/sha256/downloads/created/updated |
| `/api/public/v1/shop` | 无 | settings:{enabled,starts,ends}、open、serverTime、items；商品id/title/description/price/stock/starts/ends/available |
| `/api/public/v1/leaderboard` | game 可选游戏ID；period=week/all | 该游戏周榜或长期榜前十；name/score/updated/rank（按游戏榜响应）、label，不包含账户余额或用户私密资料 |
| `/api/public/v1/leaderboard` | 不传game；period=annual；year可选；分页 | 年度总积分榜 items:{name,points,rank}、year、total、offset、limit |
| `/api/public/v1/leaderboard` | 不传game；其他period或省略 | 当周积分榜前十 items:{name,points,rank}、week、label；当前未结算游戏奖励为预估 |

九款游戏 ID：runner、blocks、breakout、gomoku、xiangqi、chess、danmaku、maze、fighter。周榜北京时间周一切换；年度总榜由已结算周榜与周榜奖励汇总。商城消费只扣余额，退款也不会制造新的榜单积分。

商城 `stock=-1` 表示不限量，0售罄；starts/ends为0表示不限。时间窗为开始时刻包含、结束时刻不包含。available只是展示状态，最终交易仍由服务端在事务内重新检查。

蓝图文件可 GET `/api/blueprints/{id}/file`（公开审核通过的内容），验证文件长度及 sha256 后使用；官网不应拼接本地游戏路径或请求服务器上的任意文件。

```js
const response = await fetch(COMMUNITY_BASE + '/api/public/v1/forum?sort=likes&limit=12');
const data = await response.json();
if (!response.ok) throw new Error(data.error || '社区暂不可用');
// data.items 是公开的帖子摘要；组件以文本显示 title/body。
```

## 登录后的商城（可选）

官网首期可仅展示内容，引导用户在启动器或幻想镇社区 Android 内操作。若接入写操作，需独立实现既有皮肤站登录及社区会话流程，使用社区签发的 Bearer token；公开 API 不签发登录令牌，不可使用管理员令牌代替玩家。

- GET `/api/points?offset=0`：当前玩家 balance、最近30笔 ledger（id/amount/reason/created）、total/offset。
- POST `/api/points/redeem`，`{code}`：兑换一次性积分码。
- GET `/api/shop`：登录后的商城目录；GET `/api/shop/orders?offset=0`：本人订单，每页30条。
- POST `/api/shop/buy`，`{item,price,requestId}`：item为商品ID，price必须是展示时的价格字符串，requestId为客户端生成的16–80字符唯一操作标识（推荐UUID）。**网络重试必须复用相同requestId**，新一次购买才生成新的ID；每次兑换一件。响应 `{order,wallet}`。余额、库存、订单同时事务提交。价格变化、缺货、关闭或余额不足返回错误，不扣款。
- 订单字段：id/title/price/status/delivery/created/updated。status为pending、fulfilled、refunded。delivery仅管理员和购买者可见。

## 管理员接口（官网通常不需要）

以下必须使用社区管理员身份，支持既有后台会话；普通玩家拒绝。推荐通过服务端自带 `/admin/` 页面操作。

- GET `/api/admin/shop`，POST `/api/admin/shop/settings` `{enabled:boolean,starts:number,ends:number}`。
- POST `/api/admin/shop/items` `{id?,updated?,title,description,price,stock,enabled,starts,ends}`。编辑既有商品必须传读取时的updated；若库存或商品已变化则拒绝保存，需刷新。最多300件未删除商品，price是非负整数字符串。
- DELETE `/api/admin/shop/items/{id}`：软删除，不删除历史订单。
- GET `/api/admin/shop/orders?offset=0`：全部订单，每页30条。
- POST `/api/admin/shop/orders/{id}` `{status:"fulfilled"|"refunded",delivery}`：交付必须填写说明；退款幂等地退积分并恢复一件库存；已退款不可再交付。

升级必须保留服务端 data、.env，停服后备份整个 data（SQLite及WAL文件）。0.5.1只新增商城表和接口，不重建或清空排行榜、积分、账号和已有社区数据。未提供跨站共享皮肤站 Cookie 的接口。
