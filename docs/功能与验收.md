## 数据行为

- 内存按实例手动、实例自动或跟随全局的选择计算。生成命令时统一 JVM 最大堆，兼容旧实例留存的堆参数。堆受 Java 架构与物理内存约束。启动日志记录实际传给 Java 的 MB。
- 皮肤站角色验证、社区会话交换与在线连接分别处理。同一账号与服务的并发会话交换共用一次请求。临时网络故障保留本机身份。账号页可检测连接，输错密码会在输入框附近显示结果。
- 本机游戏时长从 Java 成功启动开始，到退出或主动停止结束。并行实例计时间并集，跨北京时间午夜拆分，运行中读取包含本次时长，日历展示近一年，累计值保留更早记录。运行中每 5 秒写入检查点，异常断电后的缺失尾段停在最后一次成功写盘处。
- 迁移可读取旧本机日历和已结束的启动历史。重试可重用导入数据，完整历史可补足一些日历缺口。仅有按日汇总的旧资料缺少精确起止时刻，同一天的重叠记录采用可证实的较大值。没有旧记录的时间无法还原。社区排行榜使用游戏服桥核验的数据。
- 首页只读本地资料。音乐、档案与协会在进入对应页面时加载。LINKING 的字体、音频和场景随社区插件提供，在线活动进度通过社区服务保存。

## 功能取舍与错误提示

本机桌面和开始菜单快捷方式均指向 `E:\HXZL\幻想镇启动器.exe`，其程序文件版本为 0.9.2.0。界面对照取自该安装目录的界面资源，使用独立测试资料。桌面回归测量两栏间距、实例行与卡片底部的位置，以及窄窗口中顶栏图标、角色名称和窗口控件的间距。交付目录的“预览”保存安装版对照和 0.10.0 实际窗口截图。

以本机正常安装的 0.9.2 为桌面参照。顶部保留图标导航与独立窗口控件，首页左栏展示角色、服务器状态和选中实例详情，右栏提供带搜索、导入、下载与启动按钮的实例列表，以及半年或一年的本机游玩日历。设置用独立分类栏切换游戏与 Java、外观、下载、资料迁移和扩展。积分商城收在可选社区插件里。卡片布局编辑器可直接从首页、音乐、联机、安装游戏和协会等页面进入。小游戏集合继续暂缓。联机大厅承担游戏房间与邀请，社区插件承担玩家交流、委托和剧情档案。核心界面启动时读取本地状态，下载社区包由玩家发起。

皮肤站故障保留现有角色。校验失败的扩展包无法启用。Java 版本、堆分配、缺少启动文件和网络故障分别指向可执行的恢复操作。管理员与 AI 摘要通过固定字段构建，玩家自行复制。任务技术日志默认折叠。

窗口尺寸、卡片边界和窄窗阅读顺序遵循[桌面界面约束](./桌面界面约束.md)。逐页布局、实际默认服与 0.9.2 资料的复核见本轮记录。[桌面回归与功能补齐](./0.10.0桌面回归与功能补齐.md)

## 外观与卡片的桌面验收

Windows 11 专业版 x64、i5-12450H 和本机 WebView2。真实游戏库的验收在隔离的启动器资料目录运行，读取 56 个条目，其中 53 个已安装。通过页面操作切换三种方案、命名副本、调整圆角与颜色、重载，拖动和缩放首页卡片，将角色卡移往音乐页并移回。新增的便利贴经过保存再离开，窄窗有自己的卡片顺序。

本机 0.9.2 有 10 组卡片布局和一张 MP4 壁纸。检查从旧资料预览、取消、合并再撤销布局，恢复壁纸的 20 px 圆角和 60% 卡面不透明度，并验证减少动效时视频暂停。对照旧配置、历史、服务器元数据及旧壁纸的文件指纹。重复导入和缺少壁纸的分支使用临时样本。

36 个桌面入口使用 6 组窗口、字号和外观运行，共 216 组页内测量和 12 组弹窗测量。其中包括 780 × 540、22 px 字号、三套材质和社区插件加载后的工作区。x64 与 ia32 的登录、游戏启动和插件回归均在这台 x64 Windows 上运行，使用隔离测试账号、Java 17 测试程序和本地服务样本。[外观及卡片操作检查](../scripts/desktop-customization.mjs) · [本机资料检查](../scripts/check-installed-library.mjs) · [页面边界检查](../scripts/desktop-layout.mjs)
