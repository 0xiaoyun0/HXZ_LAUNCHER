# 幻想镇 Android 0.10.1

大多数手机请下载 [ARM64 安装包](https://github.com/0xiaoyun0/HXZ_LAUNCHER/releases/download/v0.10.1/HXZ-FCL-0.10.1-arm64-v8a-release.apk)。使用 x86_64 系统的平板或模拟器请下载 [x86_64 安装包](https://github.com/0xiaoyun0/HXZ_LAUNCHER/releases/download/v0.10.1/HXZ-FCL-0.10.1-x86_64-release.apk)。

**从 0.10.0 正式版升级**时，直接打开下载的 APK，在 Android 安装界面点「更新」。保留原应用就能沿用本机资料。旧版在游戏内核页面检查新版，社区首页可能没有提示。独立测试版使用另一个应用标识，测试版里的资料属于那个应用。

- 打开社区后，聊天、社区、游戏、LINKING 和我的都有自己的入口。默认使用纯色界面，头图、背景和封面由你自己选择。
- 「我的 → 手机工具」可以添加桌面小组件，或启用语音悬浮控件。加入语音房后，切到游戏里也能看到说话人、开关麦克风。
- 聊天输入框会跟随系统键盘，横屏、平板和放大字体也有各自合适的布局。
- 从这个版本起，打开社区会自动检查更新。在非计费网络上默认预下载，准备好后由你确认安装。「我的 → 应用更新」可以手动检查或关闭自动下载。

Windows 玩家和社区服主请使用 [0.10.0 桌面版、扩展与服务端](https://github.com/0xiaoyun0/HXZ_LAUNCHER/releases/tag/v0.10.0)。
