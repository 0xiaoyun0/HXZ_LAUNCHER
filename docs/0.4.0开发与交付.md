# 0.4.0 开发与交付

0.4.0 包含机械动力蓝图库、后台任命审核员、幻想镇论坛，以及聊天位置、输入焦点和语音功能修复。新增导航依次位于“下载与安装”与“聊天大厅”之间、“聊天大厅”与“通知公告”之间；删除左上角前进后退按钮。深浅主题、全局字号和布局设置继续适用。

## 使用

蓝图库支持结构NBT、可选封面、作品说明、分类、游戏与机械动力版本、加载器和依赖。上传后为待审，仅作者与审核人员可见；批准才公开。最大8MB，解压最大32MB，解析有深度、节点和数组上限。审核员在后台用户管理中任命/撤销，权限即时生效，不能审核自己的作品；管理员可处理全部作品。审核流程和升级步骤见 [部署与接入](部署与接入.md)。

论坛支持玩家发帖、回复、点赞与搜索。后台管理可置顶、锁帖、隐藏、删除帖子及管理回复。身份由社区认证决定，正文纯文本展示，点赞幂等。

聊天离开前保存阅读位置、草稿和麦克风选择，返回时恢复；在底部时跟随新消息，阅读历史时保留位置。发送后继续聚焦输入框。实际旧版复现中返回页面距最新消息8660px、发送后焦点丢失，修复后返回底部间距0且输入框保留焦点。

## 语音

使用浏览器原生Opus，48kHz单声道、24kbps、20ms帧，经现有社区 `/ws` 双向转发。服务端注入可信连接ID，仅向同房间用户转发；房间上限20人，鼠标悬停显示成员。客户端AudioWorklet采集和混音，队列、帧大小、编码/解码任务、发送速率与缓冲均有限制；慢连接丢弃过时音频。退出或断线释放音频设备与编解码器。无需另配TURN、STUN或语音端口。

实际桌面检查发现并修复了打包内联worklet不能加载、切换页面后设备选择消失、大字号下麦克风区域与在线用户重叠的问题。选项、提示分行并增加间距，侧栏可滚动。

## 验证与发布

类型与静态检查通过。最终安装包再次通过桌面检查；独立服务端包健康检查、网页后台和新接口正常，两个ZIP不含运行数据、账号或密钥，发布元数据签名有效；桌面原生保存蓝图、SHA256校验与取消通过。四项服务端针对性检查覆盖权限、上传格式、待审隔离、审核员撤销、论坛管理和20人房间转发限制。真实两个Electron窗口验证Opus双向解码且音频能量非零、静音、关闭收听、离开释放、页面切换继续语音；使用隔离测试身份和模拟麦克风，没有访问玩家麦克风或生产账号。
