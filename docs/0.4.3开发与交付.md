# 0.4.3 开发与交付

当前工作树：release/test/work/v043，分支 release-0.4.3。基线 aac2866（Windows 0.4.2 与 Android 40204）。三端同步 0.4.3，Android 内部版本 40301。用户要求少量针对性功能验证，界面由用户验收；不部署公网服务，不改真实玩家数据。

本轮范围：头图拖动与位置保存；原生 Linking 活动栏和无方向键入口；手机/电脑/双端在线；下载连接复用与故障源退避；内嵌皮肤站账号管理；详细任务日志与崩溃排查；Windows 7 SP1 32 位独立运行时；Android 精简动效和固定导航；三端自动更新稳定性。

Windows 64 位沿用 Electron 44；32 位使用 Electron 22.3.27（最后支持 Windows 7 的主版本），独立安装包、签名 latest-ia32.json 更新通道。不能将本机 Win11 32位进程冒充真实 Win7 验证。现代 Minecraft 是否支持该系统还取决于对应 Java 和游戏版本。

活动：设置标题连续点击七次，或原方向键序列 / W W S S A D A D B A。首次进入后出现设置开关和可选左栏 Linking。进度继续使用现有服务 API。移动端仍使用版本行七次点按。

皮肤站：隔离持久化网站会话，不保存密码；登录启动器时尝试同步网站登录。旧账号没有网站会话或网站要求验证码时，在内嵌页面完成一次验证，不能把 Yggdrasil 令牌当成网站 Cookie。

## 交付位置与部署

正式交付目录：E:/hxz_la/release/0.4.3。client 为 Windows x64；client-ia32 为 Windows 7 SP1 / 32位兼容版；android 为签名APK；server 为独立社区服务端。完整源码以同版本 source.zip 交付。TEST 中的开发工作树不是玩家安装入口。

管理员需要独立更新社区服务器，双端在线标识需要0.4.3服务端。升级前停服，备份并保留 data 和 .env；替换程序文件后启动。没有自动修改公网部署。

安装版沿用同一 appId 和用户数据位置；便携版保留 profile。Android40301沿用40204证书，最低Android10/API29。系统安装授权与确认仍由用户完成。

## 构建

现代桌面：client 安装锁文件依赖和 src-electron 依赖后，执行 npm run build:desktop。

32位版：先完成现代桌面的编译，在 client/tools/legacy 执行 npm ci，再在 client 执行 npm run build:legacy。独立下载并核对 Electron22.3.27 ia32 的固定SHA256，不替换现代运行时；将主进程打包为Node16兼容CJS，并补齐fetch、AbortSignal和下载流兼容。渲染目标Chrome108。游戏Java须匹配系统；32位版将游戏最大堆限制1280MB，不承诺现代游戏在Win7运行。

发布整理：HXZ_RELEASE_DIR 指向新的空交付目录，运行 scripts/package-release.mjs。生成x64的latest.json/latest.yml和ia32的latest-ia32.json，使用已有Ed25519发布密钥。安卓按 mobile/README.md 生成签名 android-latest.json；每个最新正式Release必须同时包含三个平台更新清单，先上传安装包，再上传清单。
