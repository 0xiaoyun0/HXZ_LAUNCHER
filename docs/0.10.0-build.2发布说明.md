# 幻想镇 Android 0.10.0 · 构建 2

大多数手机和平板请下载 [ARM64 安装包](https://github.com/0xiaoyun0/HXZ_LAUNCHER/releases/download/v0.10.0-build.2/HXZ-FCL-0.10.0-build.2-arm64-v8a-release.apk)。使用 x86_64 安卓系统的设备或模拟器请下载 [x86_64 安装包](https://github.com/0xiaoyun0/HXZ_LAUNCHER/releases/download/v0.10.0-build.2/HXZ-FCL-0.10.0-build.2-x86_64-release.apk)。

**已经装过幻想镇？** 如果手机里是初版 0.10.0，或此前标为 0.10.1 的安装包，请直接打开上面的 APK，在系统界面点「更新」。保留原应用就能沿用设置和存档。这两个旧包需要手动更新这一次。

- 进入社区后，可以从公告或服务器卡片进服。界面默认使用纯色，背景和头图由你自己选择。
- 「我的 → 手机工具」可以添加桌面小组件，也可以开启游戏里的语音悬浮控件。
- 「我的 → 应用更新」显示当前构建号。今后同一个版本也能收到新构建，默认在非计费网络下载，安装由你确认。

Windows 玩家和社区服主请使用 [0.10.0 桌面版、扩展与服务端](https://github.com/0xiaoyun0/HXZ_LAUNCHER/releases/tag/v0.10.0)。
