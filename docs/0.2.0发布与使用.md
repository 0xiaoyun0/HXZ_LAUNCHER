# 0.2.0 发布与使用

旧的 release/0.1.0 保留，新包分别在 release/0.2.0/client 与 release/0.2.0/server。玩家只需要客户端，管理员额外部署独立服务端。客户端包不包含服务端代码、数据库或启动入口。

## 游戏与整合包

“下载与安装”获取真实 Minecraft 和加载器版本目录。选择版本和实例名后安装游戏本体、资源、依赖，并执行 Forge/NeoForge 安装器声明的客户端处理步骤。安装过程中可以取消，失败后同名重试会校验已有缓存；同名既有实例不会被覆盖，未完成安装不能启动。

拖入一个 mrpack，或者点击导入按钮。确认实例名称与可选文件后安装。也支持 Modrinth 搜索、选择包版本、下载后导入。下载文件校验 SHA-1、SHA-512 和大小，路径不能越界或通过链接写入；client-overrides 在 overrides 之后应用，服务端专用文件跳过。

本次用户文件 E:/QQDOWNLOAD/hxzv3.mrpack：Minecraft 1.21.1、NeoForge 21.1.250，含 updater/config.json、旧版 updater-1.0.2.jar 与 launcher-agent.jar，下载清单为空。导入后去重 servers 并启用 HXZ UP，提供兼容的随包 HXZ UP 1.0.3。首次启动前仍需按 HXZ UP 发布内容下载实际模组；导入完成不等于已经取得远端全部游戏文件。

下载默认使用 BMCLAPI 与 MCIM，失败回退官方。没有验证存在等价镜像的文件继续使用原地址。可在设置中切换官方来源。游戏安装组件流式下载和校验，资源并发有界，处理器子进程限制堆内存；不会把整个整合包读入内存。

本次修复重复 Maven 依赖与重复实际文件路径，解决 Gson Duplicate key；修复 Forge install_profile.json 的 path:null 读取异常。0xC0000005 属于另一个 Java/本机库异常：本机 Oracle Java 21.0.4 在早期窗口阶段退出，改用已安装的 Zulu Java 21.0.3 后成功渲染。遇到该退出码可在设置中选择其他匹配版本的 Java，没有据此判断所有 Oracle Java 都不可用。

## 个性化

整体字号 13–22 px，深色/浅色，主题色、背景底色、本地背景图和背景可见度，标准/紧凑/宽松间距。点“应用外观”保存；“恢复默认外观”可重置。底部启动按钮和导航在大字号下仍可操作，内容区域可滚动。

## 独立社区后台

1. 解压服务端 ZIP，运行“启动社区服务.bat”，无需安装客户端，包中自带独立 Node.js。
2. 默认访问 http://127.0.0.1:8787/admin/ 。账号 admin，随机初始密码位于服务端 data/初始管理员密码.txt；修改密码后删除该初始文件。
3. “通知公告”管理三个公告分组；“聊天记录”删除消息；“用户管理”封禁/解封；“服务配置”设置公告管理员角色 UUID 与 TURN。
4. 客户端仅配置服务地址，不提供启动/停止服务端的按钮。社区未启动不影响本地游戏安装与启动。
5. 默认只监听本机。给其他玩家使用时部署 HTTPS 代理并配置 HXZ_ORIGINS 与 TURN。每位玩家的 127.0.0.1 都指向自己的电脑；公网语音不能只开放网页端口。
6. 升级服务端时先停止旧服务，保留自己的 data 和 .env，再替换程序文件，不覆盖配置数据。

## 启动器自更新

使用 electron-updater 与 NSIS 安装程序。发布整理脚本在 client 目录生成 latest.yml，记录安装程序名称、SHA-512 和大小。管理员将安装程序及 blockmap 上传到自己的 HTTPS 静态目录，最后上传 latest.yml；客户端设置填写该目录地址，不能填管理后台或 latest.yml 文件地址。

配置后默认启动时检查，发现新版可下载并点击“重启并安装”；游戏或安装任务尚未结束时禁止重启。此机制只更新启动器，与 HXZ UP 游戏文件更新和社区服务端升级无关。

目前没有指定正式启动器更新站，也没有签发 Windows 代码签名证书。未上传发布目录，未在用户电脑上执行跨版本覆盖升级。便携版推荐手动替换程序文件并保留 profile；便携用户使用内置安装程序会进入安装向导，不承诺原地更新便携目录。
