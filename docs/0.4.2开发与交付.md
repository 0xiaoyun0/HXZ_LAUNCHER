## 与原始需求对应

- 语音进出提示：补齐服务端 voice-event，向所在频道成员及操作本人发送进出事件；切换频道和断线离开也处理。沿用社区 WebSocket，无新增端口。
- 按键说话：默认 T、可改键、全程说话可选。避免在文本输入和改键过程中触发，松键、窗口失焦、变更设置时清除说话状态。按键监听作用于启动器窗口；不声称已经提供游戏处于前台时的系统级全局按键捕获。
- 导入：修复 loaders 未定义导致的崩溃；支持 Modrinth mrpack、CurseForge manifest、Prism/MultiMC 导出及普通 Minecraft ZIP。支持外层目录及自定义 overrides；普通 ZIP 无元数据时需要指定游戏和加载器版本。只导入实例数据，不导入其他启动器账号、共享缓存及 versions。
- HXZ UP：识别各格式中 updater/config.json；Modrinth client-overrides 优先，导入预览与实际提取使用相同配置。保留原有暂存、继续与取消功能。
- CurseForge：从 MCIM 提供的真实文件元数据获取地址、文件名、大小和 SHA-1。作者未开放分发或元数据不可用时明确报错，保留任务供稍后继续，不拼接猜测的下载地址。
- MOD：按当前实例的 Minecraft/加载器筛选兼容版本，解析必需依赖；先下载校验，再写入实例，失败移除本次新增文件。同名不同内容不覆盖。原启停、删除和打开目录保留。
- 个性化：保留旧用户设置、新用户默认浅色；三个栏的透明度应用于背景，文字和按钮保持清晰。隐藏侧栏后，标题栏提供恢复外观及主页入口。原背景位置/裁剪、实例头图位置/缩放、收藏、固定服折叠、目录入口保留。
- 内存：全局默认自动分配；每实例可选跟随、自动或指定内存。修复底部内存说明表达式优先级错误。
- 论坛：服务器保存评论 parentId，拒绝跨帖回复；分页补充必要的上级评论，限制最多八层，删除父评论保留子评论。增加真实的评论点赞/取消接口和计数，同一用户重复点赞不累加。
- 颜文字与 Emoji：补回 0.4.1 Git 提交遗漏的 EmojiPicker.vue，共用于聊天与论坛。
- 蓝图库：补齐版本索引 API，从所有已审核蓝图提取 Minecraft 和 Create 版本，不再局限于当前列表页。
- 更新日志：分页读取正式 Release，最多 1000 条，后续页失败保留已读取内容；首请求不可用时沿用签名镜像降级。当前 Release 说明只写相对上一版的变化。

## 隐藏活动（管理员说明）

进入启动器“设置”，焦点在输入框之外，连续输入：↑ ↑ ↓ ↓ ← → ← → B A。每次按键间隔不超过 2.5 秒。普通导航不出现活动入口。页面右上角关闭按钮返回设置。

活动使用现有社区登录身份，不携带测试账号，不另外启动网页服务器。界面和动画随客户端打包，剧情、解锁代码、卡面与进度由社区服务提供。未输入入口代码前不返回牌库；未点亮的牌不返回剧情或真实卡面；管理员令牌与玩家令牌不会传给内嵌页面。

保留七张基础牌、最后读完的基础牌、中心恋人牌、最终剧情和“恋人牌已加入牌库”弹窗的完整顺序。最后点亮哪张基础牌都适用，读完状态和最终归档状态由服务器持久保存。切换角色或社区连接时释放图片缓存并重建页面。

后台 /admin/ 新增“活动管理”，使用原管理员登录。可开关活动，修改入口代码、七张牌的代码/开放时间/章节/对话及最终剧情。活动配置保存在 data/arcana/config.json，玩家进度在原 community.sqlite 的 arcana_progress 表，绑定角色 UUID。

初始内容来自提供的活动网页，初始活动日期已经过去，测试代码沿用原网页。正式活动开始前请在后台修改代码和开放时间。默认卡面随服务端 arcana/assets 分发；客户端不包含全部剧情或解锁代码。隐藏入口是活动设计，不是密码安全边界；源代码仓库中的默认示例内容可被查看。

## 构建与升级

客户端：安装锁文件依赖后运行 pnpm build:desktop。脚本先编译，再直接调用 electron-builder，绕过 Quasar 打包模块兼容故障。最终安装器、便携 ZIP 与独立社区 ZIP 分开交付。

发布整理：设置 HXZ_RELEASE_DIR 为独立的新版本目录，再运行 node scripts/package-release.mjs。该脚本拒绝将已有 data、.env、profile 的部署目录压成公开包。签名密钥沿用现有私有路径，不进入源码或发布文件。

社区必须升级到 0.4.2 才能使用评论点赞/嵌套回复、语音进出事件和隐藏活动。停服并备份 data 与 .env，再替换 src、public、arcana 等程序文件，保留原 data 与 .env 后启动。数据库自动追加表和列。Docker 已补上 arcana 目录。客户端不会自动部署社区服务端。

本轮不自动修改公网服务，不安装覆盖用户正在使用的客户端。用户已明确授权修复 GitHub 的 0.4.1 源码遗漏并发布 0.4.2。UI 由用户手动验收。
