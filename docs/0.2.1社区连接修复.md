# 0.2.1 社区连接修复

症状：公告列表部分正常，但聊天大厅、在线状态、语音和账号页社区连接均失败。

根因：打包后的 Electron 页面使用 file:// 来源建立 WebSocket；0.2.0 服务端默认只允许 null 和开发网页来源。HTTP 公告接口正常，但 WebSocket 在身份验证前被断开。

复现证据：同一台机器、同一服务、同一路径，null 来源与开发网页来源可以打开连接，file:// 收到 socket hang up。实际打包客户端直接建立 WebSocket 也失败。修复后的同一客户端、同一地址可正常建立连接。

修复：默认白名单加入 file://；旧 .env 已允许 null 时，自动兼容 file://，无需手工修改旧配置。不放开任意网站来源，社区令牌校验、权限、封禁和语音房间隔离继续生效。客户端与服务端版本同步为 0.2.1，继续独立运行、独立打包。

升级：服务端停止旧进程，保留 data 和 .env，再使用 0.2.1 程序运行。客户端地址仍填写社区根地址，本机默认为 http://127.0.0.1:8787。已达到自动重试次数上限的客户端需要再点“连接社区”或重新打开。0.2.0 客户端也能连接修复后的服务，安装 0.2.1 可同步版本。

发布包分别在 release/0.2.1/client 和 release/0.2.1/server；源码在 client 与 server。

回归检查：server/test/community.test.mjs 使用桌面 file:// 来源执行认证、消息、在线状态、同房间语音信令、封禁与权限检查，同时验证未知网站仍被拒绝。scripts/verify-desktop-community.mjs 使用打包页面进行双桌面窗口联调；测试身份与数据全部隔离，不连接生产皮肤站、不使用玩家凭据。

## 同版追加

用户追加：重做语音侧栏；安装整合包和启动游戏的真实进度，可展开定位卡住步骤、搜索日志。保持版本 0.2.1，客户端和服务端分别发布。

实现：当前阶段按实际校验完成的文件/条目计数，整包下载按本次传输字节计数；重试换源不会累加百分比。解压和本机库提取有计数。Java 安装组件每 250ms 报告步骤、活跃文件和接收字节；无法预估的加载器处理显示具体步骤和耗时，不使用加权假进度。任务详情保留最近 120 步、1000 行日志，支持搜索、仅错误、导出和取消。出错后保留失败阶段，按错误类型提示对应操作。游戏进程创建后显示运行状态，不把它冒充为游戏已完成渲染。HXZ UP 原有 JAR 未提供结构化计数时显示执行状态和原始日志，不编造百分比。

语音侧栏使用清晰房间计数、当前房间标记、独立连接状态、方形麦克风/收听/离开按钮；适配深浅主题及全局字号。

左上角标识调整为方框“幻”、右侧“幻想镇”与小号 FANTASY TOWN，字号变化时保持单行排列。

最终验证：客户端类型、静态与格式检查通过；真实下载检查了分块字节、换源重置和失败不计完成；Java 安装组件实际下载两个文件并报告字节/计数；真实 hxzv3.mrpack 解压完成并识别三个去重 HXZ UP 地址；现有 NeoForge 实例启动准备完成，依赖和资源均报告真实计数。没有重复启动游戏或进行长时间压力测试。
