## 使用与升级

客户端下载与安装入口新增资源包 / 光影 / 数据包，数据包需选择已有存档。实例菜单可配置 Java、检查服务器、导出已安装的默认服务器整合包。设置内“问题反馈与处理”对普通用户展示自己的反馈；社区管理员可切换全部反馈并回复或标记处理状态。

个性化中设置视频背景、默认头图、音乐、面板透明度与动画速度。视频与音乐最大50MB，图片最大8MB（安卓导入背景图会缩小至最长边2048像素）；视频质量控制画布绘制上限，不改变源视频解码分辨率。安卓切换分区仍保留背景与音乐，进入后台暂停，加入语音暂停背景音乐。默认无音乐。

社区服务端单独升级：先停止旧服务并备份 data 和 .env，替换程序/shared/node.exe 后保留配置与数据库启动。反馈表、长期分数表自动初始化。反馈、观战和新版长局分段成绩要求0.5.0服务端；未操作线上服务或玩家数据。三种客户端不捆绑运行社区服务端。

下载并发仍为8/16/32/64/128五档，默认64，Node与内置更新器共用所选档位。已知官方与镜像映射参与下载，小文件按延迟竞争，大文件符合大小和哈希要求时最多4段，最终校验失败回退完整下载。网络故障最长持续重试30分钟，可随时取消；已完成文件可继续复用，中断片段在同一任务内Range恢复。取消时清理片段，不声称跨退出保存所有未完成片段。

程序依赖缓存位于安装目录 launcher-cache；Java位于游戏根目录的同级 java 文件夹。为解决Windows旧版Java中文命令行编码，启动前将登录agent放入实例 .hxzl 并使用ASCII相对路径。账号和用户设置仍在既有profile，升级不迁移或清空。

## 实际限制

离线模式仅在已登录并建立角色/皮肤缓存、账号服务发生网络故障时由用户选择，密码错误不会触发；不保证进入需要在线验证的服务器。HXZUP维护、权限错误、坏清单和未完成替换不会被当成可以忽略的离线更新。

模组显示作者发布的项目名和图标；项目没有官方中文名称时保留作者名称或文件名，不把第三方翻译标成官方。导出包在其他启动器内通过自带命令或该启动器的启动前命令继续运行HXZUP，不假定所有启动器支持统一的自动更新钩子。

32位版共用PC功能与业务代码，运行时为Electron22；现代MC/Java本身的系统与架构要求不因启动器兼容Win7而改变。服务器诊断可以定位已知日志证据、DNS与TCP问题，服务器内部插件/模组错误仍需管理员结合服务端日志。
