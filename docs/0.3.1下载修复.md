# 0.3.1 下载修复

用户在安装 HXZ-survival / Minecraft 26.2 的5057项资源时，资源923654dec2bcc9ff88bb6c4ffd99fcffaa9b4c2a触发 `Network$RaceState.join: Download workers did not exit`。日志来自正式安装于E:/HXZL的0.3.0，游戏目录E:/hxzlacher，任务已暂停。

复现：使用真实Network代码，主下载源完成有效文件，备用源模拟不响应中断的连接等待。旧版约13秒后产生与用户相同的异常；仅去掉备用源就成功。说明失败发生在多源竞速的退出等待，而非文件校验或主文件句柄。

修复：删除单文件多源竞速线程和等待逻辑，GameInstaller继续限制8个文件并行；一个文件依次使用首选镜像和后备源，成功后不再启动其他源。每个来源最多重试配置次数，保留HTTP永久错误判定、Retry-After、SHA-1与大小校验、流式写入、取消和关闭后清理临时文件。构建前清空固定的生成目录，避免残留旧内部类进入JAR。

验证：scripts/verify-installer-network.mjs使用实际Java代码检查卡住的备用源不阻碍成功下载、503重试、坏哈希换源、取消与临时文件清理。修复后原复现约0.2秒成功。加real参数实测用户日志中的同一公开资源，11108字节、SHA-1校验通过。未重复安装整个游戏。

本机：确认没有安装Java进程，核对E:/HXZL原组件与0.3.0基线一致后备份到.test/installed-installer-0.3.0.jar，替换resources/installer/game-installer.jar并校验。未改游戏文件、账号或失败任务，用户可直接继续安装。本机实际替换后的JAR再次通过故障复现检查。完整0.3.1已构建，整理发布附件，沿用用户既有GitHub发布授权。客户端与服务端继续分开，服务端本次仅版本号变化。
