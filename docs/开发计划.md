# 幻想镇启动器 0.1.0 开发计划

用户已授权：完善 E:\hxz_la 现有框架，加入聊天大厅及语音、幻想镇皮肤站统一登录/账号管理、公告及其原版生存群组/模组一服/模组二服子菜单、游戏基本配置、HXZ UP 自动更新。现有服务只有皮肤站和 HXZ UP，聊天与公告配套服务端也已明确授权开发。

皮肤站实测：Blessing Skin 6.0.2，https://skin.hxzmc.top/api/yggdrasil 提供 Yggdrasil API for Blessing Skin 5.1.5，支持外置登录。使用其身份认证游戏与社区，不把网站 Cookie 与 Yggdrasil token 混为一谈。网页管理在独立持久会话窗口中打开；自动刷新启动器令牌，不保存密码。

交付范围：现有桌面客户端（Vue/Quasar/Electron）、Node 24 配套 HTTP/WebSocket/SQLite 服务、WebRTC 小型语音房间、部署说明与必要验证。默认本地社区服务 localhost:8787；实际 HXZUP 各群组地址及社区域名已向用户异步询问，未回答时保持可配置，不猜测生产地址。实际远端部署需要主机访问权限，先完成本地可运行交付。

实现顺序：基础环境与工程脚本；社区服务和身份校验；桌面安全桥、账号加密保存、实例解析/Java/启动/HXZUP；客户端页面和语音；实际服务/启动命令/两客户端聊天与语音/浏览器检查；打包与文档。

约束：下载流式、有界并发、校验哈希；游戏启动 shell=false，参数列表；令牌不写日志；对本地实例和压缩包路径做范围与符号链接检查。游戏更新先单独运行随包 HXZUP 1.0.3，再读取更新后的实例 JSON，避免用旧 JVM 启动参数启动新版游戏。缓存/账号独立存储。

当前状态（2026-09-14）：桌面业务、社区服务、页面和 WebRTC 已实现。已按用户最新反馈调整为桌面工作区：本地实例侧栏、实例概览、表格式实例管理、底部固定启动区；去除宣传文案。原版示例页面已移除，实际代码经过格式化、类型检查和静态检查。

验证已完成：社区认证身份不可由请求伪造、管理员公告权限、聊天持久化、同房间信令隔离；文件路径、继承 JSON、流式校验和下载失败保留原文件；实际 HXZ UP 1.0.3 JAR 维护模式；双浏览器实际聊天与 WebRTC 音频 RTP、静音/释放；真实 Electron 桌面桥、Java 检测、页面导航和进程隔离；现有测试整合包 Minecraft 1.21.1 / NeoForge 21.1.250 依赖和参数准备。

生产皮肤站真实玩家登录、游戏入服、公网 TURN 仍需部署与真实账号验收，不声称已经完成。现有客户端没有玩家凭据；服务地址仍为可配置默认值。

Windows x64 最终安装程序、便携版 ZIP、随带 Node.js 的社区服务 ZIP、SHA256SUMS.txt 已整理到 release/0.1.0。实际运行包已通过实例读取、导航、最小窗口启动区可见、模拟麦克风权限检查；服务端包 /health 已通过。开发预览与临时联调进程已停止。Electron 下载使用正常校验的国内镜像；builder 使用已安装的 Electron 目录，避免 Windows 解压临时目录的重命名失败。没有推送 GitHub，因为本次启动器开发未要求上传。
