# 0.4.4 开发与交付

开发工作树 E:/hxz_la/work/v044，分支 release-0.4.4，基线 eeb6b99。正式交付目录 E:/hxz_la/release/0.4.4。Windows x64、兼容 ia32、Android 40401 同步版本。客户端和服务器分别打包；不部署公网，不操作真实玩家数据。

## 本版范围

- 32 位和 64 位共用游戏、安装与界面代码。Electron 22 缺少 webUtils 时使用旧 File.path；现代版继续使用 getPathForFile。Java 安装参数以 ASCII 中的 UTF-8 编码传递，辅助程序的 classpath 使用工作目录下相对路径，避免中文路径变成问号。
- 按实际 Java 位数选择本机库及内存；按 Windows 系统架构选择自动下载的 Java。32 位启动器在 64 位 Windows 上可以运行 64 位 Java。真正的 32 位 Java 仍限制最大堆 1280 MB。没有合适的官方 Java 时提供明确提示，不承诺 26.2 能在 Win7/32 位系统运行。
- 三个默认入口的版本、加载器、Fabric API、包体地址/SHA256、HXZ UP 地址、默认/强制更新和自动进入服务器规则，可在社区网页后台“默认服务器”分别编辑。客户端缓存最后成功的配置，启动前刷新；旧服务端暂时使用内置默认值。
- 原版默认 26.2 / Fabric / Fabric API，s1.hxzmc.top，HXZ UP /original。模组一服 /modv1、模组二服 /modv2，游戏配置读取对应 HXZ UP。服务正在维护或未发布配置时明确提示，不猜测游戏版本。自动更新可在实例设置关闭，管理员要求强制更新的除外。
- 选择默认实例、点击启动即可准备游戏。指定版本变化时在独立目录准备升级，完成后替换；原目录保留于游戏根目录 .hxzl-backups，失败时原实例不受影响。安装任务可继续或清理。不要删除含玩家存档的备份，交由玩家自行管理。
- 日志记录实际 Java/系统/启动器架构、安装目标、退出码及异常原因；崩溃摘要保留异常附近上下文，忽略常见非致命 job-object 警告。下载遇到限流按服务端提示退避，Java 多文件共用限流冷却，继续校验内容和清理失败的临时文件。
- 独立“小游戏”入口：林间疾跑、俄罗斯方块、打砖块，卡片列表，键盘和触摸操作。三端共用规则，社区服务端回放操作记录计算成绩，每个游戏单独排名，每 5 秒刷新。支持后台移除成绩；未登录或服务不可用可练习，不计排名。Linking 内容及解锁逻辑保持原状。

## 服务端升级

后台“默认服务器”分别为三个实例设置 HXZ UP 连接列表，最多 16 项，可添加、删除和上移调整顺序。支持 http://主机:端口/整合包、HTTPS 及 HTTPS 自定义端口。备用地址必须提供同一整合包的内容。读取安装配置和更新前检查时按顺序换源，每个地址最多等待 8 秒；日志显示尝试地址和失败原因。选中的有效源传给 HXZ UP 优先使用，其余地址保留用于文件下载失败后的切换。某个可连接的源明确处于维护时尊重维护状态，不以备用源绕过。

安卓版底部主导航为聊天、社区、游戏、公告、我的五项；文字／语音与论坛／蓝图分别在分区顶部切换，保留上次选择的子页、通话状态和未读提示。PC 版继续使用原有独立左侧栏目。

排行榜和默认服务器后台需要本版独立社区服务端。停服后备份 data 和 .env，替换程序文件（包含新增 shared 目录）后启动，保留原数据。新配置在 data/server-presets.json，成绩在原 community.sqlite 新增表。首次默认地址分别为 https://hxzup.1szt.com/original、/modv1、/modv2。整合包的文件同步策略仍由对应 HXZ UP 管理。

## 开发验证记录

已做针对性规则回放、后台权限及排行榜验证、路径编码和架构选择检查；原有安装恢复、网络失败重试、收藏、崩溃报告与架构更新签名检查通过。Java 下载实际 64／128 并发、失败换源、校验和取消清理检查通过。

Windows 11 上分别运行正式 Electron 44 x64 与 Electron 22 ia32 包，文件选择、原生文件路径、整合包识别与 Java 扫描均通过；两者均能识别同一组 64 位 Java。UTF-8 编码路径由真实 Java 读取验证。PC x64 实包检查小游戏入口、键盘事件及暂停后结算；Canvas 使用固定步长逻辑、逐帧插值、缓存背景和有界特效，暂停停止绘制，排名请求不堆积。

安卓版检查五项导航、七个独立页面、子页记忆，以及 320／390／820 宽度、缩小可用高度及大字号下导航和输入框不重叠。桌面类型检查、三端生产构建和 Android Lint 通过，APK 沿用原签名证书，版本为 0.4.4（40401）。更新清单使用既有发布密钥签名。UI 仍由用户手动验收，不以桌面浏览器帧率代替安卓真机性能结论。
