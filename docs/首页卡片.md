# 兼容卡片格式

一张卡片是一个 UTF-8 JSON 文件，扩展名为 `.hxzplugin`。复制 `examples/worlds.hxzplugin`，修改标识、作者、标题、说明和目标页面。在完整工作台的「设置 → 扩展 → 玩家自制卡片」导入，核对作者和正文后启用。卡片立即出现在首页，可以移动、改变尺寸、停用或移除。重新导入同一标识后需要再次确认权限。

| 字段 | 用途 |
| --- | --- |
| `format` | 固定为 `hxz-card-v2` |
| `manifest.id / version` | 小写字母开头的标识符及三段版本号 |
| `manifest.name / author / description` | 供玩家在启用前查看 |
| `manifest.apiVersion / permissions` | 值为 `2` 和 `["home.card"]` |
| `card.title / body / route` | 标题、纯文本说明、可选的启动器内页面路径 |

桌面端和市场共享 `server/shared/card-plugin.mjs`。校验器限制字段、大小和目标路由。原 API 1 插件的作者可以把展示内容改写为这个格式。市场向兼容旧客户端保留了旧包识别。

文件上限为 64 KiB。API 2 只接受表内的字段，权限范围是首页展示和白名单内的站内导航。目标页面仍执行自身的登录与扩展检查。官方音乐、小游戏和社区使用单独打包、按启动器版本固定 SHA-256 的代码包。安全模式参数 `--disable-plugins` 可在排查异常时跳过官方扩展与玩家卡片。
