# 兼容卡片格式

一张卡片是一个 UTF-8 JSON 文件，扩展名为 `.hxzplugin`。可直接修改 `examples/worlds.hxzplugin`。独立的兼容 SDK 提供格式校验与样例。0.10.0 游戏启动器首页采用固定操作入口。

| 字段 | 用途 |
| --- | --- |
| `format` | 固定为 `hxz-card-v2` |
| `manifest.id / version` | 小写字母开头的标识符及三段版本号 |
| `manifest.name / author / description` | 供玩家在启用前查看 |
| `manifest.apiVersion / permissions` | 值为 `2` 和 `["home.card"]` |
| `card.title / body / route` | 标题、纯文本说明、可选的启动器内页面路径 |

桌面端和市场共享 `server/shared/card-plugin.mjs`。校验器限制字段、大小和目标路由。原 API 1 插件的作者可以把展示内容改写为这个格式。市场向兼容旧客户端保留了旧包识别。
