# 幻想镇 0.10.0 启动器界面设计参考

0.10.0 首页首先服务回来的玩家。打开窗口后，应当能认出上次游玩的实例、确认当前角色并直接启动。喜欢布置桌面的玩家可以选择卡片和背景，喜欢紧凑列表的玩家也能在同一套导航里完成这些操作。

## 幻想镇、HMCL 与 PCL

2026 年 11 月 20 日核对了本机 `E:\HXZL\幻想镇启动器.exe` 的版本信息（文件版本 0.9.2、产品版本 0.9.2.0）、安装版留存的界面预览、玩家提供的实际首页截图，以及对应发布源码。预览显示首次使用时的默认服和「安装并启动」，玩家截图则补充了已登录、已有许多实例时的真实布局。外部启动器依据下列官方产品页、文档及源码核对。

| 参考 | 能从资料确认的设计 | 幻想镇的取舍 |
| --- | --- | --- |
| 幻想镇 0.9.2 | 宽窗左栏放角色、服务状态和实例详情，右栏放实例与游玩日历。实例行同时显示名称、版本和启动按钮。顶栏有图标，卡片标题有整理入口。旧版设置也识别图片、MP4 和 WebM 背景。[本机安装版与发布源码核对](./0.9.2与0.10.0桌面功能对照.md) | 保留玩家认得的入口和卡片。宽窗可以同时看列表与角色，窄窗把继续游玩的操作放前面。默认服在本机没有实例时仍可发现。 |
| HMCL | 官方分别展示主题配色、自定义背景图和自动安装游戏或加载器的流程。[HMCL 功能介绍](https://hmcl.huangyuhui.net/) | 玩家壁纸与界面方案分别保存。换色、调整卡片或切换布局时继续使用自己的背景。首页和游戏库提供安装入口，安装流程归入资源页。 |
| PCL | 启动页给启动按钮更高的视觉权重，在旁边提供版本选择和版本设置。个性化页给背景图片单独一张卡，能调不透明度，图片从本地目录读取。[启动页源码](https://github.com/Meloong-Git/PCL/blob/93ede5d9e638c99fcec853a9ba1eecd91ceee7f5/Plain%20Craft%20Launcher%202/Pages/PageLaunch/PageLaunchLeft.xaml) · [外观页源码](https://github.com/Meloong-Git/PCL/blob/93ede5d9e638c99fcec853a9ba1eecd91ceee7f5/Plain%20Craft%20Launcher%202/Pages/PageSetup/PageSetupUI.xaml) | 给当前实例一个明确的主操作。实例设置从该实例进入。外观设置提供独立壁纸选择器，选择纯色可以收起背景媒体。 |

## 五款桌面启动器的功能参照

| 产品 | 官方资料中可见的具体做法 | 对幻想镇的启发 |
| --- | --- | --- |
| Modrinth App | 实例的 Content 页列出其内容，模组可集中安装、卸载和更新。官方以打开的 Cobblemon 实例展示这个流程。[Modrinth App 产品页](https://modrinth.com/app) | 「资源」负责发现内容。进入游戏库中的某个实例后，再展示它已安装的内容和可执行操作，始终显示操作目标。 |
| Prism Launcher | 可从工具栏创建实例，在选定实例的菜单进入编辑。启动器设置可独立调整实例排序、图标主题和颜色主题，还可选择菜单栏或工具栏。[创建与编辑实例](https://www.prismlauncher.org/wiki/getting-started/create-instance/) · [启动器设置](https://www.prismlauncher.org/wiki/help-pages/launcher-settings/) | 实例多时保留清晰的列表、排序和选中态。让玩家选信息密度，同时维持「启动」「管理」的名称与键盘操作顺序。 |
| GDLauncher Carbon | 游戏库提供命名分组和收藏栏。Carbon 也支持从其他启动器导入实例，并在整合包更新时展示变更。[分组与收藏](https://gdlauncher.com/guides/group-instances-and-favorites/) · [Carbon 功能说明](https://gdlauncher.com/docs/gdlauncher-vs-gdlauncher-carbon/) | 首页只需呈现最近或常玩的实例。完整收藏、导入与更新详情留在游戏库，适合同时管理几十个实例的玩家。 |
| XMCL | 发现页支持用 Minecraft 版本和加载器筛选整合包与社区项目，从发现资源延续到游玩。[XMCL 官方功能介绍](https://xmcl.app/en/) | 由实例进入资源页时，其版本和加载器是有意义的筛选条件。它们适合放在资源列表上方，占用一行就够。 |
| FTB App | 支持检索整合包、安装多个版本、更新已有实例。Java 与内存可以按整合包实例配置，下载速度也可调整。[FTB App 功能介绍](https://www.feed-the-beast.com/ftb-app) | 全局设置显示默认内存，实例详情说明沿用全局还是单独设置。下载任务在状态栏可达，进度和错误在任务内展开。 |

Minecraft 官方启动器的 Quick Play 还提供一个有用的对照。它按实际游玩时间排列最近五个世界，玩家可以固定常玩的世界。幻想镇玩家明确选择了「继续上次的实例」，因此首页应恢复实例。临时浏览另一个实例时，仍应找得到原来的继续入口。[Minecraft 官方 Quick Play 说明](https://www.minecraft.net/en-us/article/quick-play-coming-java-and-bedrock-edition)

## 幻想镇的设计取舍

| 玩家操作 | 建议的交互结果 |
| --- | --- |
| 更换整套界面 | 方案应当在卡片疏密、实例列表的排布或窗格材质上有清晰差别。默认窗口要看得清角色与实例，小窗首屏要能继续游玩，纯色高对比方案要能读清长路径。 |
| 更换背景 | 提供纯色、本机静态图和本机动态视频。换界面方案、重新打开应用后，仍使用玩家选择的背景。清除背景后恢复可读的底色。视频应静音，暂停后保留清晰的静态表面。 |
| 整理卡片 | 允许移动、调整尺寸、隐藏和恢复卡片。将某张卡隐藏后，功能仍能从对应页面进入。恢复默认可以在没有任何可见卡片时操作。 |
| 调整窗口 | 窄窗让按钮组换行、长名称换行或显示完整名称入口。选择态要在浅色、深色和强对比壁纸上都能认出。顶栏为导航、账号与窗口控制各留独立空间。[桌面界面约束](./桌面界面约束.md) |
| 启用社区 | 游戏库、资源、联机、播放器随启动器提供。设置安装社区扩展并重启后，社区、协会和 LINKING 出现在同一个窗口，沿用相同的页面标题、卡片边界和背景偏好。 |

表中的取舍用于决定入口归属和验收场景。实际交付的功能、设备与验证结果见对应版本的回归记录。[0.10.0 桌面回归与功能补齐](./0.10.0桌面回归与功能补齐.md)
