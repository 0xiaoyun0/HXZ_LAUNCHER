# 幻想镇启动器 0.10.0 桌面回归与功能补齐

这次核对以本机正常安装的 0.9.2、其中三个默认实例的版本清单和玩家实际操作为依据。完整的 140 项清单保留了修改前的判断。下表更新本次已经处理的项目。[修改前的逐项对照](./0.9.2与0.10.0桌面功能对照.md)

## 窗口排版

窗口、内容、卡片、滚动、阅读区，以及窄窗的任务顺序有单独的尺寸约束。[桌面界面约束](./桌面界面约束.md)

| 玩家看到的问题 | 现在的布局规则 | 怎么复查 |
| --- | --- | --- |
| 窗口变窄后图标挤在一起，两个顶栏项目同时高亮 | 标题栏、工作区、状态栏各占一行，顶栏保留图标，按宽度收起文字。每个位置有自己的点击区域 | 安装社区插件，依次进入社区、协会和 LINKING，缩窄窗口，检查当前页、头像和窗口按钮 |
| 设置卡片套卡片，折叠标题贴边，字号变大时按钮伸出卡片 | 分类栏和内容分列，同一组设置只画一层边框。表单标签、控件和操作组可换行，折叠标题整行可点击 | 打开设置，切换各分类，展开「游戏运行与兼容」，使用 22 px 字号 |
| 资源和语音页面出现拖动手柄，空内容占着大块固定高度 | 卡片按内容定高，通过 CSS 网格排列。列数取决于可用空间，语音房列表和设备控制分别排布 | 打开安装游戏、下载节点和语音房，切换房间列表、缩小窗口 |
| 背包和活动页重复标题，活动按钮贴着卡片边缘 | 页面负责主标题，嵌入的模块负责条目和操作。卡片的正文和操作使用统一内边距 | 从社区更多功能进入「我的背包」和「活动与赛事」 |
| 积分页的余额、入口和兑换输入散在整屏，背包空状态挤在第一格 | 积分余额和账本分区，窄窗垂直排列。空背包占满内容栏。收件箱工具条、服务器日历和更新公告有独立边界 | 从社区进入积分、背包和服务器记录，分别检查空列表与有数据的页面 |
| LINKING 正文缩成窄带，四周却有空白 | 阅读区占满导航与底部状态栏之间的剩余空间，章节自己滚动 | 进入档案馆，打开章节，调整窗口高度，检查阅读区与状态栏 |
| 实例过多时首页丢掉主要操作，默认服挤出可见列表 | 首页突出继续上次实例。三个默认服有固定入口，实例列表、底部操作和日历各有独立边界 | 使用已有游戏目录及带大量收藏的测试目录，搜索、切换实例、进入默认服详情 |

桌面检查在原生 Windows 启动器的 WebView2 中执行。对 36 个入口或设置分类各测六组。16 px 浅色使用 780 × 540、1250 × 825、1360 × 880、1920 × 1080，22 px 深色使用 780 × 540 和 1000 × 660。每组另从正常入口打开实例配置和每周时长榜，检查焦点、关闭键和对话框边界。按这组新约束回测，修改前的 1000 × 660 大字号窗口中，36 个入口的关闭按钮均越过右边界。测量窗口边界、横向溢出、控件碰撞、重复标题及档案正文高度。顶栏另外检查八个中间宽度。长页面还会滚到中部和底部检查。标准窗口会为每个入口留存一张实际画面。完成本地构建后，运行 `npm run test:desktop:layout` 可以重复这组检查。[逐页检查脚本](../scripts/desktop-layout.mjs)

2026-11-20 的 Windows 11 x64 实测通过 216 组页面布局和 12 组弹窗检查。包括启用社区后往返各页并回到首页、在窄窗切换设置分类，以及比较页面顶部、中部和底部的控件边界。1360 × 880 窗口的 LINKING 档案内容区高 659 px，在 780 × 540、22 px 字号下高 297 px。新版在原先关闭键越界的条件下通过了全部 36 个入口。

## 旧版细节与去留

| 玩家操作或旧数据 | 0.10.0 的处理 | 归属 |
| --- | --- | --- |
| 继续上次游戏 | 首次启动识别有效的旧游戏目录，读取选中的实例和上次成功游玩的记录。首页可以直接继续 | 核心 |
| 找到默认服务器 | 首页和游戏库都能找到原版生存群组服、模组一服、模组二服。版本来自各自实际安装的清单。详情可看地址、联机状态和更新规则，点「进入服务器」会明确请求加入 | 核心 |
| 皮肤站断线 | 保留已有角色并提供连接检测。玩家能从角色卡管理皮肤站。临时服务错误、登录失效和错误密码分别提示 | 核心 |
| 设置游戏内存 | 全局设置和实例覆盖共用启动时的内存计算。非法数值当场提示，保存后重启仍有效，启动前能查看实际限制 | 核心 |
| 调整下载并发、限速与来源 | 设置提供引擎支持的并发档位和总限速。重新打开和重启后能读回选择 | 核心 |
| 恢复误移除的实例 | 在「设置 → 游戏与 Java → 已移除实例」将仍在磁盘上的实例恢复到游戏库 | 核心 |
| 回看某天玩了多久 | 本机日历合并旧日历和已结束的会话，合并重叠时间、拆分跨日记录。日期支持鼠标和键盘打开。服务器核验时长和周榜有独立入口 | 本机在核心，服务器记录在社区 |
| 播放已有音乐 | 保留播放器、播放模式、歌词和底栏控制。旧曲库支持预览、取消、确认导入及重复导入去重，可接回仍存在的本地文件及可识别的网易云条目 | 核心 |
| 与朋友联机 | 联机大厅保留开房、邀请、实例匹配和连接诊断。设置中可调整社区备用中继 | 核心 |
| 阅读档案、办委托、收消息 | 在设置下载或导入官方社区包后重启，原窗口增加社区、协会和 LINKING。收件箱把可识别的旧通知带到对应内容 | 可选社区插件 |
| 查看入服申请、积分及已兑换的权益 | 世界与入服、积分流水、背包、兑换记录、活动和申诉集中在社区更多功能中 | 可选社区插件 |
| 查找与投稿蓝图 | 公开浏览和下载从资源页进入。投稿、收藏等身份操作位于社区 | 核心及可选社区插件 |
| 游戏出错后求助 | 先说明原因与可执行的处理方法。需要协助时可以复制脱敏摘要，也可确认后提交管理员工单并跟进回复。技术日志默认折叠 | 核心 |
| 每页自由拖拽、小游戏占据主导航 | 桌面使用固定的任务入口，保留游戏库、联机和音乐的空间。旧小游戏集合继续暂缓 | 本轮取舍 |

## 实测数据与边界

- 同一台 Windows 11 x64 电脑运行 x64 和 ia32 客户端。测试角色、皮肤站模拟服务、社区服务和游戏工作目录均独立。本机 Java 17 诊断客户端记录收到的堆参数，覆盖非法输入、保存、重启、启动和停止。
- 使用本机已安装 0.9.2 的只读资料单独启动新版，共识别 56 项，其中 53 项已安装，有 11 天历史游玩记录。原版群组服为 26.2／Fabric 0.19.5，模组一服与二服同为 1.21.1，分别使用 NeoForge 21.1.250 和 21.1.251。测试前后核对四份旧资料和三个实例清单的文件指纹。[旧版资料复核脚本](../scripts/check-installed-library.mjs)
- 本地服务覆盖皮肤站 503、插件下载失败、损坏包、重启启停、工单和社区交互。正式服登录、两个物理设备间的语音或公网联机，以及真实 32 位操作系统仍需在相应环境验证。只有汇总的旧日历保留可证实的时长，无法反推已经丢失的会话。
