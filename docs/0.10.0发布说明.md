# 幻想镇启动器 0.10.0

首页的「继续游玩」会打开上次使用的实例。Windows 开始菜单提供一个「幻想镇 3rd」入口，在「设置 → 工作区」切换完整工作台与极简版，下次启动会记住选择。两个界面共用游戏目录、皮肤站角色、内存设置和个人积分。拖动工作台卡片时可以看到旁边的卡片让位，松手保存，Esc 取消。极简版可在「下载 → 模组与资源」同时查本地文件与在线版本，直接切换目标实例。

音乐播放器、小游戏和社区分别在「设置 → 扩展」安装或移除，重启后生效。社区包提供聊天、论坛、语音、积分商城、排行榜、冒险者协会和 LINKING。玩家可以在同一页导入 API 2 自制首页卡片。

首次运行会检查已有的 0.9.2 游戏目录。手动内存、实例内存继承和 HXZRE 的关闭状态可随旧配置迁移；设置里也可从指定的旧资料导入。游玩记录和导入前的备份保存在新的用户资料目录。登录幻想镇角色后可以查看对应的服务器积分。

安装后，桌面和开始菜单都能打开同一个启动器。下载扩展时会从本版本的 GitHub 附件获取，启动器检查大小和摘要后再启用。下载断流可以重试，文件不匹配时会提示重新下载或选择同版本的 ZIP。

此版修复了修改卡片间距时其他外观设置被重置的问题。单选项、开关、弹窗和页面按钮遵循同一套按压反馈。启用系统「减少动态效果」或把动效设为零会立即生效。

皮肤站连接短暂中断时，角色验证会自动再试一次。续期返回不完整的登录信息时，启动器会保留已有角色并提示重新检测。已下载的启动器更新如果损坏，也能从原页面重新下载。

使用 0.9.2 Windows 安装版的玩家可以通过原有更新入口升级。便携版需要下载新版完整包，首次进入新版时请重新登录皮肤站。

安卓版支持 ARM64 手机、平板和 x86_64 安卓设备。打开应用后，从社区公告或服务器卡片就能选实例、下载整合包并进入游戏。游戏内核使用 Fold Craft Launcher，启动前按所选服务器检查 HXZUP 更新。

手机导航新增「小游戏」。24 款游戏与 Windows 使用同一套规则和封面，同一角色的社区计分成绩可在两端查看。在线时长由游戏服核验，跨端共用积分余额。切回钱包、积分榜或游玩日历时会刷新。修复了 Android 11 旧 WebView 打开栏目弹窗时看不到内容的问题。

Windows 的任务中心调整了执行步骤标题和卡片边缘的距离，时间线与行分隔线分开显示。游戏启动完成后可以继续查看本次执行的步骤和用时。

社区服主可以从 0.9.2 后台的「服务维护 → 服务更新」获取 0.10.0。默认每六小时检查一次。勾选定时安装后，服务会在指定的北京时间备份数据库并重启，新进程启动失败时恢复旧版本。首次部署请下载独立的 Windows x64 社区服务端完整包。

0.9.2 安卓正式版玩家请手动下载适合设备的 APK，在系统安装界面选择「更新」。新版沿用原来的应用标识和发行签名。旧版自动更新最多接收 64 MiB，完整游戏内核超过这个大小。首次进入新版请重新登录皮肤站。32 位安卓系统可以继续使用 0.9.2。游戏运行组件及社区服务端继续使用各自的更新清单。
