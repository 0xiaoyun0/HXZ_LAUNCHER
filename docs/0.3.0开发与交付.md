## 实现与根因

1. 社区：实际 HTTPS 请求失败后没有重连分支，WebSocket 重连也会在4次后永久停止。已用实际客户端模块、确定性定时器复现并修复；增加退避与随机间隔、网络恢复重试、过期会话更新、手动断开停止重试。桌面主窗口关闭后台节流，新版服务端每15秒协议心跳并支持应用心跳，旧服务兼容。头像同步不再阻塞连接。公网握手正常但没有真实角色登录凭据，不能声称完成公网登录长连接验收。
2. 安装：原下载一个临时503就失败、下载总时长超过180秒会被强制中止，原安装直接写入正式实例。现在临时失败最多3轮重试，连接/无数据超时与总下载时长分离，失败等待流关闭并清除临时part。新实例在游戏根目录 `.hxzl-install/<名称>/instance/<名称>` 暂存，job.json保留安装身份、整合包校验、选项、错误；成功才原子移入versions。同名完整实例不会覆盖；旧版有明确失败标记的目录可迁入暂存继续。清理只删该任务拥有的暂存或已标记失败目录，不删共享资源和其他实例。继续任务复用已校验完整文件，单文件部分字节不保留。
3. Java安装器强制headless，降低工作线程及共享网络并发至8，关闭安装确认框后主进程继续，任务详情可自由收起。关闭正在安装/运行的主窗口改为最小化，不强杀任务。取消会等待Java进程树和文件句柄退出再允许继续/清理。
4. 实际26.2安装发现错误下载Windows x86/arm64本机库导致不可用资源终止x64安装。客户端和Java安装器均按架构筛选。官方26.2安装在隔离测试目录实际经历取消、暂存、继续并完成5057项资源。Java不足时支持官方有界校验的运行环境安装。
5. 启动器GitHub正式Release为更新源，electron-updater 6.8.9比较语义版本并校验下载；默认自动下载，游戏/安装结束后15秒倒计时静默安装并重启，关闭开关停止自动安装，保留手动入口。日志读取同仓库公开Release正文。草稿/预发布不参与更新。GitHub会移除中文附件名，因此公开资产统一ASCII名称，旧版本程序字节不变，校验文件按公开名称重新生成。
6. 固定服务器：HXZ-survival为原版生存群组服，首次准备26.2，默认quickPlay进入s1.hxzmc.top；HXZ-mod-1/2是不可启动的明确占位。每实例可关闭自动进入，也可保存其他主机/端口。MOD管理支持列表、搜索、原生多选添加、启用/禁用、回收站删除、打开目录，运行或安装时不修改模组。
7. 左栏运行日志移除，统一任务详情；三个分服入口保留在通知公告内，并加启动器日志页签。全窗口背景覆盖侧栏与底栏，卡片透明度保留可读性；实例头图使用压缩后有界本地文件，简化首页保留实例选择、头图与固定启动区。
