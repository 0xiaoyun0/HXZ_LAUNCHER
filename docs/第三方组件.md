# 第三方组件

0.4.5 国际象棋规则使用 chess.js 1.4.0（BSD-2-Clause，https://github.com/jhlywa/chess.js），服务端分发保留其 LICENSE。机器人搜索及其他棋类规则由本项目维护。Zulu Java 从 Azul 官方 Metadata API 查询并按官方 SHA-256 校验，安装目录保留归档内许可证：https://docs.azul.com/core/install/metadata-api 。

0.4.5 的内置更新运行时 updater-launcher.jar 沿用 HXZ UP 1.0.3 协议，独立编译 client/installer-java 中的 Updater、Network、GameInstaller、ForgeInstaller，使同步与游戏资源下载共用启动器并发设置。原 updater-1.0.3.jar 保留作为编译依赖，不改动独立 HXZ UP 服务端。

主要运行依赖：Vue、Quasar、Vue Router、Pinia、Vue I18n、Electron、yauzl、ws、electron-updater；各组件的版权和许可证仍归原作者。构建工具依赖由锁文件固定。Electron 分发目录保留 LICENSE 与 LICENSES.chromium.html。

`client/resources/hxzup` 中的 `updater-1.0.3.jar` 与 `launcher-agent.jar` 来自同一工作区维护的 HXZ UP 1.0.3，源代码在 https://github.com/0xiaoyun0/hxz_update/tree/v1.0.3 。JAR 内含其已有的第三方告知和 Gson 许可证，随包保持不变。

authlib-injector 在首次需要时从官方发行接口下载，校验官方 SHA-256，遵循其 Apache-2.0 许可证。项目：https://github.com/yushijinhun/authlib-injector 。本启动器不随包分发 Minecraft 游戏资源；根据玩家本地版本清单及 HXZ UP 配置下载所需资源。

协议文档：

- https://yushijinhun.github.io/authlib-injector/en/launcher-technical-specification.html
- https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API/Perfect_negotiation
- https://www.electronjs.org/docs/latest/tutorial/security

0.2.0 的 client/installer-java 复用同工作区 HXZ UP 的 GameInstaller/ForgeInstaller 并单独维护修复，编译为 resources/installer/game-installer.jar，与原 HXZ UP JAR 共同使用。协议与服务文档：https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack 、https://bmclapidoc.bangbang93.com/ 、https://www.mcimirror.top/ 、https://www.electron.build/docs/features/auto-update/ 。

0.3.0 的安装组件同时包含独立维护的 Network.java，以降低并发并保留下载取消清理逻辑。Java自动安装使用Mojang公开运行环境清单及文件校验，来源文件仍保留原版权告知。启动器GitHub更新使用固定electron-updater 6.8.9，静默安装调用以该版本实际接口为准。
