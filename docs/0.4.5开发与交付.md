## 已实现的功能

- 手工删除实例目录后，旧升级任务可恢复为安装。旧任务配置变化或记录损坏时，将原任务文件保留至 .hxzl-backups 再重新安装。替换失败恢复原实例；还原失败明确显示原文件路径。
- 首页实例栏支持收起和展开的 260ms 双向过渡，固定列表内部宽度、保留 DOM 与滚动位置；快速反向点击衔接当前动画，设置异步合并保存。详情自适应，工具栏不换行顶开页面，尊重减少动态效果设置。实例提供逻辑隐藏和物理删除，弹窗说明存档影响；设置中管理隐藏实例。物理删除仅限所选 versions 子目录，保护共享 assets/libraries；占用时明确提示。
- 中文路径检索开关影响自动 Java 发现，不破坏明确选择的中文路径。实际 Java 架构决定依赖与独立 natives 缓存，修复带 @jar 等 classifier 的 x86 库混入 x64。
- 首次优先 D:/HXZ-minecraft/.minecraft；不足 50 GiB 依次检查后续存在的固定磁盘。没有合适磁盘时要求手动选择，不静默落 C。已有设置不迁移。
- 显式 Java 验证通过后优先使用。无合适 Java 时按游戏版本与系统架构安装 Zulu，路径位于 HXZ-minecraft/java。使用官方 SHA-256 校验，不依赖存在舍入差异的接口 size 字段。32 位 Java 仍受堆大小限制，现代游戏自身的系统要求不会改变。
- 设置分组为游戏与存储、外观与操作、下载与更新、聊天与社区。编辑保留草稿，离开时应用、放弃或继续编辑，提示可关闭。全部校验并落盘后才更新内存配置。
- 聊天日期在前、时间在后；自己靠右、他人靠左，相邻同用户消息分组。记录范围 1/3/5/7/30 天或不限，默认不限；历史每页最多 100 条，实时窗口有界，数据库不再因超过 3000 条删除旧记录。
- 手机、电脑与双端状态按用户合并。同平台新连接替换旧连接，旧端收到明确关闭码后停止抢占式重连。
- 内置 HXZUP 共用启动器 8/16/32/64/128 并发档，默认 64。独立 updater-launcher.jar 包含新的并发与架构筛选逻辑，保留原始 1.0.3 文件。
- 五子棋、象棋、国际象棋支持社区联机与五档机器人，三端共用规则。服务端校验走法与胜负，机器人在独立工作线程计算。机器人模式也需要连接社区服务。
- 安卓修订 40502：删除导致隐式双列的底部二级切换栏；文字/语音与论坛/蓝图各使用一个左侧悬浮图标，仅在各自分区显示。点击切换，长按 420ms 后拖动，两组位置独立保存并在重启后恢复；保留五个主导航和安全区。棋类与积分界面适配手机。

## 积分与对局规则

2026-09-23 用户确认：北京时间每周一结算上周；联机胜利每人每周所有游戏合计最多 1 分；年度榜由当年已结算周榜及周榜前三奖励累计，未结算本周不提前计入；消费不减排名，余额跨年保留。

六款游戏各有周榜前十和本人排名。非联机成绩按各游戏周榜前三名 3/2/1 分结算；周积分榜前三名额外获得 3/2/1 分，奖励不反向改变当周排名。进行中的排名奖励随名次变化，结算后固定。年度榜分页展示全部用户。跨年周的游戏排名结算归属周结束日期所在年份。

后台支持增加积分、扣除余额、生成一次性兑换码；额度使用十进制字符串与 BigInt，无业务额度上限。兑换和管理员发放即时进入余额及当周积分榜，随周榜结算进入年度累计；消费只减余额。兑换、发放、结算有唯一操作记录。玩家可查看余额、排名、兑换入口与收支记录。

联机每步五分钟，空房三十分钟关闭；每人最多两局未结束对局。自由五子棋无禁手。象棋支持蹩马腿、塞象眼、河界、九宫、将帅照面、自将检查，无合法走法判负，三次重复或连续 120 手无吃子判和。国际象棋支持王车易位、吃过路兵、升变、逼和、重复及五十回合规则。单局最多 600 手。五档机器人逐级增加搜索深度与时间预算，不宣称专业棋力等级。
