# 0.3.4 启动器更新镜像

启动器自身更新增加 GitHub 直连、GHProxy（ghproxy.net）、GHFast（ghfast.top）、GH-Proxy（gh-proxy.com）四个入口。只代理本仓库公开发布文件，不转发账号、皮肤站或社区令牌。无需玩家额外配置，原有自动更新开关继续生效。游戏文件仍使用独立的下载来源设置。

检查时最多并行读取四份小型发布信息，每个入口8秒超时、响应上限256KB；跳过错误网页、无效签名及不可用入口，采用可访问来源中的最高正式版本。安装文件优先使用成功读取新版的来源，失败自动换源，45秒无下载进度取消当前传输、等待清理后继续下一来源。所有下载固定到同一个版本的Release路径，不在换源时混入另一版本文件。

发布信息使用Ed25519签名，公钥内置于客户端。安装程序继续由electron-updater流式下载并验证签名清单中的SHA-512。镜像不能通过同时替换程序与普通校验文件来获得自动安装权限。该发布签名与Windows代码签名不同；本项目目前没有Windows代码签名证书。

更新日志先读取GitHub正式Release列表，6秒内不可用时，从经过签名校验的发布信息读取最新版本说明。镜像降级时仅提供最新说明，不伪造历史列表。全部来源不可用时保留当前程序并提示重试，开启自动更新时仍定期重新检查。无法保证第三方公共镜像永久可用，缓存也可能延迟；有任一来源提供新版即可优先识别，所有来源同时缓存旧信息时需等待缓存更新。

## 发布流程

更新版本号及CHANGELOG，执行桌面构建，然后在根目录运行 `node scripts/package-release.mjs`。脚本同时生成兼容旧客户端的latest.yml和新客户端使用的latest.json签名信封。正式Release必须完整包含安装程序、blockmap、latest.yml、latest.json、便携ZIP、独立服务端ZIP及SHA256SUMS.txt；先上传草稿并验证附件，再公开Release。不要先公开尚未上传签名清单的空Release。

签名私钥不在工程或GitHub中，当前发布机默认路径为用户目录下 `.hxz-launcher-publish/update-ed25519.pem`，仅当前用户及SYSTEM可访问。也可用环境变量HXZ_UPDATE_SIGNING_KEY指定私钥文件。维护者应将其安全备份；丢失密钥后不能给已发布客户端签发新更新。脚本检查私钥与内置公钥匹配，缺失或不匹配则停止，不生成不安全的无签名更新。严禁把私钥放入客户端、发布附件或提交记录。

0.3.3及更早的客户端没有此次镜像逻辑；若旧版已无法连接GitHub，需要先手动安装一次0.3.4，之后使用新的多来源更新。客户端与社区服务端保持独立，社区服务端本次仅同步版本号，不要求玩家部署服务端。

镜像入口文档：[GHProxy](https://ghproxy.net/)、[GHFast](https://ghfast.top/)、[GH-Proxy](https://gh-proxy.com/)。当前网络实测GHProxy可返回本项目有效Release文件；另外两个入口探测超时，因此作为可自动跳过的备用来源，不声明全部站点已实测稳定。

## 验证

通过四项针对性检查：关闭自动更新与任务忙碌时不自动安装、下载失败固定版本换源、直连不可用及旧镜像缓存时选择新版、篡改签名/HTML/过大信息拒绝。类型与静态检查通过。实际Electron更新组件连接隔离HTTP服务，第一来源不返回任何数据，超时取消后第二来源完成下载并通过SHA-512，未执行安装程序。完整0.3.4桌面构建通过；未重复游戏、社区或整合包测试。
