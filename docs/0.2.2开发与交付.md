# 0.2.2 开发与交付

用户要求：通知公告中接入三个服各自的 HXZ UP 更新日志，严禁混淆；放宽语音房间区域；设置中保留 HXZ UP 默认弹窗，默认开启，关闭后沿用集成任务详情；个性化允许修改本人头像。

项目 E:/hxz_la。客户端与社区服务端仍独立运行/打包，不修改 HXZ UP 服务。HXZ UP 当前源代码实际在 E:/hxz_up/hxzup，E:/hxz/_up/hxzup 是旧的 1.0.1。已读取 HXZ UP 1.0.3 的 version.json / changelog.json 协议及原生窗口实现。

日志来源由管理员在独立社区后台为 survival、mod-1、mod-2 分别配置。固定白名单，拒绝相同根地址，不从当前实例猜测分组，不将镜像列表当作多个服。按组和完整地址缓存 30 秒，发布前后核对 version，维护中不给出混合日志。每组独立错误、来源显示、分组路由过滤。已向用户询问三个实际接入地址，未收到时保持未配置，不能猜测映射。

头像绑定皮肤站角色，客户端本地选择图片生成有界 PNG，小图同步社区并以版本 URL 获取，不把图片塞入在线广播。离线保留本地头像，下次连接同步。默认字头像可恢复。更新弹窗沿用已有 HXZ UP JAR：headless=false + showChangelog=true，等待其进程结束再继续启动游戏；关闭开关恢复 headless。每个实例是否自动更新仍独立。

0.2.2 已完成构建和独立打包，安装程序、便携 ZIP、服务端 ZIP、更新元数据和校验文件在 release/0.2.2。公开服务端 ZIP 在迁入真实 data/.env 前生成，确认不含运行数据，发布文件 SHA-256 已全部核对。旧服务停止后，逐文件校验复制 data 和 .env，新社区服务运行于 release/0.2.2/server/幻想镇社区服务端，端口8787，进程26044（工具会话77290），旧数据保留。不能把已部署目录重新压入公开 ZIP。未要求 GitHub 推送。


必要验证已完成：服务端分组与来源重新绑定、维护状态、重复地址拒绝；头像仅允许修改本人，图片格式与尺寸约束；独立后台、聊天与语音隔离回归。真实随包 HXZ UP 分别以无界面和原生窗口运行，通过 Windows 进程窗口确认弹窗显示，并验证开关对应 showChangelog 配置；维护返回后不启动游戏。打包桌面已验证三服日志路由互不混入、原生图片缩略处理/预览、头像同步到第二个客户端、语音实际音频、设置开关以及大字号布局。已修复原有图片策略拦截远程头像。截图位于 docs/screenshots/022-*.png。


语音区域增至约300–360px，房间和按钮间距增加。房间列表独立滚动，麦克风/收听/离开保留在列表外，防止大字号下操作按钮被挤出区域。

按最新截图反馈，将房间右侧人数横排为“2 / 8”，不再上下分行。最终安装包对应的桌面页面已验证同一行显示，22px 字号下没有横向溢出；深浅主题截图已更新到 docs/screenshots/022-community-*.png。
