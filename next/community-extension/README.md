# 幻想镇 0.6.0 直连联机扩展

这是社区服务端配套模块，**不放入启动器的 profile 或 Minecraft 文件夹**。用于房主授权、公开房间目录与公网探测，不转发游戏流量。

使用现有社区的 Node 环境运行：

```text
node install.mjs /实际的社区服务端目录
```

路径有空格时加引号。目标应包含 `src/server.mjs`；安装器检查接口位置，不匹配会停止。会备份入口文件，然后接入模块。重启社区服务后生效。管理员可在新版启动器“联机”页面下方授权成员创建房间。

首次运行只新增 direct_lobby_hosts、direct_lobby_audit 表，不重置既有账号、积分、排行榜或帖子。房间目录在内存中，90 秒无心跳移除。更新前保留正常的数据备份；需要回退时恢复入口备份并重启。

已在独立本机社区数据库验证，没有代替你操作公网服务。详细说明见压缩包中的 MC直连大厅.md。
