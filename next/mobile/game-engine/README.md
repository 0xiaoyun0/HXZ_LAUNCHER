# 幻想镇 Android 游戏运行组件 0.7.0

可选的 ARM64 原生游戏引擎。社区本体无需安装它也能正常使用聊天、语音、论坛和活动。组件通过同签名的本地权限接收幻想镇社区的三服安装与启动请求；应用身份为 top.hxzmc.gameengine。请勿使用第三方修改包接收账号令牌。

最低配合 Android 10 版本的幻想镇社区 0.7.0；手机运行大型 PC 模组属于实验功能。建议 Wi-Fi 和足够存储。不同 GPU、内存、加载器和模组组合可能无法启动；本次没有实体手机进服验证。卸载组件前备份组件内的游戏世界。

## 使用

1. 安装幻想镇社区并登录皮肤站。
2. 发现 → Minecraft → 运行提示，了解设备限制后启用。
3. 安装同版本 HXZ-GameEngine APK，或使用「下载运行组件」。系统仍会要求确认安装 APK。
4. 选择一个默认服务器，配置内存和启动前更新，然后「安装并进入」。支持仅安装及进入原生触控/渲染高级设置。
5. 组件数据与社区账号分开保存。社区只把当前登录令牌传给同签名组件的内存任务，不生成包含令牌的启动文件。运行期间仍使用正常皮肤站验证。

默认下载策略为官方优先、32 并发，失败使用相应镜像。HXZUP 将 1/ 实例文件和 3/ 共享游戏内容映射到此服私有目录，同名时 1/ 优先；0/、2/、4/、5/ 的桌面路径和清理规则被过滤。存档、截图、Java 运行库和版本元数据不被覆盖。三服配置来自现有社区后台；归档包模式需要先在引擎内导入，或由管理员改用 HXZUP 配置。

新增入口：com.tungsten.fcl.hxz.HxzBridgeActivity、HxzRunner，以及 up.hxz.AndroidPack 和适配的更新器。修改范围包括签名权限、私有实例目录、幻想镇账号桥、更新包映射、默认下载策略、品牌身份与构建配置。
