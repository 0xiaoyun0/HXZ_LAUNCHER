# 幻想镇 Android 游戏运行组件 0.7.0

2026-10-12 安卓安装适配修订：构建号 70003。实测设备为小米 Pad 8 Pro；交付至 `release/0.7.0/android/revision-70003`，使用现有运行组件更新通道分发。幻想镇社区本体保持 0.7.0，账号桥修订同为 70003，无需卸载或清空游戏数据。

可选的 ARM64 原生游戏引擎。社区本体无需安装它也能正常使用聊天、语音、论坛和活动。组件通过同签名的本地权限接收幻想镇社区的三服安装与启动请求；应用身份为 top.hxzmc.gameengine。请勿使用第三方修改包接收账号令牌。

最低配合 Android 10 版本的幻想镇社区 0.7.0；手机运行大型 PC 模组属于实验功能。建议 Wi-Fi 和足够存储。不同 GPU、内存、加载器和模组组合可能无法启动；实测范围详见 docs/0.7.0安卓适配修订.md。卸载组件前备份组件内的游戏世界。

## 使用

1. 安装幻想镇社区并登录皮肤站。
2. 发现 → Minecraft → 运行提示，了解设备限制后启用。
3. 首次使用选择「下载运行组件」；已安装组件的用户选择「检查组件更新」，下载完成后点击「安装组件更新」，按系统提示覆盖安装。请勿先卸载组件。此入口位于「发现 → Minecraft」，与「我的 → 应用更新」的社区本体更新分开。
4. 选择一个默认服务器，配置内存和启动前更新，然后「安装并进入」。支持仅安装及进入原生触控/渲染高级设置。
5. 社区通过同签名权限把所选账号导入 FCL 的正常账号存储；不生成包含令牌的临时启动文件或日志。运行期间仍使用正常皮肤站验证，更新/安装选项单独保存在不含令牌的实例配置中。

默认下载策略为官方优先、32 并发，失败使用相应镜像。HXZUP 将 1/ 实例文件和 3/ 共享游戏内容映射到此服私有目录，同名时 1/ 优先；0/、2/、4/、5/ 的桌面路径和清理规则被过滤。存档、截图、Java 运行库和版本元数据不被覆盖。三服配置来自现有社区后台；归档包模式需要先在引擎内导入，或由管理员改用 HXZUP 配置。

## 构建 70001 的安装适配

- 安装器日志统一写入应用私有外部目录。NeoForge/Forge 处理器根据游戏和主类字节码要求选择 Java；当前模组一服 1.21.1 使用 Java 21，不再依次盲试四个运行时。处理器内存上限 2 GB、最多 4 个计算线程，为界面和系统预留空间。
- 下载与安装使用前台任务和有时限的唤醒锁。安装日志增量读取，保留当前处理器、步骤、耗时和失败尾部；失败窗口可复制诊断。取消只结束安装器 JVM，不按包名前缀终止其他游戏进程。
- 有 SHA-1 的 FCL 文件下载接入桌面同源的下载引擎：官方优先、32 个连接、每节点最多五次尝试、永久错误换源、断点保留、校验后替换及低速切换。没有 SHA-1 的上游下载仍使用 FCL 流程，不能将其称为全部支持断点续传。
- 失败后保留已经下载的文件；完整任务成功后才记录安装完成。残留版本 JSON 不会再让下一次安装被跳过。模组检查缓存大小/修改时间，下载完整性和原生补丁启用仍进行内容校验。空闲下载线程 30 秒后释放。
- Forge/NeoForge 自动渲染在设备支持 Vulkan 时选择 Zink；用户明确指定的渲染器仍被保留。渲染器选择不是所有模组都兼容的保证。

## 模组兼容规则

规则只针对已检查过的具体 SHA-1，不根据中文文件名猜测。覆盖当前模组一、二服共 458 个不同模组文件的标识和必需依赖；后续整合包更换组件版本时需要重新核验对应规则。

| 组件 | 当前处理 |
| --- | --- |
| Voxy offline 0.2.15 beta | 此构建带桌面 x86 原生依赖，手机更新前跳过 |
| IMBlocker 5.5.4 / 5.6.1 | 桌面输入法接口，手机更新前跳过 |
| AcceleratedRecoiling 21.1.13 alpha | 此构建只有桌面 x86 碰撞加速库，手机保留原始碰撞实现 |
| Modern UI 3.13.0.1 | 仅 GL4ES / NG-GL4ES 模式跳过；Zink / VirGL 保留 |
| Sable 2.0.3 与航空学 | 保留服务器玩法模组，加入此精确构建的 ARM64 原生适配补丁 |

在下载文件前过滤已知不适用组件；已经存在的对应文件备份至实例的 `updater/android-compatibility`，报告为 `report.json`。规则或渲染器不再要求禁用时可恢复原文件。发现保留的模组必需依赖被禁用组件时停止并报告，不连带删除玩法模组。尚未知晓的模组不会被笼统禁用；这也意味着不能保证未来任意包体均可直接运行。

Sable Java 适配器来自 [sable-android-patch 2.0.3](https://github.com/sa1672ndo/sable-android-patch/releases/tag/2.0.3)，MIT 许可。替换了其中原生库，使用 [SableRapierPlugin 2.0.3](https://github.com/ZalithLauncher/NativeLibPlugin/releases/tag/sable_rapier-0.1.0_NDK_BUILD) 中的 ARM64 构建；[对应原生源码](https://github.com/MovTery/sable_rapier_android) 为 Apache-2.0。保留许可和修改说明，`repack-sable.py` 可重建该资产。核对了当前 Sable 的 53 个 JNI 导出名称与 16 KiB ELF 段对齐；这些静态检查不等于实际游戏兼容性认证。

已通过原生 APK 编译及定向本机 JVM 检查：断流续传、404 换源、UTF-8 日志、完成记录、更新前过滤、备份恢复、必需依赖保护、HXZUP 目录映射，以及实际两服清单的规则核验。70003 还验证了用户所报 Nashorn 超时的换源路径、实际认证提供器和 HXZUP 更新门控。实体平板已确认账号/皮肤导入、皮肤站验证、HXZUP 同步，并用系统 Vulkan 越过内置驱动的窗口初始化失败；进服与内存相关的最终结果见适配修订文档，不将单台设备结果推广到所有设备。
