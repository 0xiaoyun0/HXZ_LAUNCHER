# 幻想镇社区 Android 数据说明

应用向玩家选择的社区服务及幻想镇皮肤站发送完成登录、聊天、论坛、蓝图和公告操作必需的数据。默认社区为 https://qqbot.hxzmc.top，皮肤站为 https://skin.hxzmc.top。

登录密码只在本次认证时发送给皮肤站，不落盘。刷新凭据存放在应用私有目录，通过 AndroidKeyStore 加密；社区会话不写入日志或下载地址。退出登录清除本地凭据。账号的聊天、发帖和活动进度由社区服务按原有规则保存。

麦克风只在用户主动加入语音、授予权限后使用。音频由社区 WebSocket 实时转发，不在客户端录音或保存；离开房间、退出账号或结束应用会释放麦克风。传输使用 HTTPS/WSS，此通话不宣称端到端加密。

头像及蓝图由系统文件选择器授予单文件访问。应用不扫描手机文件，不请求全部文件存储权限。下载文件经校验后由用户选择保存位置。音频及页面缓存、消息列表均设置大小或数量上限。

音乐文件只读取用户通过系统选择器选中的内容。使用网易云搜索、公开歌单导入或在线播放时，向网易云发送查询和歌曲 ID，不携带皮肤站或社区凭据。仅在用户主动分享播放器时，将播放器音频编码后通过当前社区语音频道发送给频道成员；进入后台停止分享。联机大厅列表和授权使用现有社区身份，安卓版不建立 Minecraft 游戏连接。

获社区管理员授权的用户，可在阅读说明并同意后登录自己的网易云账号。登录使用网易云官方页面；该服务的 Cookie 保存在设备本地，并绑定当前社区身份，不传给社区管理员或其他用户。获取歌曲播放地址时，只向网易云发送所需登录状态，实际可播放内容由账号、会员和版权权限决定。用户可随时退出网易云账号；撤销社区授权会停止该功能。社区只存储授权名单，不保存网易云密码或登录 Cookie。

应用不包含广告、分析 SDK 或追踪服务。不提供游戏启动、游戏资源下载或 Minecraft 账号启动功能。需要系统提供的 Android System WebView；建议保持系统 WebView 更新。

应用更新默认在启动或返回前台时定期访问GitHub及其镜像（gh-proxy.com、ghproxy.net、ghfast.top），发送普通更新请求，不附加账号凭据。可在“我的 → 应用更新”关闭自动检查及自动下载。安装包仅缓存在应用私有缓存目录，失败或取消时清除临时下载。应用请求安装来源权限以调用Android系统安装确认，不能绕过系统授权。
