# 幻想镇社区 · Android 0.8.0

本版增加社区工作台与场景入口、好友小队、玩家空间、作品共建、知识建造、活动赛事、B 站一起看、棋局回放与社区桌面组件。完整更新见 [0.8.0 发布说明](../docs/0.8.0发布说明.md)。

内部版本 80000。最低 Android 10（API 29），目标 API 35。保留 top.hxzmc.community 应用身份与固定签名，可覆盖旧版并保留账号与设置。Minecraft 由可选的独立 ARM64 游戏组件运行，社区功能无需安装该组件。

## 界面与功能

手机底部为聊天、社区、发现、公告、我的五项，平板使用侧边导航。聊天／语音、论坛／蓝图通过左侧悬浮图标切换，长按可移动且分别记住位置。统一卡片、主题、字号、透明度和轻量动效；应用选择框与确认窗采用统一弹层，系统权限与文件选择仍使用系统界面。

- 皮肤站登录、角色切换、内嵌账号管理、头像与在线设备状态。
- 文字聊天、日期和分组、Emoji／颜文字、图片/GIF、最多 100 张收藏表情、历史范围与最新消息定位。普通聊天附件保留 30 天。
- 原生 Opus 语音、后台可配置房间和容量、静音、收听、按住说话、设备路由和前台通话通知；增加低频过滤、限幅、静音包抑制及有界缓冲。
- 论坛发帖、嵌套回复、点赞与排序；机械动力蓝图上传、筛选、审核和下载。
- 分服公告、HXZ UP 日志、反馈与管理员处理、账户积分、收支、兑换及商城。
- 十八款小游戏、棋类联机／机器人／观战、排行榜；共享既有服务端规则。
- 音乐库、网易云搜索与公开歌单导入、不可播放曲目自动跳过、现有语音频道一起听。
- MC 联机房间目录、邀请复制和管理员开房授权管理；手机不创建 Minecraft 世界。
- 发现 → LINKING：章节目录、档案探索、任务与活动管理；使用新活动入口和进度，不复用旧彩蛋。
- 冒险家协会、统一委托、凭证图片、积分/背包材料托管与游戏内道具收货；账号页提供背包、权限时长和可信服务器统计。

普通音频、常见 NCM 和旧 QMC v1 可导入，单曲不超过 50 MB；不支持所有新版 QQ／汽水加密缓存。新增同步歌词和跨页歌词底栏。管理员可授权个人网易云账号，用户同意风险后在官方页面登录，凭据仅保存在本机；按会员与版权权限提供音频。音乐切换页面继续播放，进入后台暂停音乐和分享；语音由原生前台服务管理。

## 架构

Vue 3 与本地打包资源负责界面；原生 Java 负责账号加密、HTTPS/WSS、文件选择、音频解码与通话。背包、聊天附件、限时权限和新委托流程需要配套 0.8.0 社区服务端，不需要清空社区数据，也无需另装扩展。保留收件箱、输入 @ 候选、点赞收藏提醒和默认服在线名单。

发现 → Minecraft 可下载同签名游戏组件，读取社区后台的三服配置、幻想镇皮肤站账号及 HXZ UP 配置。组件采用独立应用 ID，账号令牌只通过受签名保护的本地调用传入内存。沿用已发布的游戏组件 0.7.0 / 70003，属于实验功能；设备性能、GPU 和电脑模组兼容性会影响结果。完整修改源码、GPL 许可及构建说明见 [游戏组件](game-engine/README.md)，随 Release 提供源码归档。

凭据由 AndroidKeyStore 加密保存。音频不录音落盘，分享播放器不会自动取消麦克风静音。更新清单有签名，APK 检查哈希、长度、包名、版本和同证书；安装仍需要 Android 系统确认。

## 构建

需要 Node.js 22.12+、JDK 21、Gradle 8.7+ 和 Android SDK 35（本版使用 Gradle 8.14.4 构建）。

1. 仓库 next 目录执行 npm ci；apps/linking 中执行 npm ci，返回 next 运行 npm run linking:build；再在 mobile/web 执行 npm ci 和 npm run build。
2. 设置 JAVA_HOME 与 ANDROID_HOME，在 mobile/android 执行 gradle assembleDebug。
3. Release 设置 HXZ_ANDROID_KEYSTORE、HXZ_ANDROID_STORE_PASSWORD 为原有私有签名配置，再执行 gradle assembleRelease lintRelease。不要生成新密钥替代正式密钥。
4. 输出 mobile/android/app/build/outputs/apk/release/app-release.apk。每次正式 Android 发布必须提高 versionCode。

共享代码位于 ../../packages/mobile-ui 和 ../../packages/community；不要单独复制 mobile 后构建。签名更新清单使用 tools/SignAndroidUpdate.java，密钥只通过环境变量读取。
