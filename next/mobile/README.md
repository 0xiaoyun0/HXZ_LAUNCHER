# 幻想镇社区 · Android 0.6.2

内部版本 60201，最低 Android 10（API 29），目标 API 35。保留 top.hxzmc.community 应用身份与固定签名，可覆盖旧版并保留账号与设置。仅提供社区功能，不在手机运行 Minecraft。

## 界面与功能

手机底部为聊天、社区、发现、公告、我的五项，平板使用侧边导航。聊天／语音、论坛／蓝图通过左侧悬浮图标切换，长按可移动且分别记住位置。统一卡片、主题、字号、透明度和轻量动效；应用选择框与确认窗采用统一弹层，系统权限与文件选择仍使用系统界面。

- 皮肤站登录、角色切换、内嵌账号管理、头像与在线设备状态。
- 文字聊天、日期和分组、80 项 Emoji／颜文字、历史范围与最新消息定位。
- 原生 Opus 语音、20 人房间、静音、收听、按住说话、设备路由和前台通话通知。
- 论坛发帖、嵌套回复、点赞与排序；机械动力蓝图上传、筛选、审核和下载。
- 分服公告、HXZ UP 日志、反馈与管理员处理、账户积分、收支、兑换及商城。
- 九款小游戏、棋类联机／机器人／观战、排行榜；共享既有服务端规则。
- 音乐库、网易云搜索与公开歌单导入、不可播放曲目自动跳过、现有语音频道一起听。
- MC 联机房间目录、邀请复制和管理员开房授权管理；手机不创建 Minecraft 世界。
- 保留活动进度与入口：我的页版本行连续点按七次。

普通音频、常见 NCM 和旧 QMC v1 可导入，单曲不超过 50 MB；不支持所有新版 QQ／汽水加密缓存。新增同步歌词和跨页歌词底栏。管理员可授权个人网易云账号，用户同意风险后在官方页面登录，凭据仅保存在本机；按会员与版权权限提供音频。音乐切换页面继续播放，进入后台暂停音乐和分享；语音由原生前台服务管理。

## 架构

Vue 3 与本地打包资源负责界面；原生 Java 负责账号加密、HTTPS/WSS、文件选择、音频解码与通话。使用现有社区协议，不需要迁移或清空社区数据。升级使用一个完整 0.6.2 社区服务端，无需另装扩展。新增收件箱、输入 @ 候选、点赞收藏提醒和默认服在线名单。

凭据由 AndroidKeyStore 加密保存。音频不录音落盘，分享播放器不会自动取消麦克风静音。更新清单有签名，APK 检查哈希、长度、包名、版本和同证书；安装仍需要 Android 系统确认。

## 构建

需要 Node.js 22.12+、JDK 21、Gradle 8.7 和 Android SDK 35。

1. 仓库 next 目录执行 npm ci，再在 mobile/web 执行 npm ci 和 npm run build。
2. 设置 JAVA_HOME 与 ANDROID_HOME，在 mobile/android 执行 gradle assembleDebug。
3. Release 设置 HXZ_ANDROID_KEYSTORE、HXZ_ANDROID_STORE_PASSWORD 为原有私有签名配置，再执行 gradle assembleRelease lintRelease。不要生成新密钥替代正式密钥。
4. 输出 mobile/android/app/build/outputs/apk/release/app-release.apk。每次正式 Android 发布必须提高 versionCode。

共享代码位于 ../../packages/mobile-ui 和 ../../packages/community；不要单独复制 mobile 后构建。签名更新清单使用 tools/SignAndroidUpdate.java，密钥只通过环境变量读取。
