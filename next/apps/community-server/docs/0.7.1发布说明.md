# 幻想镇 0.7.1

本次更新基于 0.7.0，重点修复小游戏、公会交付和跨页卡片，并调整 MC 联机方式。

## 小游戏

- 重新整理全部 15 个小游戏的普通模式、专注模式及手机横屏布局；修复棋盘拉伸、操作区被挤出、文字和素材重叠。游戏区按可用空间等比缩放，手机保留摇杆、按钮及适用的手势操作。
- 暂停、结算与升级选择使用独立浮层；选择增益时暂停战斗，窄屏可滚动，不挤动下方页面。
- 苍穹航线的长期增益从 6 种扩展到 24 种，新增追踪、穿透、连锁、护盾、维修、资源回收等组合；提高后期敌人的压力。
- 打砖块随机增益从 3 种扩展到 9 种，新增强击、爆破、金币、导引、破钢及恢复；保留三次机会和每五关恢复机制。
- 三种棋类改用有独立进程预算的成熟搜索引擎，保留五档难度。玩家落子立即确认，机器人在后台计算；联机落子、观战和房间变化实时通知，轮询作为断线补偿。
- 修复狼人杀离开房间后无法正常再次创建的情况。新规则与旧客户端的成绩校验按版本区分。

## 冒险者公会

- 展示接取、进行、提交、补充和完成步骤；凭证图片支持预览、移除，补充材料自动保留原内容。
- 接取、撤回和结算加入明确确认；撤回后可以重新接取，已提交待验收时不能绕过审核撤回。
- 实物奖励需发布者确认交付；积分托管、支付和退款防止重复结算。弹窗中的错误显示在当前操作旁。

## 联机与卡片

- MC 房间优先使用 IPv4/IPv6 公网直连，不可达时尝试 WebRTC P2P；支持多人进入同一个房主世界。取消社区游戏流量中继，社区只负责授权、目录和信令，语音转发不受影响。
- 修复首页游戏实例右键菜单偏离点击位置和宽度过窄的问题；随字号适配，靠近窗口边缘时自动避让，支持键盘打开。
- 修复卡片跨页移动后的内容登记、鼠标释放位置和布局保存，保留原功能、尺寸、锁定及隐藏设置。

Windows x64、ia32 与 Android 社区同步为 0.7.1；Android 内部构建号 70100。配套社区服务端也需升级为 0.7.1。可选 Android 游戏组件沿用已发布的 70003 修订，不重复下载未变化的组件。
