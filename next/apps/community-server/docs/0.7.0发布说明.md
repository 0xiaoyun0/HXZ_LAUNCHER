# 幻想镇 0.7.0

本版基于 0.6.4，新增冒险者公会、通用卡片、跨页整理、可信游戏统计与社区服务自更新；完善新 LINKING 档案馆。

## 游戏与下载

- 保持官方源优先、默认 32 并发。补充经过路径核对的官方备用域名和公共镜像。临时连接失败单节点最多尝试五次，再换其他来源；404 等确定不可用的地址立即跳过。
- 大文件最后一段失败后保留已完成分段，继续传输剩余部分。持续低速时切换来源，实际下载仍在前进时不按整包耗时强行终止。失败后可以继续任务。
- 内置散列匹配的 Minecraft 常用日志配置。未知 log4j2 配置暂不可下载时，使用安全的本地日志配置，继续记录 latest.log，避免被日志配置卡住启动。
- 实例卡片支持右键直达详情、配置、模组及文件夹。
- 游戏运行且启动器失焦后进入低资源模式，卸载页面和三维场景、暂停背景视频；语音、音乐及下载继续。返回窗口自动恢复，可在设置关闭。
- HXZ UP 更新窗口采用统一卡片布局，显示真实步骤、文件数、字节、速度和日志；大字号保留操作区。

## 社区与活动

- 冒险者公会：玩家发布委托、上传图片、管理员审核、认领、提交凭证、验收与积分结算。积分委托先从委托人余额托管，拒绝或撤销按规则退还；道具承诺由双方在游戏内交付。
- 管理员可发布主线任务，作为 LINKING 档案的解锁条件。主线奖励计入当周获得积分；玩家间转账不重复增加榜单积分。
- 新 LINKING 自适应填满可用空间，完善中文文案、入口图标和入场动画，保留档案阅读、任务进度和管理员编辑入口。
- 默认增加一起听歌房间。后台可配置 1–24 个房间、每房间 2–50 人；关闭房间会通知成员退出。
- 语音增加低频过滤、峰值限幅、静音包抑制和有界播放缓冲，减少爆音、排队延迟与无效传输。
- 修复积分商城图片上传，手机支持文件选择；商品封面按可见区域加载，并限制并发及缓存。
- 可信游戏统计通道：各服务器使用独立令牌，上报原版统计、成就及约定指标。账号页可以查看三服记录，活动可使用阈值解锁。随包提供只读统计采集器。
- 后台按业务分组，增加公会审核、语音房间、游戏统计与服务更新。小游戏目录和数量随实际清单生成。

## 卡片与手机界面

- 编辑模式中跨页面拖动卡片，提供目的地提示、落点动画和移回入口。保持原有自动尺寸、缩放、隐藏、锁定、对齐、撤销及个性化保存。
- 新增便利贴、时钟、日历、搜索和小助手卡片；内容与配置仅在编辑模式修改。
- 新增首次使用引导，可在设置重新查看。
- 完善桌面和手机页面切换、载入及操作动效，遵循关闭动画与系统减弱动态效果。
- 手机小游戏专注模式依据剩余空间适配画布，保持比例；适用游戏可切换摇杆，失焦和触控取消会释放按键。完善小屏棋盘和文字排布。

## Android 游戏运行组件

Android 社区中新增 Minecraft 入口，可安装独立 ARM64 游戏组件；基于固定版本的 FCL 原生运行环境，包含 Java 8/17/21/25、加载器安装、触屏与渲染设置。默认三服使用社区后台配置，支持幻想镇皮肤站登录、HXZ UP 更新及自动进入服务器。社区 APK 和游戏组件 APK 分别安装，使用同一发行证书验证调用身份。

此组件为实验性接入。已完成原生编译与接口、手机尺寸模拟检查，尚未在实体手机实际进入三服。电脑大型模组及某些 GPU/Java 组合可能无法运行。下载前会显示风险提示；可调整内存、渲染器和自动更新，先仅安装再调试。社区功能不要求安装游戏组件。

## 服务端升级

首次从旧版升级，请备份整个 data 与 .env，使用 0.7.0 的启动脚本启动新版服务。此后后台可自动检查签名更新，在指定时间备份并安装；新服务启动失败会恢复旧程序及数据库。自动安装默认关闭，自动检查默认开启。

游戏统计需要在三个 Minecraft 服务端分别配置采集器。新公会、LINKING 条件及可配置语音房间需要配套 0.7.0 社区服务端。详细操作见《0.7.0部署与验收》；本地交付不会修改现有线上数据库。
