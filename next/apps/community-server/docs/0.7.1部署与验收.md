# 0.7.1 部署与验收

## 玩家升级

Windows 安装版沿用原有签名自动更新通道，x64 和 ia32 清单分开。便携版退出后更新完整目录，保留 profile 和原游戏目录。Android 版本号 0.7.1、内部构建号 70100，继续使用原应用身份和签名覆盖安装。Android 系统仍会要求确认安装。

本轮 Android 社区界面与棋类同步已更新；可选游戏运行组件仍为 0.7.0 / 70003，更新入口保持原有签名清单和原发布地址，不会将组件降回早期 70000 版。

## 社区升级

已有 0.7.0 supervisor 的管理员可用后台「服务维护 → 服务更新」安装签名更新。完整部署只需 HXZ-Community-0.7.1-windows-x64.zip；update.zip 是后台自动更新程序使用的包，无需部署第二个服务端。

手动迁移须先停服，备份整个 data 和 .env，再复制到新程序目录；使用 HXZ_DATA 外部路径的保持原值。不要单独复制正在写入的 SQLite 文件，不要清空积分、榜单、账号或公会数据。本版不要求重建数据库。Linux 使用源码包内 next/apps/community-server，Node.js 24+。

反向代理必须放行 /ws 和 /lobby-signal 的 WebSocket Upgrade；同包 nginx-community.conf.example 已更新。/lobby-signal 只传握手，MC 中继 /lobby-relay 已关闭并返回失效提示。社区语音仍复用原通道。旧客户端需要先更新后才能使用新的 P2P 房间。

P2P 不是所有网络均可穿透：双方 UDP 受限或特殊 NAT 下仍可能失败，此时使用可达公网 IPv4/IPv6 或自行配置的虚拟局域网。项目不提供 TURN 游戏中继，也不会静默开放系统防火墙。手机社区可查看目录和复制邀请，本版 MC P2P 运行端为 Windows。

## 棋类引擎与资源

社区包含 shared/engines/maid 下的可执行搜索模块及完整源码、许可证和构建说明。无需在社区服务器安装 Java；搜索运行在独立 Node 子进程，有内存与时间预算。不要删除该目录。来源和许可证见 third_party/maid-board-engine/README.md。

## 验证范围

- 桌面类型检查、生产资源、x64 / ia32 安装器与便携包，以及 Android release 签名构建通过。
- 全部 15 个游戏已在桌面和模拟手机尺寸检查普通/专注布局，并检查适用的横屏、棋局、暂停与升级弹层；这不能代替 Android 实机触控和 GPU 验收。
- 本地隔离社区验证公会凭证上传、补充、交付、积分结算、棋类规则与异步机器人，以及跨页卡片拖动和刷新持久化。
- Electron 44 x64 / Electron 22 ia32 原生 P2P 已在本机两客人并发传输中校验数据和背压；尚未在不同运营商网络、实体 Win7 或全部机型上验收。
- 测试未操作公网社区、真实用户 profile 或 Minecraft 存档。

发布后优先检查：社区原有榜单/余额是否保留；两处不同网络的联机可达性；手机小游戏横竖屏操作；管理员委托结算。出现 P2P 不可达时以网络检查结果为准，不承诺无公网条件一定成功。
