# 社区工作台接口 · 0.8.0

继续使用现有社区 Bearer 会话。每次读取和修改由服务端验证可见性、成员角色与管理员身份，客户端隐藏按钮不能替代鉴权。以下为接入索引，字段定义以对应模块及共享 hub-catalog.mjs 为准。

| 入口 | 方法与用途 |
| --- | --- |
| /api/hub/catalog | GET 功能类型、服务器分组与管理能力 |
| /api/hub/desk | GET 本人办事汇总；category=action/waiting/progress/done，offset 分页，每页 24 项；只聚合原流程，不提供另一个办结写接口 |
| /api/hub/workbench | GET 管理员审核队列；普通成员禁止访问 |
| /api/hub/social、members | GET 社交概况、可选成员；查询只返回允许公开的字段 |
| /api/hub/profile、preferences | PUT 玩家空间与通知偏好 |
| /api/hub/friends、teams、teams/:id | 好友和队伍关系操作；校验邀请状态与屏蔽关系 |
| /api/hub/saved、letters | 分类收藏、发送与查看本人时光信 |
| /api/hub/records | GET 分页筛选；POST 新建；草稿与已发布内容分离 |
| /api/hub/records/:id | GET 详情；PUT 编辑并携带 revision |
| /api/hub/records/:id/:action | 审核、归档、报名、成员、项目等受限动作；不可通用执行任意方法 |
| /api/hub/records/:id/discussion | POST 为已发布作品关联论坛主题；重试返回同一主题 |
| /api/hub/records/:id/reply | POST 私密申诉沟通，携带 revision、requestId 和 body；仅本人/管理员 |
| /api/hub/events/passport | GET 活动足迹；保留已有内部路径，界面不再称护照 |
| /api/hub/production | POST 递归生产计算；只能引用有权读取的配方 |
| /api/hub/knowledge、knowledge/export | GET 已发布知识检索与有界离线正文 |
| /api/hub/devices、handoffs | 本人设备、接续与待办；下载必须由目标电脑确认 |
| /api/hub/trades、trades/:id/buy、trades/:id/close | 托管、成交与撤回；服务端事务结算 |
| /api/hub/media/resolve | POST 解析 B 站标识/短链接；不接收任意站点代理请求 |
| /api/hub/media/rooms | GET 房间目录；POST 创建放映 |
| /api/hub/media/rooms/:id/:action | join、leave、control、queue、vote、next、remove；主持权限与版本冲突校验 |
| /api/blueprints/:id/materials | GET 已授权蓝图方块参考，懒加载旧 NBT 元数据；不增加下载计数 |
| /api/board-workshop | GET 公开棋局与本人可分享的已结束对局；POST 明确分享 |
| /api/board-workshop/:code | GET 验证后回放；作者/管理员 DELETE 撤回 |
| /api/boards | POST 可附 challenge 与 ply 创建不计分练习；沿用已有棋类规则 |

写入重试使用同一 requestId，新的用户操作使用新的值。编辑使用服务端返回的 revision，409 后重新读取，不盲目覆盖。读取和修改分别限频，429 应退避；客户端切页、隐藏时停止无用轮询。401 重新验证会话，403 不绕过权限，404 不再重试已删除资源。

公开记录、个人私密记录和成员记录严格分离。申诉内容不能通过邀请成员公开；账本条目是管理员发布的说明，不等同于玩家积分余额。普通转账/交易不重复增加榜单成绩。作品讨论复用论坛审核，隐藏主题不会因再次请求关联而自动恢复。

B 站媒体由官方播放器加载，社区只同步节目与进度，不代理或破解视频。b23 解析有主机白名单、重定向与超时上限。屏幕分享使用独立、同房间受限信令与 P2P，不能用工作台接口转发任意二进制数据。

游戏桥使用独立服务器凭据，见源码 game-bridge.mjs、game-telemetry.mjs 以及主文档《0.8.0游戏服务端桥》。官网不得把游戏桥令牌或管理员会话下发给访客。
