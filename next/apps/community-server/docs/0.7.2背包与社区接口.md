# 0.7.2 背包、委托与聊天附件

沿用社区 Bearer 会话，管理员接口另需管理员权限。积分使用十进制字符串，数量为整数；时间为 Unix 毫秒。返回 400 表示参数/当前业务状态不满足，403 为权限不足，409 为并发编辑冲突。错误体为 `{error}`。

## 背包与权限

| 接口 | 输入 / 返回 |
| --- | --- |
| GET /api/inventory | items（不可变发放快照、quantity、batches）、mail、grants、permissions、serverTime |
| POST /api/inventory/use | `{batch,requestId}`；返回 permission、expires 和新背包。相同用户及 requestId 重试不重复消耗 |
| POST /api/inventory/claim | `{id}` 邮件附件；重复领取不重复入账 |
| POST /api/inventory/redeem | `{code}`；每个兑换码每人一次 |
| GET /api/admin/inventory | 道具定义、兑换码、权限列表、可选成员 |
| POST /api/admin/inventory/items | 新建不传 id；编辑携带 id、updated。title、description、image、kind、commission、enabled；voucher 另含 permission、unit、duration |
| POST /api/admin/inventory/mail | `{item,quantity,title,recipients,requestId}`；1–500 人，作为待领取附件邮寄 |
| POST /api/admin/inventory/codes | `{item,quantity,code,starts,expires,maxUses}`；另可用 `{id,enabled}` 开关 |

kind 为 material、collectible、voucher；permission 为 lobby.host、music.netease；unit 为 days、months。同权限的未使用凭证跨物品定义合计最多三张。领取/兑换超过容量时保持原邮件或兑换机会。既有永久权限与限时权限分别保存。

商城 `/api/admin/shop/items` 可设置 inventory_item、weekly_stock、user_limit、user_period（week/month）。默认两种凭证单价100，全局每周库存3，个人每周/每月1；购买入背包，用掉时才开始计时。管理员修改过的商品不由重启重置。

## 委托

GET /api/guild 的 scope 支持 public、accepted、published、mine、review（管理）；q、status、offset 可筛选。列表返回 stats、inProgress、wallet。

POST /api/guild 提交 `{requestId,title,description,rewardType,reward,images,funding}`。rewardType 为 points、items、inventory、none；inventory 的 reward 是 JSON 字符串 `{item,quantity}`。funding=admin 需管理员权限，否则使用个人积分余额。所有新委托先审核。

委托路由 `/api/guild/:id/review|accept|submit|resolve|receipt|withdraw|cancel`：审核、接取、提交说明/图片、验收、收货、放弃接取、撤销。resolve 的 approved 必须为布尔值；退回需 note。游戏内道具需 delivered=true 后进入 delivery，由接取人调用 receipt `{received:true}` 才完成。普通用户不能自行撤销已被接取的委托。背包物品由系统托管和邮件交付。

## 聊天附件

- POST /api/chat-media/upload：`{image: dataURL}`。PNG/JPEG/WebP/GIF，8 MB/张；有尺寸、帧数和账户空间限制；返回图片 id、mime、width、height、size。
- POST /api/chat/send：`{body?,attachments?:id[],requestId}`。最多1000字、4张图；有文字或图片即可。幂等返回 `{message}`，并通过已有 WebSocket chat 事件广播。
- GET /api/chat/stickers：收藏列表；POST/DELETE 同路由 `{id}` 收藏或移除，最多100张。
- 消息 attachments 每项有服务端生成的 url；过期项仅有 expired=true。客户端直接使用生成的链接，不拼接可猜测的收藏访问令牌。
- 普通消息的图片链接保留30天；收藏保留文件，旧消息仍按期过期。未发送上传与已无引用文件由后台清理。Nginx 推荐 client_max_body_size 12m。

图片不接收 SVG 或任意远程URL；物品/商品图片仍经 `/api/media/upload` 的 PNG 转换上传。发布包同时更新网页后台与 shared 资源。
