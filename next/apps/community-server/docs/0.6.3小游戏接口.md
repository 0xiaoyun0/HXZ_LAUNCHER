# 0.6.3 小游戏接口

沿用社区 Bearer 登录、封禁、限流。旧街机规则 2/3/4 保留，新规则为 5。新增 ID `contra`、`garden`，沿用 `/api/arcade` 局次、输入重放及结算接口，不接受直接申报分数。

| 请求 | 用途 |
| --- | --- |
| GET /api/werewolf | 房间列表及是否已加入 |
| POST /api/werewolf | `{title}` 创建六人房 |
| GET /api/werewolf/:id | 本人可见状态，须先加入 |
| POST /api/werewolf/:id | `{action, ...}` 操作 |

`action`：`join/leave/ready/start/chat/act`。房主 `start` 可传 `fillBots:true`，真人需准备。`chat` 传最多 300 字的 `text`。`act` 传当前 `turn`、`target`，女巫可传 `choice:heal/poison/skip`。过期 turn 拒绝，超时跳过。

`players` 结束前不含其他角色，`me` 仅含本人角色、行动类型、目标、查验及药剂。狼人知道同伴，其他角色不可获取。讨论/投票阶段仅存活玩家发言，准备/结束阶段成员均可发言。

六名真人才计联机积分；胜者沿用每人每周联机获胜合计最多 1 分，每局仅结算一次。机器人练习不发联机积分，不改变周榜/总榜规则。

房间在进程内存中，重启不恢复，已结算积分仍在原数据库。客户端每两秒刷新；断开不会替真人行动，超时跳过。重启部署前应告知对局玩家。
