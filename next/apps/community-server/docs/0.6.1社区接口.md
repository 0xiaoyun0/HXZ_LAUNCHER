# 0.6.1 社区增量接口与部署

基于原社区服务端升级，停止服务后先备份整个 data、.env。不要删除 community.sqlite、session.key、商城/积分表、原活动配置。新表由程序首次启动创建，不需要运行清库脚本。完整发布包已包含所有模块，不再另装扩展。

除公开服务器状态外，以下接口使用既有 Bearer 社区会话；admin 路径在服务端校验管理员身份。账号令牌不要放入 URL。

| 接口 | 用途 |
| --- | --- |
| GET /api/inbox?before=ID&unread=1 | 本人收件箱，每页40条，返回 items/more/unread |
| GET /api/inbox/unread | 本人未读数 |
| POST /api/inbox/read | `{id}` 标记一条，`{all:true}` 标记本人全部 |
| GET /api/members/search?q=NAME | 按玩家名搜索提及候选，最多30条 |
| POST /api/admin/inbox/send | `{id,title,body,recipients:[uid]}` 或 `{id,title,body,all:true}`；操作 id 应保持不变以安全重试 |
| GET /api/admin/inbox | 管理员发送审计记录 |
| PUT /api/forum/posts/:id/favorite | `{enabled:true/false}` 收藏/取消 |
| PUT /api/blueprints/:id/like 或 favorite | `{enabled:true/false}` 点赞/收藏公开蓝图 |
| GET /api/chat/history?around=ID | 定位旧消息前后最多80条；删除内容返回404 |
| GET /api/forum/posts/:id?reply=UUID | 定位指定回复所在页，返回真实 offset |
| GET/POST/PUT /api/admin/rewards | 活动码列表/创建/停用，创建字段 code、amount（正整数字符串）、starts/expires（毫秒时间戳）、perUserLimit（默认1，0不限）、maxUses（0不限）；PUT为id/enabled |
| POST /api/points/redeem | 沿用原 `{code}`；兼容旧单次码与新活动码 |
| GET /api/music/access | 当前用户的 allowed/admin；管理员默认有权 |
| GET/POST /api/admin/music | 授权名单，POST `{uid,enabled}` |
| GET /api/server-online | 三服独立状态，30秒缓存；players 是服务器提供的样本，不能保证完整 |
| GET/PUT /api/admin/server-online | 三个 id 为 survival/mod-1/mod-2，items中配置name/address/enabled |
| GET /api/lobby/relay | 中继启用状态和房间流量限制 |
| GET/PUT /api/admin/lobby/relay | `{enabled,kbps}`，每房间双向总带宽，默认256KB/s，可64–4096KB/s |

新增 WebSocket 事件 inbox-changed、music-access-changed，客户端收到后重新读取对应数据。点赞/收藏撤销后重新添加不重复发送通知；对自己的操作不通知自己。已删除或被管理的帖子、回复与聊天消息会使收件箱相关正文脱敏。

`/lobby-relay` 复用社区 HTTP/HTTPS 监听器的 WebSocket Upgrade，不另开游戏中继端口。首帧传送会话，房主需既有开房授权。后续会话采用邀请码证明、固定证书的 TLS 端到端通道，社区只转发加密数据。每房间限制32连接、全局256连接，发送队列有上限。管理员关闭中继立即断开已有中继；直连不受影响。按示例 nginx 的 `location /` 转发 WebSocket 可覆盖 `/ws` 和 `/lobby-relay`。如果现网只为 `/ws` 配置 Upgrade，需为 `/lobby-relay` 同步配置。

网易云登录凭据不经过此服务端。名单授权不等于歌曲版权或会员授权。桌面为各社区身份隔离持久会话，安卓把设备中的音乐站点会话绑定至当前社区身份；退出清理音乐会话。
