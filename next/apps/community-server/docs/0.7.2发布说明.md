# 幻想镇 0.7.2

本次新增与修复相较于 0.7.1。

- 冒险者公会更名为冒险家协会，统一使用委托。概览、进行中与委托广场保留可整理卡片，广场默认占满主区域；点击委托后集中展开详情与交付操作，桌面使用宽弹窗，手机使用详情页。关闭或返回后保留筛选与浏览位置。积分托管、补交凭证和双方确认游戏内道具交付形成完整流程。
- 新增账号背包：材料、收藏品、权限凭证、物品兑换码和邮寄附件。管理员可设置图片、可用于委托的材料及限时权限商品。
- 商城默认提供 100 积分的联机开房三天凭证、网易云登录一个月凭证，各每周限量三张；每位玩家分别每周、每月限购一张。同类凭证最多持有三张，购买后存入背包，主动使用时开始计时。既有永久授权保留。
- 聊天支持 PNG、JPEG、WebP、GIF，每条最多四张、每张最多 8 MB。可收藏最多 100 张表情；收藏表情收入统一表情栏，图片按钮与表情按钮相邻且样式一致，待发送预览限制为 64 像素。普通聊天图片保留 30 天，收藏的表情继续保留。
- 新增语音屏幕覆盖，进入语音频道后显示正在说话的伙伴。Windows 新增独立游戏内聊天窗口和可编辑快捷键；退出语音、停止音乐、收回歌词均可快捷操作。
- 游戏启动后可选择最小化、隐藏到托盘或保留窗口，休眠和界面缓存释放可分别开关。
- 下载支持中断分段内继续传输、进度合并写盘和尾部无数据连接更快切源；修复整合包搜索分页跳过结果，加入常用中文名称搜索、查询缓存和更合理的元数据等待时间。
- 更多菜单可查看全部功能，隐藏入口仍可搜索；账号页面提供直接进入背包的入口。

Windows x64、Windows ia32、Android 社区同步为 0.7.2。Android 构建号 70200，Android 10 及以上；可选游戏运行组件继续使用兼容的 70003，不需要重复安装。社区服务端也需升级到 0.7.2。

Windows 默认快捷键：Ctrl+Alt+C 显示/隐藏游戏内聊天，Ctrl+Alt+V 退出语音，Ctrl+Alt+M 停止音乐，Ctrl+Alt+L 收回歌词。可在设置 → 社区与语音修改。原生覆盖适用于窗口或无边框游戏；独占全屏的显示由系统与游戏决定。
