# 幻想镇 0.7.3

本次更新集中修复联机、游戏内覆盖与反馈处理，并新增三款肉鸽小游戏。

- 修复 P2P 协商消息在连续到达时丢失的问题；连接失败可重试，并显示公网地址、STUN 和 NAT 诊断。支持自动选择、P2P、公网 IPv4/IPv6、UPnP、PCP、NAT-PMP、手动映射和已有虚拟局域网。游戏流量不经过社区中继。
- 修复房间邀请复制和解析，支持 HXZROOM 大小写、聊天中的完整邀请以及从链接打开启动器。
- 加入时自动核对已安装实例的游戏版本、加载器及模组摘要。缺少默认服务器整合包时，可确认后安装再加入；原版及无附加模组的加载器实例也可自动安装。没有可信下载配置的自定义整合包会提示向房主获取整包。
- 固定 HXZUP 使用当前选定的游戏目录，修复导入配置保留其他电脑路径、设置保存与任务启动交错的问题。
- 修复语音覆盖、游戏内文字大厅的数据传递；语音连接期间保持活动状态检测。调整默认快捷键，已有自定义键位保留。
- 反馈中心新增状态筛选、搜索、回复通知、重新打开、归档和删除；只有管理员能删除已解决或已归档的反馈。电脑详情使用独立弹窗，手机在当前面板内处理。
- 新增 16「星潮幸存」怪潮生存、17「星图旅札」卡牌探险、18「星灯迷宫」地牢闯关。分别提供天赋构筑、卡牌与路线奖励、三十间房间与首领战；支持暂停、结算、周榜与长期榜。
- 新游戏补齐统一封面、触屏摇杆、手牌面板、普通/专注及手机横屏布局。

Windows 64 位、32 位和 Android 社区同步为 0.7.3。联机开房及加入运行在 Windows 端；手机仍可查看房间、管理授权和复制邀请。社区服务端应同步更新，保留原有 data 与 .env。
