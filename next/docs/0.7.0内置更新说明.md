# 0.7.0 Android 内置更新修订

2026-10-12。社区客户端和游戏运行组件各自保持 0.7.0，本次修订构建号为 70003。两者沿用原包名和证书，覆盖安装保留各自数据，不要先卸载。只有公开签名清单切换后，内置更新才会推送该构建。

1. 幻想镇社区「我的 → 应用更新 → 检查更新」，下载并按 Android 提示安装社区客户端构建 70003。
2. 重新进入社区，在「发现 → Minecraft → 检查组件更新」下载游戏运行组件，完成后点击「安装组件更新」，按系统提示覆盖安装。
3. 返回 Minecraft 页面，选择模组一服「安装并进入」；已下载的游戏文件可继续使用。

社区修订修复了更新入口：安装过组件之后，缓存 APK 不应让按钮一直停在「安装组件更新」。现在比较已安装版本与通过签名验证的清单，安装完成返回后刷新状态；旧界面残留的安装操作也会先检查是否已经安装。不会自动点击 Android 系统安装确认。

复现命令：`node scripts/tests/android-engine-update070.mjs`。修改前实际 state 方法返回错误 ready=true；修改后已安装缓存、新下载包、安装返回、首次安装、文件缺失和无效缓存六种情况通过。Android 边界使用桩替代，不能视作手机实际安装验收。

运行组件的下载、NeoForge 安装和模组适配说明见《0.7.0安卓适配修订》。本次完整修改源码随 HXZ-GameEngine-0.7.0-70003-source.zip 发布；维护源码保存在 Git 主分支及 v0.7.0-android.70003、v0.7.0-android-client.70003 标签。旧 70001 附件和标签继续保留。只更新 Android 两个签名清单，Windows 和社区服务端的更新内容保持不变。

70003 新增修复：公共 Maven 依赖超时自动换源；皮肤站认证地址拼接；社区账号/皮肤导入原生运行组件；FCL 原生启动也调用 HXZUP；首次安装不能误跳过整合包；应用恢复时初始化崩溃；实例配置隔离；自动检查图形驱动、首次手机画质默认值，以及为系统与图形预留空间的内存分配与低内存启动保护。新版完整源码归档为 HXZ-GameEngine-0.7.0-70003-source.zip。

70003 补充：运行组件首次打开或返回前台时自动读取同签名社区的已选角色，社区提供「导入社区账号」；认证元数据及验证请求采用保留 HTTPS 校验的 IPv4 优先连接，规范皮肤站首页和接口路径。启动前在独立进程检测图形能力，自动修正渲染器和 Vulkan 驱动并保存至 FCL 实例。70002 为本地中间构建，未启用其自动更新清单。
