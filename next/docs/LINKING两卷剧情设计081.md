## 来源与作者层关系

用户指定 LINKING 是现实世界，《雪烬长明》是其模拟世界；这是作者层约束，不能直接写进玩家剧情、任务答案或人物已知信息。玩家是探索者，与记录员林苇、设备维护周拾、档案负责人唐知衡在现实馆舍中检查载体、校准接收设备、纠正索引、调取资料。白枝人物只通过既有影像、声音和文书记录出现。馆里的照片、底带与纸星工具不是原作银铃跨界而来的原件。

取材优先当前游戏已完成文本：第一卷 G1—12、第二卷 G13—22。第一卷逐屏来源 `text` 与稳定屏 ID、第二卷 `design/scenario/vol02_c013.md`—`vol02_c022.md` 是具体事件依据；两份改编大纲和人物依据用于校对顺序与身份。当前正式发行仍为 0.6.0 / G1—34，候选至 G48；不能把后续在制工作写成完成。详见 [LINKING原作对照081.md](LINKING原作对照081.md)。

实现入口为 `apps/community-server/src/linking-volumes081.mjs`，引用 `linking-volume1-reality081.mjs`、`linking-volume2-reality081.mjs`。每卷的内部 `sourceMap` 按档案 ID 记录绝对来源路径、稳定屏 ID 和改编关系；工厂只取玩家内容，不将内部来源表传给玩家。现实馆内的误归、仪器故障和调查行动属于新增情节，不冒称小说已经发生的事实。
