# 0.9.0 使用与升级

## 开启或关闭前向纠错

桌面启动器打开“设置 → 社区连接”，使用“启用上传前向纠错补偿”开关。关闭后直接连接默认服务器原地址；打开后只有管理员配置了 FEC origin 和 token 的服务器会经过本地 edge，未配置的服务器仍使用原地址。FEC 会增加一些上传带宽和恢复等待，网络稳定时可以关闭。

社区管理员在服务端运行 `node fec-origin.mjs`，设置 `HXZ_FEC_LISTEN`、`HXZ_FEC_TARGET` 和 `HXZ_FEC_TOKEN`，再把对应的 `origin` 和 token 写入三个默认服务器配置。token 只应放在服务端配置和受信任的管理后台中。

## 选择联机方式

在“MC 联机大厅 → 连接检查”点击“测试本机 P2P”。测试成功后优先使用 P2P；如果双方网络无法穿透，可以选择公网直连或开启社区中继备用。中继开关在“设置 → 社区连接”，房主创建房间时也可以单独关闭备用中继。

管理员可使用 `/api/lobby/relay` 查看中继状态，并通过 `/api/admin/lobby/relay` 设置 `enabled` 和 `kbps`。关闭中继不会影响局域网、IPv4、IPv6 或 P2P 联机。

## 覆盖升级

桌面安装版从 0.8.8 检查更新即可安装 0.9.0；便携版下载对应架构的完整包并保留原来的 `profile` 目录。Android 使用 `HXZ-Community-Android-0.9.0-90000.apk` 覆盖安装，系统版本要求仍为 Android 10（API 29）或更高。

Android 15/16 的部分设备使用 16 KiB 内存页。旧版 APK 内的 NG-GL4ES 仍含 4 KiB `PT_LOAD` 段，系统会在安装阶段报兼容性问题；0.9.0 的 ARM64 渲染库已使用 16 KiB linker page size 重建，APK 内所有 ARM64 原生库均通过 16 KiB 对齐检查。
