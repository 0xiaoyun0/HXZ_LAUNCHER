# 幻想镇 0.8.0

本次基于 0.7.3，保留可拖动、调整大小、跨页移动的卡片布局。

工作台作为集中办事入口，显示待处理、等待结果、进行中和已办结事项；各功能也在聊天、公告、资源、实例、音乐、账号等对应栏目提供入口，两处共用内容和进度。

## 社区与共同创作

- 新增好友、小队、玩家空间、搭子偏好、新人互助、分类收藏和订阅。时光信与回归摘要进入原收件箱，并遵守免打扰偏好。
- 新增活动报名、单淘汰赛、寻宝进度与「活动足迹」。管理员可管理排期、名额、赛程及结果；需要游戏统计的条件只接受受信任游戏服务端数据。
- 共同项目支持成员分工、任务、材料、便签画布、修改历史与阶段成果。保存遇到版本冲突时提示重新读取，不覆盖别人的修改。
- 新增作品展览、素材库、截图裁剪标注及视频片段保存；作品可建立关联论坛讨论。知识库支持检索、引用及离线正文。
- 建造助手支持生产配方计算与蓝图材料参考。蓝图统计的是结构方块，不将其冒充精确合成用料。

## 一起交流与游玩

- 语音房间新增课堂、自习和互助模式、主持人安排发言、专注计时与屏幕分享。屏幕画面优先使用设备间直连，受网络条件限制。
- 增加实时文字字幕；本地语音识别和翻译仅在运行环境支持并完成模型准备后可用。旧运行环境可继续输入字幕。
- 一起看视频支持 B 站 BV/av 视频链接、分 P 和 b23 短链接；使用官方播放器，由房间按钮同步播放、暂停和定位。视频访问权限仍由原站决定，播放器内部操作不保证同步。
- 棋局工坊支持分享已完成对局、逐步回放和挑战码，可从指定步骤与机器人或好友继续练习；练习不计入积分榜。
- 世界接力支持地图版本、隔离导入、接力占用、快照审核与交接。手机端查看与接续，Windows 执行本地世界导入。

## 工具与管理

- 新增实例恢复点、实验副本、整目录迁移、配置预设和启动记录；恢复与迁移先校验，失败保留恢复信息，统计采集不阻塞游戏启动。
- 新增布局导入预览、受限流程卡片与声明式扩展；扩展只组合已有控件，不执行上传的脚本。
- 多端接续支持同账号待办和目标设备确认；Android 新增社区桌面组件，显示最近访问时的信息，不持续后台联网。
- 入服服务提供白名单申请与真实空位提醒。游戏桥未部署时明确显示待配置，不生成虚构在线数据。
- 玩家交易采用背包和积分托管，支持撤回、交付和幂等结算。管理工作台统一审核、提案投票、公开账本与私密申诉；处理申诉不自动扣款或退款。
- 统一页面标题与文件选择按钮，适配浅暗主题、大字号和手机窄屏；服务监控新增玩家本机连接耗时。
- 棋类引擎分开计算进程启动与搜索时限，减少服务端繁忙时低难度对局误报超时。

## 升级说明

Windows、Android 社区及社区服务端版本均为 0.8.0，Android 构建号 80000。新增社区功能需要服务端一起升级；升级前备份完整 data 和配置，保留账号、积分及历史数据。Android 游戏运行组件仍使用现有兼容版本，不将社区版本变更误当作游戏引擎升级。

实际验证范围及设备限制见《0.8.0验收矩阵》。本地构建不代表线上服务已经部署。
