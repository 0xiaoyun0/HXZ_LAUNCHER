# 0.8.6 使用与升级

Windows 安装版通过内置更新升级，或运行同架构安装器。便携版退出后解压新包，保留原 profile；不要把账号目录上传或分享。

Android 覆盖安装 0.8.6 / 80600，保留账号、存档、下载进度和运行模块。运行模块仍由应用自动获取已发布的 0.8.4 / 80400 资源。无需卸载重装，也无需安装独立游戏引擎 APK。

社区后台使用内置更新应用本版签名更新包；新部署使用完整服务端包。先备份 SQLite 数据及配置，再更新程序。游戏服务端桥沿用 0.8.0，无需重复替换。

首页「游玩日历 → 服务器在线」可查看核验记录、每日在线详情与奖励进度。每满累计 24 小时获得 5 积分；周榜排名不影响奖励，未满部分保留。旧版已结算周期不再计奖，尚未结算的核验时间按新规则计算。后台可以暂停积分发放，重新开启时补发完整周期。

本轮由用户手动验证安卓帧率：关闭内存扩展，保持同一设备、实例、视角、画质、分辨率和视距，进入游戏并等待区块加载稳定后记录 F3 的帧率，同时检查水体与透明物体。测试方法及限制见 [安卓性能说明](0.8.6-安卓性能.md)。
