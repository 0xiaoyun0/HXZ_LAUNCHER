# 0.8.2 使用与升级

## 玩家

Windows 安装版可在设置中检查更新，或运行对应架构安装器覆盖安装。沿用原账号、偏好和游戏目录，无需删除 `.minecraft`。便携版退出程序后解压完整包，保留 `profile`，不要混用两种架构的文件。

Android 安装 `HXZ-Community-Android-0.8.2-80200.apk`，沿用原应用标识与签名；0.8.1 的 80100、80101 均可覆盖更新，勿先卸载。最低 Android 10，可选游戏组件仍为 70003。

小游戏共 20 款；新增两款在肉鸽分类中可见。在线计分由服务端根据操作重放核验，升级社区服务端后使用新规则；旧规则中的进行中对局和历史榜单保留，不重置积分。离线练习与在线排行榜分开，不把本地分数伪装成服务器成绩。

LINKING 章节与任务从社区读取。前两卷和第三值夜依次要求完成前置，音乐新外观仍由原章「让回声归位」解锁。新章节的任务和纪念物不额外授予联机或网易云权限。上线流程见 [LINKING 管理说明](0.8.2-LINKING上线准备.md)。

## 管理员

完整服务端只有一个：`HXZ-Community-0.8.2-windows-x64.zip`。`update.zip` 是后台更新器的校验载荷，不是需要同时运行的第二个服务。已有新版 supervisor 的服务可通过后台检查、下载、校验并应用更新；应用前自动备份并切换，失败恢复原服务。手动升级需先停服并一致性备份完整 `data` 和 `.env`，再替换程序，保留账号、积分、物品、帖子、任务和剧情进度。

游戏服务端的 MCDR / NeoForge 桥原样沿用 0.8.0，无需为本次客户端更新重装。部署结束后确认 `/health` 为 0.8.2，并使用普通账号检查聊天、小游戏提交与 LINKING 前置。客户端安装完成不代表社区程序或剧情已发布。

## 验证范围

本次包括真实隔离社区 API 与 SQLite 的任务、奖励、审核、计分回放测试，以及桌面和移动网页的实际点击、布局截图。测试使用隔离账号与数据，不向线上玩家发放测试奖励。

浏览器测试不替代 Android 实体设备验收；当前 Windows 中启动 ia32 不等于实体 Windows 7 验收。游戏运行组件、真实 Minecraft、跨运营商 P2P 和实机麦克风不属于本轮重新验证范围。
