# 0.6.0 安装器与完整服务端补交

本轮需求：补齐正式 Windows 安装器与完整社区服务端，按版本整理 release。用户已退出便携版，同意移动目录并保留 profile。未修改线上服务及真实账号数据。

## 本地产物

- release/0.6.0/windows-x64/HXZ-Launcher-0.6.0-x64.exe
- release/0.6.0/windows-ia32/HXZ-Launcher-0.6.0-ia32.exe
- release/0.6.0/server/HXZ-Community-0.6.0-windows-x64.zip
- 原 Android、便携包和源码分别归入 android、windows-*、source；更新元数据放在 updates。
- 旧 0.5.2-air 目录单独保留；新旧便携 profile 均保留原文件，未合并或删除。

安装器使用 electron-builder 26.17.0 / NSIS，保留 appId top.hxzmc.launcher、正式产品名与用户目录 %APPDATA%/幻想镇启动器。卸载不删除用户数据，首次打开安装版备份原 settings.json。支持目录选择、快捷方式和 GitHub/镜像签名自动更新。未配置 Windows Authenticode 证书；发布清单沿用既有 Ed25519 密钥，二者不是同一签名机制。

完整社区服务端已包含所有既有业务、网页后台、直连授权及房间目录，无需第二个扩展包。Windows 自带 Node.js 24 x64 和运行依赖；旧版升级须停服，完整备份并保留 data 与 .env。不会将 Minecraft 游戏流量送入社区服务器。
