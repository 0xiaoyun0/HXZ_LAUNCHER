# 0.6.4 更新内容

## 2026-10-08 界面修订

- 统一卡片字阶、留白、按钮、菜单和输入控件，快捷入口采用更紧凑的图文排布；保留拖动、缩放、自动尺寸、隐藏和保存布局。
- 改善浅色与深色主题的文字对比，选中状态和默认头像跟随主题色；修复外观预览在暗色主题下文字难以辨认的问题。
- 补齐卡片聚焦、按钮按压、下拉箭头和封面反馈；修复关闭动画时已关闭的菜单仍然残留的问题。
- 统一语音房间卡片的成员区间距，整合包和蓝图封面加载失败时使用统一占位；移除重复的实例版本描述。
- 改善手机与平板字号、触控区和卡片间距，修复手机横屏时导航入口被裁切的问题。

Windows 仍为 0.6.4；已安装 0.6.4 的用户需下载修订安装器覆盖安装，旧版本仍可通过更新检查升级。Android 构建号递增至 60402，沿用原签名并支持应用内检查更新。社区服务端本次无需重复更新。

## 0.6.4 原有更新

相较于 0.6.3：

- 新增小游戏 13「云朵 2048」、14「青柠贪吃蛇」、15「星野扫雷」，支持鼠标、键盘、触屏与社区周榜、长期榜。
- 第 10 款游戏更换为原创坦克防守「星堡双卫」：提供单人练习与两台设备联网合作。电脑、手机可互相加入同一社区房间，各自控制自己的坦克，共守二十波防线。
- 合作对局由社区服务端同步和判定。断线、切到后台自动暂停；双方恢复连接后可继续。离开正在进行的房间会结束本局。
- 统一游戏内标题、得分、暂停、操作提示、排行榜和手机按键。手机开局进入专注游玩，棋盘保持比例，横屏和窄屏按可用空间排列。
- 修复倒计时暂停后缺少继续按钮、切换排行榜时旧请求覆盖新榜单、棋类切换残留上一局、狼人杀轮询收起讨论记录等问题。
- 改善移动操作响应与绘制平滑度，修复打砖块加宽球拍越界，完善扫雷首步安全、插旗与数字展开行为。
- 全部 15 款小游戏使用同一套蓝白清透二次元封面，统一构图比例与编号样式；封面本地加载，整套约 1.53 MB。
- 统一右上角收件箱和快速搜索的图标尺寸、线宽及按钮状态。
- 下载默认优先官方源，连接失败、校验失败或持续无响应后切换备用镜像；新增下载速度滑动条，最高档不限速。多个文件与分段共享限速额度，游戏安装与内置 HXZ UP 同步设置，运行中调整也可生效。
- 俄罗斯方块支持点击旋转、左右滑动移动、下滑后松手落下和上滑暂存；吃豆人、贪吃蛇支持连续滑动转向，2048 支持方向滑动。中断触摸不会继续移动或误落子。
- 修复小游戏分类、搜索结果未靠左排列的问题；保留自定义卡片宽度、自动尺寸、锁定及隐藏状态，切回全部游戏恢复原布局。历史卡片配置兼容迁移，后续增加游戏不会打乱已有卡片。
- 更新 Windows 与 Android 图标，补齐页面切换与加载反馈。动效仅作用于内容，不挤动导航和卡片，支持调整速度、关闭动画及系统减弱动态效果。

Windows x64、Windows ia32 与 Android 同步为 0.6.4；Android 构建号 60402。新游戏计分与双人合作需要管理员升级完整社区服务端。保留旧版游戏规则与历史排行榜数据；不用清空数据库。
