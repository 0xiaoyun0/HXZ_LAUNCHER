# 0.8.4 发布与验收检查清单

更新：2026-10-21。0.8.4 已公开预发布，安卓 80401 为后续修订。下列未勾选项包含尚待用户手动完成的实机验收，不能把协议测试或编译成功当成实机运行成功。

## 稳定发布前须完成的验收（预发布交给用户手动检查）

- [ ] 完成独立 Android 游戏引擎：真实 JVM 启动、LWJGL/GLFW 图形与输入/音频、窗口和进程退出恢复。以实际进入 Minecraft 世界为判定，不能靠空 Activity、JNI 占位或资源就绪状态通过。
- [x] 从真实上游逐项锁定 Android JVM、图形和其他底层依赖的源码、补丁、构建方式、许可与二进制散列；最终附件另作全量核验。
- [ ] 完成独立模块格式及签名发布工具、三服真实安装/HXZUP/账号交接，并把最终实例模组指纹接入房间 ready、加入校验和退出回报。
- [x] 跨端房间要求 Minecraft、加载器、加载器版本和已安装整合包模组指纹精确匹配。安卓仅把经过内置客户端规则、真实备份散列和依赖复验的隔离原件计入该指纹；任意缺失/禁用文件、邀请里的平台或预设标记不能自行授权差异。
- [ ] 在用户手动实机验收时，验证 AndroidKeyStore 房间证书、真实 WebRTC ICE/SDP、跨网络直连、下载中断恢复及至少一次完整游戏启动。现有 JVM 和浏览器夹具不能替代这些结果；按用户要求，开发阶段不操作平板。

## 完成实现后逐项验收

- [ ] 安装/下载：官方源优先，备用节点只能取得同一目标文件；断点、取消、重试、完整散列、签名验证、解压隔离与重复激活逐项通过。全部节点失效时保留可继续进度，并真实显示失败。
- [ ] 运行模块：下载和解压完成前不可激活；已安装目录在复用、激活和启动前执行全量文件散列检查；激活失败保持上一个可信模块可用；运行中的模块不被覆盖。高频状态查询不执行全量散列。
- [ ] 模块签名：外层签名 payload 的 `moduleSha256` 必须等于 ZIP 中 `module.json` 原始字节散列；安装后的清单与资源逐项复验。复用模块时核对路径链接与清单字节，不能仅靠 `verified.json` 自报。
- [ ] 联机：反复开房、关房、加入和退出后，无遗留监听端口、P2P 信令连接、NAT 映射、证书别名或后台线程；权限撤销、账号切换、租期和邀请过期后拒绝新连接并从大厅移除房间。
- [ ] PC/Android 协议：TLS 指纹在发送邀请密钥前校验；帧大小和背压、错误回报、实例指纹及房间 ready/退出行为双向一致。分别记录夹具与真机验证范围。
- [ ] 社区数据：升级和失败恢复均保留所有用户账户、角色、凭据、服务端数据、存档和已安装资源；有迁移时先验证备份及回滚。不得以清空数据换取通过。
- [x] 构建：本地 Windows 两架构、服务端、Android 80400 签名 APK 和独立运行模块已构建。APK 身份与旧社区相同，未使用废弃嵌入方案产物；上传前另核验最终附件与签名元数据。

现阶段已记录的下载节点及边界见 [0.8.4下载节点](0.8.4下载节点.md)，实际完成/阻断状态见 [0.8.4开发状态](0.8.4开发状态.md)。

## 2026-10-21 静态审计记录

- Android 独立引擎的 GLFW 3.4 公开 C ABI 与 native executor 链接检查通过；Java host 定向编译通过。该结果**不代表**设备上完成 JVM、渲染、音频、输入或 Minecraft 启动。
- 运行模块 ZIP 与签名清单测试 13 项通过；packager 按 ZIP 原始 `module.json` 字节写入签名 payload 的 `moduleSha256`。已用最终 Mesa/JRE 构建模块，719 个文件实际解包与全量散列检查通过；仍无设备运行验证。
- 单设备进程 IPC 限同 UID、共享帧长度/尺寸受检、输入与关闭有界；重复打开有进程门禁，未持有的陈旧 Unix socket 可清理。仍须在真机上验证 Surface 重建、游戏保存退出、连续多次开房/退房和进程被系统回收后的恢复。
- 账号令牌在生成启动 job 前重新读取并检查角色代次；诊断仅记录准备阶段与有限日志尾，复制时隐藏已知令牌、URL 查询和启动参数。首次运行写入移动端低负载默认值。图形后端单独固定为 OpenGL，避免用户选择当前宿主不支持的 Minecraft Vulkan 后端；其他已有设置及世界不清空。
- 跨平台联机仅接受实际 Minecraft、加载器版本和已安装原包模组数量/散列精确匹配。经内置精确散列规则核验的客户端适配原件保留并复验，任意未知禁用项不计入。普通默认服务器启动不额外计算联机指纹，减少手机重复读盘。
- 本地 `release/0.8.4` 已有 Win64/Win32 便携版、NSIS 安装器及 Windows x64 服务端 ZIP；包内版本与安装通道均核为 0.8.4，服务端 ZIP 不含 `.env` 和 `data/`。安装器与旧发行方式一样未配置 Windows 代码签名，需在交付说明中如实提示。
- 桌面、服务端、Android APK 及运行模块签名清单均已生成；后续发布检查逐项核对附件散列、源码快照与签名。0.8.4 先以预发布供用户手测，不替换最新稳定发行版。
