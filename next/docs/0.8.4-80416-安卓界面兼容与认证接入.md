# Android 80416：ModernUI 绘制兼容与认证接入

## 本次崩溃

80415 的 vivo V2408A / Android 16 报告已越过字体加载阶段，新的异常是 `icyllis.modernui.core.Core.requireUiRecordingContext` 抛出 `UI recording context has not been created yet, or creation failed`。这表示 ModernUI 的绘制上下文未成功建立，不能仅凭退出码 255 判断为内存不足，也不能把报告中的 Connector / Sable 通用提示当作根因。

核对两服实际安装的 `ModernUI-NeoForge-1.21.1-3.13.0.1-universal.jar`，SHA-256 均为 `258623778012daad6fdd8793add3324b970df62a07c477697c43fe85deef1db6`。精确版本字节码显示：`Core.initUiThread` 在 GPU 上下文缺失时仍建立 UI 线程，后续绘制要求非空录制上下文；关闭文字引擎的 bootstrap 配置不能关闭整个 UI 初始化。

[ModernUI 官方项目](https://github.com/BloCamLimb/ModernUI-MC)列明该 Minecraft 版本使用 OpenGL 后端。当前日志未包含底层设备初始化的第一处失败，不能声称已修复其 Arc3D 驱动，也不把声明 OpenGL 3.3 当作完全兼容的证明。

80416 使用已有可恢复的客户端适配流程，提前备份并停用上述精确版本的 ModernUI，改用 Minecraft 原生界面。规则同时校验文件 SHA-256、完整模组标识、嵌套库、无玩法数据和保留模组的真实必需依赖；未知或被用户恢复的文件不强行处理。服务端要求某个玩法组件依赖 ModernUI 时保留原件。HXZUP 检查前恢复原文件、更新后重新适配，备份仍用于房间模组指纹，避免重复下载或破坏联机版本识别。

这是针对已报告组合的兼容绕行，不是对所有 ModernUI / 渲染器版本的兼容保证。上一版 FreeType / AWT 依赖修复继续保留。

## 对照 FCL 的网络接入

FCL 的下载网络工具不负责 Minecraft 的游戏 TCP 连接；游戏连接依然由 Minecraft / Netty、Java 和操作系统负责。不能用替换下载器来宣称修复“进不了服务器”。

本轮核对固定 FCL 提交 `efe4dcc5dbc78c55be177c330239e12845ae7ccf` 中 [AuthlibInjectorAccount](https://github.com/FCL-Team/FoldCraftLauncher/blob/efe4dcc5dbc78c55be177c330239e12845ae7ccf/FCL/src/main/java/com/tungsten/fclcore/auth/authlibinjector/AuthlibInjectorAccount.java) 的接入方式，补齐 HXZ 原先遗漏的两项参数：

- `authlibinjector.side=client`：明确以客户端身份运行认证代理。
- `authlibinjector.yggdrasil.prefetched`：将皮肤站的公开服务元数据按原 UTF-8 字节编码传给代理，避免游戏 VM 启动时重复请求元数据。

预取由社区主进程已有 OkHttp 网络栈执行，使用 Android 的 DNS / TLS 机制。仅访问固定 HTTPS 皮肤站地址，响应上限 256 KiB、调用时限 8 秒、成功缓存 5 分钟，使用独立缓存锁，不占用社区状态锁。失败时保持原有在线认证，不使用伪造会话，不跳过登录凭据验证，不禁用证书检查，不把认证请求转发到社区服务器或第三方镜像。此机制只改善认证初始化；后续 session join、服务器端验证、模组协议或公网连通故障仍需具体入服提示判断。

## 验证与交付

- 修复前，真实 ModernUI 文件在隔离测试实例中仍被保留，启动前兼容断言失败；添加规则后通过精确文件隔离、恢复、HXZUP 前后事务、房间指纹、用户恢复和必需依赖保护检查。
- 两服只读扫描：225 / 261 个模组文件，未知元数据均为 0，预期可适配 11 / 9 个文件；不会移动桌面实例文件。
- 认证参数、UTF-8 元数据、缺失/无效响应、HTTPS 限制及降级行为通过定向测试；新增 ModernUI 可读诊断，保留通用兼容性事务回归。
- 完整 Android 签名构建。未进行手机真机渲染、实际账号认证或加入服务器验收。

仍使用 0.8.4，构建号 80416。运行模块不变，覆盖更新保留账号、游戏和存档。APK 与签名内置更新清单发布在既有 v0.8.4 Release。
