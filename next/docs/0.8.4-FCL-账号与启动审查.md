## 可复现修复与验证

`scripts/tests/android-jvm-arguments084.mjs` 抽取生产AndroidEngineHost的job写入和field校验，读取实际二进制请求，验证JNI选项、classpath、空格、堆参数、缺值拒绝和失败清理。修复前两次独立红测分别报“Native access option must be a single JNI option”和“Failed request serialization must remove its partial credential file”。修复后11项通过。该脚本同时运行JavaRuntimeMetadataTest：10项合成文件检查，加本地实际ARM64 Java21和Java25 release文件共12项通过。

`scripts/tests/android-launch-auth084.mjs` 抽取生产账号方法，以模拟传输验证validate成功、403刷新、缓存副本、固定目标地址、断网/5xx不刷新也不清缓存、角色变化、clientToken变化、刷新403、格式错误、未登录及并发注销，共20项通过；并检查同UIDProvider限制与Activity启动接线。修复前红测为“A game launch must validate the cached skin-site token”。测试使用虚构字符串，不使用真实账号或外站。

这些是主机JVM协议、文件和并发验证；未执行手机JNI、未进游戏、未做真机前后台/低内存/存档保存测试。本次不修改版本、build/release或发布资源。原有诊断与Mod规则仅审查对照，不重复执行其广泛测试套件。
