# 0.8.4 使用与升级

## 本轮交付

0.8.4 先作为验收预发布提供。未实机验证的新安卓引擎不会通过「最新稳定版」自动推给所有用户；现有稳定版继续保留。确认实机结果后，可将同一发行版转为正式版。

Windows 用户选择 x64 或 ia32 安装器。安装器延续原有发行方式，未配置 Windows 代码签名。不要删除原 profile、.minecraft 或 Java 目录。

安卓用户下载最新修订 `HXZ-Community-Android-0.8.4-80401.apk`，覆盖安装原幻想镇社区应用，包名及签名与此前一致。80400 已安装用户也可直接覆盖。不要先卸载；卸载会清除应用私有数据。

`HXZ-Runtime-0.8.4.zip` 是由社区应用自行下载、校验和启用的运行资源，不是第二个应用，也无需手动解压。对应 `game-runtime-latest.json` 用于签名验证。

## 安卓验收步骤

1. 登录皮肤站并选择角色，进入「游戏 → Minecraft」。
2. 选择一个默认服务器，点击「准备并进入」。首次需要阅读运行提示并下载运行模块。
3. 等待模块和游戏准备完成，检查画面、声音、触控及服务器登录。
4. 退出游戏并重新打开，确认社区账号、游戏设置和世界仍然存在。
5. 联机验收时，两端须使用相同游戏版本、加载器及模组；先由房主进入世界、等待大厅显示已开放，再让另一端加入。

游戏内顶部的「键盘」可调用手机输入法。在世界内点击会打开聊天，支持中文和命令；编辑告示牌或其他文本时，先选中游戏里的文本框，再点「键盘」输入。物理键盘仍可使用。

多个皮肤站角色的账号须先在「切换游戏角色」选择一个角色。游戏准备入口不会再把角色管理误导向触控设置。

本轮按照用户要求不连接平板代为测试。若失败，可复制游戏准备页面的技术诊断，说明服务器、设备型号以及操作步骤。不要发送账号密码或登录令牌。

## 兼容性

- 社区应用：Android 10 或以上。
- 本次游戏运行模块：ARM64、4 KiB 系统内存页；不支持的设备会在下载前提示原因。
- 游戏运行模块提供 Java 21/25、与目标游戏匹配的原生库及 OpenGL 渲染路径；不是任意版本和任意模组的兼容保证。
- 高内存整合包可能超出设备能力。保持自动内存和渲染器选择，再按实际运行表现调整分辨率。
- 旧版独立运行组件不会被删除，其存档也不会自动迁入。新模块的世界位于社区应用私有目录。
- P2P 和公网直连受双方 NAT、防火墙及网络条件影响；本版本不使用游戏流量中继，不能保证任意网络都可建房。
- 模组一服的 Sable 物理库目前随整合包提供 Linux glibc 原生文件，与 Android bionic 不兼容。已确认手机本地世界的物理服务调用存在缺口；远程客户端是否会触发须实机验收。Sable、航空学等内容模组保持原样，当前这类联机房主请使用 PC。

## 80401 修订

- 修复 Minecraft 初始化时设置窗口尺寸限制触发错误回调的问题；合法的窗口图标、位置及显示操作由宿主接管，不再打断游戏启动。
- 修复关闭自动更新后跳过本地 HXZUP 整合包检查的问题；同版本缺失或损坏的文件也会修复，完整旧包仍可免联网继续。
- 增加手机输入法入口，整理触控边界；模块下载失败显示节点、阶段及可采取的操作。
- 独立运行资源仍使用已签名的 80400 模块；本次修复位于社区 APK，不要求重新下载未改变的 Java/Mesa 等资源。
- 所有检查分别记录本地代码、编译和协议范围，没有新增实机运行结论。

## 手机客户端模组适配

启动顺序为「恢复上次保留的原件 → HXZUP 校验与更新 → 客户端兼容检查 → 进入游戏」。当前自动规则仅覆盖两服正在使用的 IMBlocker 5.5.4/5.6.1 官方文件；它们负责桌面输入法整合，不能在 Android 使用桌面 X11、ibus 或 fcitx 接口。匹配完整文件散列和模组元数据后才会停用，未知版本、内容模组和被其他模组依赖的文件不会被随意删除。

隔离原件、事务记录和原因保存在实例的 `.hxz/client-mods/`，诊断会列出实际调整。原件继续参与整合包一致性核对，防止仅因已核验的客户端差异拒绝跨端联机；任意手动禁用或缺失文件不能绕过房间检查。自动预检不是所有模组均兼容的保证，仍需按上述步骤手动验收入服。

IMBlocker 客户端属性与版本记录：[作者发布的 5.5.4](https://api.modrinth.com/v2/version/gom4UX66)、[作者发布的 5.6.1](https://modrinth.com/mod/imblocker-original/version/JCFs4e8D)。ModernUI 的旧 gl4es 规则不适用于这次引擎；AcceleratedRecoiling 有 Java 后端，不能仅因存在 x64 库就禁用。这些规则没有沿用。

## 社区服务端部署

首次部署使用 `HXZ-Community-0.8.4-windows-x64.zip`。已有服务使用 `HXZ-Community-0.8.4-update.zip`，升级前备份当前 data 与 .env；不要用空目录覆盖玩家数据。

排行榜、背包、积分、发布内容和活动进度存放在服务端数据目录，不在客户端安装包中。服务端包和自动更新包不夹带开发环境的运行数据库。

游戏服统计桥沿用本轮附件中注明的 0.8.0 桥组件及散列，不伪造新的桥版本。
