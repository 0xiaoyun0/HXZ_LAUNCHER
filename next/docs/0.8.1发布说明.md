# 幻想镇 0.8.1

本次基于 0.8.0，集中修复游戏退出后的恢复问题，精简界面，并补齐 LINKING 剧情与音乐档案体验。保留账号、已安装实例、卡片布局与历史社区数据。

## 启动与恢复

- 游戏退出后，启动器先接收退出状态，再恢复窗口和覆盖层；恢复失败会显示错误，避免异常沿退出流程传播。
- 自动更新安装失败并重新打开旧版后，不再自动重复安装同一版本。需要时仍可手动重试。
- 页面加载失败提供主动恢复入口；模块下载失败可手动重新载入界面，不会自动刷新或重启循环。
- 社区连接失败显示可执行的说明。写入中断时提示结果尚未确认，先刷新再重试，减少重复提交。

## 更集中的首页与导航

- 首页集中为「我的角色」「游戏实例」「开始游戏」「服务状态」四张默认卡片。角色卡提供登录、账号与角色切换、皮肤站入口；更新移至设置「下载与更新」。
- 本地已安装实例与三个默认服务器都可在首页选择；联机大厅继续提供对应服务器的安装、启动和在线玩家入口。
- 移除工作台、个人待办及重复快捷入口；保留冒险家协会、小游戏和音乐。蓝图库移入社区，移除作品共建、知识建造、好友与小队、棋局与作品的前端入口。
- 主导航固定展示常用栏目，LINKING 常驻。右上角「快速前往」与 Ctrl+K 共用入口；反馈入口移至右上角，任务与日志入口移至右下角。
- 修正拖动、拉伸及窗口缩小时的卡片越界；继续保留自动高度、尺寸调整、锁定、隐藏恢复及布局保存。服务监控使用更清楚的分组，保留真实连接状态与本机延迟。

## 实例文件管理

实例管理统一提供模组、资源包、光影与机械动力蓝图文件列表，可查看文件名、启用或禁用，并拖入文件导入。同名文件受到保护，操作遵守实例隔离，游戏运行期间禁止写入。

## LINKING 与音乐档案

- 新增两卷续篇《第七门的回声》《迟到的北行信》，共 24 份档案、32 项任务、8 处口令线索及 4 件调查纪念物。管理员可创建独立未发布草稿，再检查和发布；客户端升级不会自动发布或覆盖线上章节。
- 管理员可在 LINKING 内打开「0.8.1 剧情预览」，直接切换两卷并阅读全部正文。此入口只读，不保存线上进度、不验证口令、不发放奖励。
- 正式玩家的章节前置与任务解锁由服务端验证。阅读支持继续阅读、滚动位置恢复和前后篇导航；保存失败时不会假装解锁下一篇。
- 完成对应剧情可解锁音乐档案界面，提供唱片阵列、选择、检视与场景动效，并接入原有曲库、搜索、导入、歌词、播放控制、一起听和网易云授权。
- 经典音乐界面与原布局保留，可随时切回。音乐播放不因切页或切换外观而重建；减少动态效果时静止，页面隐藏时暂停场景，三维不可用时使用静态视图。

## Android

Android 社区重新整理手机页面：默认服务器前置，运行组件与高级参数按需展开；「我的」保留账号和常用操作，设置拆为账号连接、外观显示、语音聊天、下载更新四个分区。文字/语音、论坛/蓝图使用页内切换，避免悬浮按钮遮挡内容。

统一与桌面一致的线性图标，卡片按有效宽度与字号换列；修复歌词、余额、分页、语音成员和长标题被操作按钮挤压的问题。音乐重排为播放、曲库、在线搜索、一起听四块，保留原有功能。短窗口弹窗可滚动到提交按钮。正式安装包沿用原签名身份，可选游戏运行组件继续使用已发布的 70003 修订。

## 升级与验证边界

Windows 提供 x64 与 ia32 安装器和便携包；Android 提供 0.8.1 / 80100 社区客户端。已有安装版使用内置更新；便携版退出后保留 profile 再升级。社区服务端需要同步升级才能使用新版剧情管理和外观解锁接口，升级前备份并保留整个 data 与 .env。

本版本包含隔离数据下的功能与界面回归，以及 Windows 两种架构的本机验证。浏览器中的 Android 界面检查不能替代实体手机验收，ia32 在当前 Windows 上运行不能替代实体 Windows 7 测试；公网游戏服部署、真实联机及在线媒体的可用性仍取决于各服务环境。许可证与第三方声明随对应发行文件保留。
