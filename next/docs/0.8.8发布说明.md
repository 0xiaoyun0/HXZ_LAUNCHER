# 幻想镇 NEXT 0.8.8

0.8.8 是一次桌面与 Android 的稳定性和交付优化版本。

## 更新内容

- 修复更新下载在首个来源失败后仍挂在旧下载 Promise、界面持续显示“下载中”的问题；失败会切换来源并重新计算真实进度。
- 桌面 x64、ia32 和 Android 共用收敛后的卡片布局约束，长标题、窄窗口、空状态、操作区和滚动容器不会把尺寸传递到外层造成错位。
- Android 增加刘海/手势区安全边距、横屏低高度布局保护和单一滚动责任，统一 44px 触控区与卡片换行规则。
- 更新清单按当前版本自动生成，避免版本升级时沿用旧版本文件名或 Android versionCode。

## 构建

- Windows x64 / ia32：安装器与便携版。
- Android：arm64-v8a，versionName `0.8.8`，versionCode `80800`，minSdk 29。
- 更新签名与 SHA-256 清单随发布包生成。

## 升级

旧版 0.8.7 及更早版本可以通过桌面更新通道升级到 0.8.8。Android 请覆盖安装 0.8.8，应用数据保留。
