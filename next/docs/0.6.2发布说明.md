# 幻想镇 0.6.2

本版修复 0.6.1 的联机与歌词问题，同步提供 Windows x64、Windows ia32、Android 和完整社区服务端。

- 修复 Minecraft 26.2 单人世界无法自动开放联机：适配新版 LAN 接口，保留旧版接口支持，不改变世界游戏模式或开启访客作弊权限。
- 自动开放失败后会退避重试；取消房间后不再执行过期的开放请求。世界已经使用其他端口时给出重新进入世界的提示。
- 清理联机错误中的 Log4j 标记，公网探测分别显示 IPv4、IPv6 和对应地址，方便区分网络探测失败与世界尚未开放。
- 桌面歌词改为独立透明窗口，可自由拖动、调整大小、置顶和锁定鼠标穿透，不占用启动器卡片或改变页面透明度。
- 音乐页可开启“关闭主窗口后继续播放和显示歌词”。开启桌面歌词后生效；系统托盘可恢复主窗口、解锁歌词或彻底退出。默认关闭此选项。
- 桌面歌词遵循关闭动画设置；保留歌词卡片、左下角收回入口和个人网易云授权方式。
- 修复切换栏目后沿用上一页滚动位置，导致新页面标题或顶部内容被隐藏的问题；卡片内部与聊天记录的滚动不受影响。
- Android 同步版本与更新清单，继续使用移动端歌词和完整社区功能；本次不申请额外的系统悬浮窗权限。

## 升级

Windows 安装版沿用签名自动更新通道，0.5.2、0.6.0、0.6.1 可识别此更新。便携版请退出后更换完整包，保留 `profile`。Android 内部版本 60201，沿用原签名覆盖安装。

社区服务端仍是一个完整包。已有 0.6.1 服务端兼容本次客户端；更新服务端前停服并备份、保留整个 `data` 和 `.env`，无需清空积分、榜单、论坛或账号。

联机接口通过本机 26.2 游戏文件核对，并运行新旧签名的 Java 助手检查。本机隔离社区与双架构加密中继不等于真实异地多人游戏验收；Android 真机权限、耳机及后台语音仍需实机验证。
