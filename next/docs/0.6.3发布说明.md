# 0.6.3 更新内容

- 默认官方来源、32 并行。游戏本体、依赖和资源进入同一队列，大小文件同时推进；大文件使用可恢复分块下载。
- 修复正常传输消耗重试时间、最后一个文件持续低速等待的问题。异常时尝试备用节点，保留已校验文件和支持恢复的下载进度。
- 修复默认服务器首次安装后重复准备游戏的问题，启动器与内置 HXZ UP 使用一致的下载设置。
- 安装失败优先显示原因和继续操作，保留具体文件及底层错误；任务详情显示文件下载量与最后一项状态。
- 小游戏 10「丛林突击」：三关横版跑射、八向瞄准、跳跃与冲刺。
- 小游戏 11「花园守卫」：三类炮塔、升级回收、三十波挑战和首领波次。
- 小游戏 12「月下圆桌」：六人狼人杀、私密夜间行动、白天讨论和投票；人数不足可补齐机器人练习。六位真人参与的胜方沿用每周联机积分规则。
- 统一游戏操作图标、按钮及移动触控区，改善窄屏、横屏、大字号布局，修复进入游戏后页面自动跳动。

Windows x64、ia32、Android 同步为 0.6.3。管理员须同步更新完整社区服务端，才能使用新游戏联网计分及狼人杀；旧服务端仍可用于原有社区功能。

升级服务端前停服并备份整个 `data` 与 `.env`，替换程序时保留两者。排行榜、积分、帖子继续使用原数据，无需重建数据库。狼人杀当前房间保存在内存，服务重启后须重新开房。

安装版沿用签名自动更新通道；便携版退出后更新完整目录并保留 `profile`。Android 沿用原签名覆盖安装。32 位包沿用旧系统兼容运行环境，新 Minecraft 与 Java 仍需满足各自系统要求。
