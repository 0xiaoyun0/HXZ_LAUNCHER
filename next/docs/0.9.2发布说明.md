# 幻想镇 NEXT 0.9.2

- 在线人数增加桌面与 Android 本机 MC 状态查询，旧社区 DNS 失败时仍可读取人数与公开玩家；已安装游戏桥时优先采用新鲜的完整状态。失败显示未知，不伪造零人。
- 统一 MC 连接协议，处理 SRV、直连、分片响应、超时和取消；HXZRE 回环入口保留原服务器握手域名。
- HXZRE 必须完成 Edge → Origin → MC 的双向请求后才显示已启用，失败自动直连。服务端支持实际进程状态、传输自检与开关生效。
- Windows 游戏运行期间默认继续操作启动器，可运行多个不同实例、调整设置、安装其他实例；设置提供开关和资源/文件冲突说明，每个进程可单独停止。同目录实例需先创建副本；运行中删除、覆盖恢复或迁移仍要求先关闭对应游戏。
- Windows 新增完整权限插件 API 1、本地安装启停、插件市场提交与管理员审核。安装和升级默认停用，启用需要确认权限；提供安全模式、规范与示例包。
- Windows 与 Android 增加自动错误队列，隐藏凭据、断网重试。后台汇总重复错误，显示基本环境与发生次数，可记录处理人、状态、说明及历史。
- 游戏桥升级为 0.9.2，使用会话、单调序列和回执避免旧心跳覆盖；增加待发送队列恢复。继续兼容旧桥，保留状态、统计、聊天及白名单接口。
- 社区后台新增实际运行版本/目录、HXZRE 传输诊断、自动错误收集、插件审核。修复手动覆盖安装被旧 active 更新目录遮蔽的问题。
- 交付延续 0.8 目录与签名更新结构：Windows x64/ia32 安装与便携、Android APK、社区全量与更新包、MC 组件、源码、更新清单和 SHA-256。

Windows ia32 保留 Electron 22.3.27 兼容构建；HXZRE 原生模块仅 Windows x64。Android 保留 0.8.8 的应用身份、签名与四 ABI 安装结构，使用 versionCode 90200，资源表不压缩并对齐。Android 游戏引擎仍使用一个游戏进程；桌面插件不在 Android 执行。

本机验收结果与边界见同目录的验证记录：回环协议和 native HXZRE、后台浏览器、插件完整流程、错误重试及构建检查。真实服务器安装与公网 UDP 防火墙状态需在部署后使用双端自检核对；未连接 Android 真机或实体 Win7。
