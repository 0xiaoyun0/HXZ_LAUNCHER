## 音频、设置与仍有的缺口

1. **OpenAL 与 SDL 音频是不同链路。** [FCLauncher:202–222](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fclauncher/FCLauncher.java#L202) 设置 OpenSL 后端，[468–471](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fclauncher/FCLauncher.java#L468) 预加载 OpenAL。[SDLAudioManager:26–48、82–124](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/org/libsdl/app/SDLAudioManager.java#L26) 则枚举/监听设备变化并设置音频线程优先级。HXZ 已有明确 OpenAL 库路径与动态库目录，但本次没有验证设备实际出声、蓝牙切换、后台音频焦点或 OpenAL 选择的后端，也没有引入 SDL 音频类充当修复。
2. **游戏改键应影响触控语义。** [GameOption:51–96、161–222](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fcl/setting/GameOption.java#L51) 按实例读取并监听 options.txt，[MinecraftKeyBindingMapper:20–42](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fclauncher/keycodes/MinecraftKeyBindingMapper.java#L20) 解析新旧键绑定格式。HXZ 触控仍使用固定 WASD/E/T 等。尤其更改聊天键后，“键盘”按钮可能无法打开聊天。后续应设计独立的实例绑定读取层，再接入触控动作和打开聊天流程。
3. **输入框状态同步与 SDL 通道就绪。** [GameTextSender:25–85](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fcl/control/GameTextSender.kt#L25) 区分 GLFW 与 SDL 文本提交，并等待输入通道；[SdlImeController:131–186](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/org/libsdl/app/SdlImeController.java#L131) 处理输入法所有权；TouchControllerInputView 的已读部分还包含选择区、组合文本、批量编辑。HXZ 目前为独立 EditText 确认后提交，支持中文候选由 Android 编辑器先行完成；不具备游戏文本框的选择区/组合区协议、SDL 原生文本通道和 dead-key/AltGr 完整组合。UI 的 LengthFilter 仍按 UTF-16 长度计数，而底层发送上限按 code point 计数，两者上限对 emoji 不一致。
4. **陀螺仪与可编辑触控。** [Gyroscope:93–156](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fcl/control/Gyroscope.java#L93) 的捕获态门控、旋转轴映射、死区与时间重置值得独立设计；HXZ 目前没有该能力。FCL 的布局编辑、滑动连键、长按、方向锁和手势热栏也未移植，属于明确产品缺口，不等于当前固定触控按钮实现有错误。
5. **设置的作用域与迁移。** [VersionSetting:46–57](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fcl/setting/VersionSetting.kt#L46) 区分全局与实例设置；[MenuSetting:350–368、447–479](https://github.com/FCL-Team/FoldCraftLauncher/blob/a36e1e42292d6a67c93be0dafbfdceff01823e71/FCL/src/main/java/com/tungsten/fcl/setting/MenuSetting.kt#L350) 支持监听和旧字段迁移。HXZ 当前的按钮大小、分辨率百分比、灵敏度保存于全局 SharedPreferences。以后增加实例覆盖时应显式定义优先级、合法值和迁移，而非不断增加互相覆盖的 JSON 字段。

FCL 本身也不能当成无缺陷的规格。例如 TouchController.kt:107–114 在 ACTION_POINTER_UP 分支中，查找使用 Android pointerId，删除却使用映射后的 proxy pointerId；这是源代码阅读发现的潜在不一致，未用设备复现。因此本次没有把该指针映射方案照搬到 HXZ。

## 本次 HXZ 变更与验证

实际修改：`GameControlsView.java`；新增 `GamePointerGesture.java`、`GameMouseState.java`、`GameKeyMap.java`；Activity 只调整 `dispatchKeyEvent` 和新增 `onGenericMotionEvent`。`GameTouchLayout` 与 `GameTextInput` 原有行为通过定向回归后保留。

验证入口：`scripts/tests/android-touch084.ps1`。包含原有 6899 个布局/Unicode 断言，新增 10 个手势轨迹断言、85 个实体键盘/鼠标状态断言。覆盖慢速拖动、回原点、无 MOVE 直接 UP、模式切换重设锚点、鼠标双通道重复边沿、单通道空快照不提前释放另一通道的按住状态、组合按钮释放、五按钮、分辨率映射、F 键/标点/导航/小键盘以及控制字符与快捷键字符隔离。

另使用 Android 35 的 `android.jar` 对 ControlsView、NativeRuntime 与所有新增 helper 进行 javac `--release 17` 编译。上述均为本地、无人值守验证；没有连接实机、启动游戏、断言实际鼠标捕获成功或声称设备音频已验证。Activity 的完整 Android 编译由合并主审查统一执行。
