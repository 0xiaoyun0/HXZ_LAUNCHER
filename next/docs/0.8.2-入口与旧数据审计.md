# 0.8.2 功能入口与旧数据审计

## 修复的问题

- 共享社区页面仍能显示好友、小队、知识、作品与棋局工坊，旧收藏和通知可绕过导航重新打开这些页面。现在前后端共用功能白名单；历史数据保留，退役功能不再提供操作入口。
- 玩家空间不再发起好友关系、时光信、项目或旧作品操作。旧收藏保留归档提示与移除按钮，正常服务器网址与现有内容仍可打开。
- 桌面收件箱原本只识别少数路由，且会先标已读；音乐、LINKING、协会、联机任务通知可能没有动作。现在统一验证目标，内容读取失败保持未读，归档内容明确提示，未知入口不会跳到空白页。
- 安卓通知原先只识别旧蓝图库地址，现兼容新旧地址；补齐语音、论坛、联机、积分商城、游戏榜单及小游戏准备页。小游戏通知只定位内容，不自动开始对局。
- 旧跨页卡片配置中的已删除卡片不会生成空卡；合法的音乐、聊天、角色等跨页布局继续保留。
- 管理员队列和统计只统计当前功能；保留服务器对旧记录的兼容读写，不让历史数据变成死入口。

## 验证范围

- 使用已发布 0.8.1 的共享页面代码复现退役栏目仍出现的问题。
- 5 项策略测试覆盖旧深链、有效通知、外部/未知地址、记录类型白名单和旧卡片配置迁移。
- 真实浏览器点击验证桌面 1360×880、1024×768 / 22px 深色布局；检查导航搜索、管理员队列、历史收藏、个人空间、跨页卡片、通知读取顺序、旧记录伪装链接与路由兜底。
- 安卓 WebView 桥接夹具验证 320px、390px、844×390 横屏及 22px 字号，实际点击收件箱→音乐、蓝图、榜单、小游戏和社区管理；检查未知目标保持未读、旧功能归档、小游戏不自动开局。
- 相关截图已逐张查看；类型检查通过。接口与原生桥接夹具明确用于隔离回归，不代表公网用户数据、真实语音或安卓实机验证。

## 后续约束

`server/shared/hub-visibility.mjs` 是保留功能清单，`packages/hub/navigation.mjs` 负责旧链接与通知目标兼容。新功能不得只增加一个菜单，必须同步增加路由、目标处理与实际接口验证；新跨页卡片还须登记 `isPortableCard`。
