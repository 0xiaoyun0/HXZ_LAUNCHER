# 幻想镇 0.8.2 · 观测与远征

本次更新基于 0.8.1，继续精简入口，完善小游戏与 LINKING 的实际游玩流程。

- 新增「骰光远征」：分配骰子进行攻击、防御与蓄能，观察敌方预告，选择遗物构筑。
- 新增「风帆补给线」：选择航路、规划补给，应对天气与事件，改装船只完成远征。小游戏总数增至 20 款。
- 拓展怪潮生存、卡牌探险、地牢闯关的升级联动、遗物与卡牌变化；新游戏同步支持电脑和手机。
- 新增 LINKING「第三值夜：未关的观测窗」，含 7 篇档案、10 项任务、2 件纪念物，承接两卷调查后的观察与交接。章节是否开放由社区正式发布状态决定，不随安装自动解锁。
- 清理旧通知、收藏、快速前往、跨页卡片及管理员待办中通往已删除功能的入口。历史内容保留，可移除旧收藏，但不能误入已停用页面。
- 修复收件箱中 LINKING、协会、音乐等通知无法跳转，以及无效内容提前标记已读的问题。
- 管理员审核队列、分页与统计排除已退役内容；新章节管理入口依据服务端能力显示，避免连接旧服务时出现无效操作。
- 调整新游戏的决策区、暂停、结算及移动专注模式，补齐对应插画封面。

Windows x64、Windows ia32、Android 社区客户端和社区服务端同步更新。Android 构建号 80200；可选游戏运行组件 70003、游戏服务端桥 0.8.0 保持不变。
