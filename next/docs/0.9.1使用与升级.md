# 0.9.1 使用与升级

桌面安装版直接运行更新检查即可从 0.8.8、0.9.0 覆盖升级，账号、设置和游戏目录不需要清空。Windows x64 与 ia32 必须选择对应架构；ia32 便携包使用 Electron 22.3.27。

社区服务端先停止旧进程，再解压 0.9.1 服务端更新包覆盖程序文件，保留原 data、.env 和数据库。启动后会自动建立 data/hxzre 下的三个 token，并从默认服务器配置生成 HXZRE Origin；后台“默认服务器”页可查看状态。

Android 0.9.1 使用相同 applicationId 与正式签名，可直接覆盖旧版。安装前保留系统允许的未知来源权限，安装器会执行签名和版本校验；游戏运行资源会在应用内断点续传，不需要另装 FCL APK。

启动器设置中的 HXZRE 开关由玩家自行决定。开启后只有 Windows x64 且服务器提供有效 Origin 时接管上传链路，失败会回退原连接；关闭后立即使用原始连接。联机大厅的“测试本机 P2P”只验证信令、ICE 和本机回环，不会创建普通公开房间。
