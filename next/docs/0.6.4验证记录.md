# 0.6.4 验证记录

基线为 Windows x64，同步 ia32 和 Android。仅使用隔离 profile / 临时社区数据库，没有修改生产账号、游戏存档或线上服务。

## 功能

- 游戏暂停回归先复现倒计时暂停后无继续按钮，再修复并通过同一测试。
- 排行榜请求竞态先复现迟到周榜覆盖长期榜，再修复；当前游戏与榜单范围均需匹配才更新。
- 固定随机种子校验 11 款街机规则重放，保留 v5 旧规则。扫雷 108 个首步位置均安全、插旗保护与胜利判定；2048 单次合并；贪吃蛇反向输入；打砖块加宽球拍边界均通过。
- 两个独立浏览器进程、两个不同玩家身份连接真实隔离社区：创建、加入、准备、同时向相反方向移动、无权访问拒绝、断线双方暂停、重连继续、离开终止通过。不是同设备模拟两个玩家。
- 合作服务检查房主权限、旧序号拒绝、新连接序号恢复、一次结算、离开不发成绩；单人回放拒绝第二玩家控制。棋类使用真实本地 HTTP 建立三种机器人对局；狼人杀检查六人身份隔离、过期行动、完整结算、记录展开保持。

## 界面

逐一截图查看 15 款游戏相关界面。覆盖手机 320/390、横屏、平板及桌面 1360/1024、大字暗色抽查；图像位于 .runtime/game-review064。修复复查发现的房间姓名纵排、游戏按键冒泡成房间指令、手机坦克横屏过小、暂停次要按钮对比度问题。

全部 15 张封面均已替换，检查两端图片实际解码和 01–15 顺序，桌面封面 8:5 比例，手机无横向溢出。原图由内置 imagegen 生成，产品内置 768×480 WebP 总计约 1.53 MB，未依赖远程图片。标题、编号由界面渲染。暂停、图标、开始/结束、棋桌进入、房间加入/退出等操作已在截图流程中检查。

桌面收件箱/搜索按钮均 32×32，图标 17 px，描边 1.8，同色，点击分别打开对应页面。手机原生桥接用浏览器夹具接真实隔离接口，不能替代实体手机验收；实际 Windows 7 和 Android 设备的硬件、网络、触控仍需用户验收。
