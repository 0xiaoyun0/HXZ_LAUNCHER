# 幻想镇启动器 0.8.7

本次发布补齐桌面端、安卓端、社区服务端、游戏服桥接、源码和自动更新清单。

## 主要内容

- 联机：管理员可配置全员开房权限、连接上限；P2P 与公网候选并行探测，协商失败进行有限重试。
- 小游戏：简化显示只保留标题、编号、类型提示、开始和收藏，隐藏重复封面与说明；完整显示可随时恢复。
- 游玩记录：保留游玩日历与在线时长榜接口，积分按真实游玩时长结算。
- 桌面端：x64、ia32 安装包与便携包同步更新。
- 安卓端：arm64-v8a、Android API 29+，版本号 80700；沿用已验证的签名构建。
