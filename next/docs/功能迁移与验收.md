## 本轮卡片实现

以下旧版编辑模式说明由本段覆盖：当前卡片直接使用标题旁手柄及右下角缩放，自动保存、网格对齐，并支持锁定、撤销、预设宽度、适应内容、同排等高、隐藏恢复。普通设置仍有未保存提醒；布局无需进入编辑模式，也无需另外点击保存。首页“欢迎”卡片改为快捷入口。设置默认按内容高度排列。具体操作见 卡片版验收说明.md。

- 启动页、账号、聊天（消息/在线伙伴）、语音房间、游戏厅、安装配置、积分榜、实例概览与设置分组接入布局编辑器。
- 编辑时拖标题和右下角；也提供上移、下移、宽窄、高低按钮。平常禁用拖拽，避免干扰输入与游戏。卡片可隐藏、找回；每页能恢复默认，设置可以恢复全部布局。
- 布局保存在独立 profile/settings.json 的 cardLayouts，窄容器与宽容器分别保存；隐藏保留卡片尺寸。卡片底色、间距、圆角、不透明度可调，最低不透明度 20%。弹窗与任务面板保持实色。
- 离开布局编辑时询问保存/放弃；现有设置未保存提醒继续保留。保存普通设置不会覆盖刚编辑的卡片布局。
- 轻缓页面过渡、弹窗、菜单、卡片移位；跟随动画速度设置和系统减弱动态效果，关闭时 CSS 与 Motion 均停用。拖动期间不做延迟动画，松手后平滑归位。
- 动态帖子、蓝图、商品、聊天消息仍按业务列表排列；它们不是逐条自由拖拽的桌面挂件。游戏画布和 Linking 内容逻辑没有重写。
- 服务监控通过桌面主进程只读读取 uptime.hxzmc.top，30 秒缓存，页面可见时每分钟刷新，失败/过期显示待确认，沿用后台分组与名称。
