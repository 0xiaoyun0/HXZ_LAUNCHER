# 幻想镇 NEXT 0.9.1

0.9.1 是 0.9.0 的兼容修复版，重点收口 HXZRE 全链路、联机大厅状态、P2P 自检、后台管理界面和 Android 游戏引擎设置，并保持旧版覆盖升级路径。

## 联机与 HXZRE

- 修复本机 P2P 自检先等待回包后才发送探测数据导致的必然超时；测试房间使用短时效格式并允许普通登录用户完成自检，不改变普通房间的开房权限。
- 默认服务器服务端启动时继续自动生成三个 HXZRE Origin 与持久 token；后台“默认服务器”页新增 HXZRE 状态卡片、参数和服务端开关，token 不在界面显示。
- 启动游戏时继续在任务面板即时显示 HXZRE 检查、已启用、回退或用户关闭状态。客户端开关仍由用户决定，服务端和客户端不需要手工填写 token。
- 联机大厅在线人数查询修正 SRV 解析后的握手主机名，新增强制刷新参数并显示查询错误；桌面卡片显示在线/上限和公开玩家名单，后台可立即检查三个入口。

## Android 与兼容性

- Android 版本号为 0.9.1 / versionCode 90100，沿用 0.8.8 签名与覆盖安装身份。
- 修复 Android 11 及以上安装错误 `-124`：发布 APK 的 `resources.arsc` 现在保持未压缩并经过 4 字节对齐，覆盖升级和首次安装使用同一包。
- 游戏运行设置增加自动兼容与完全原生 FCL（EGL）选择、内存/交换预算、分辨率、触控大小和灵敏度；映射到同一运行请求，保持一个安装包。
- 允许 4 KiB 与 16 KiB 内存页设备进入运行模块检查；Release APK 的 arm64 ELF 通过 16 KiB 对齐检查。最低 API 仍为 29，未连接实体 Android 真机。

## Windows、升级与后台

- 重新构建 Windows x64 与 ia32 安装包和便携包；ia32 继续使用 Electron 22.3.27 兼容构建，保留 Windows 7 兼容路径。
- 更新清单使用 versionCode 90100，保留断点下载、签名校验和旧版本覆盖安装；旧版安装版可直接通过现有清单升级。
- 后台管理页面统一卡片、间距、响应式网格和状态徽章，连接与服务器维护区域集中显示 HXZRE、在线玩家和 P2P 相关设置。

## 本机验证

- 社区 P2P 自检、Minecraft 状态协议、在线人数强制刷新和 HXZRE 自动配置回归测试通过。
- `npm run typecheck`、移动端 Vite 构建、桌面 Vite/Electron 构建、网站构建和 Android Release 构建通过。
- Android APK 通过 v2 签名校验以及 arm64 16 KiB ELF 对齐检查；未连接 Android 真机，未宣称完成实体 Win7/Android 设备验收。
