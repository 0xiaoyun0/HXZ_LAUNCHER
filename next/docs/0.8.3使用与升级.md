# 0.8.3 使用与升级

## 玩家

1. Windows 安装版使用内置更新，或运行对应系统架构的 0.8.3 安装器。便携版解压完整新包并保留原 `profile`；不要只替换一个 EXE。
2. Android 安装 `HXZ-Community-Android-0.8.3-80300.apk`，包名和签名沿用正式版，支持 Android 10 及以上。游戏运行组件是可选的 ARM64 APK；更新到 80300 后才会应用组件中的下载修复。
3. 使用皮肤站账号登录。注册会打开 `https://skin.hxzmc.top/auth/register`。已经登录过的账号可继续使用本地缓存，社区暂时断线不会清空账号。
4. 在资源页的下载节点中检测当前网络。检测的是公共样本与响应头延迟，并非所有文件的完整测速；真实下载会按适用文件类型切换来源。
5. 首页选择服务器后点“安装并开始”；下载异常时在任务与日志中查看原因并继续，避免手动删除正在安装的目录。
6. 新引导可以跳过或收起。电脑在设置的帮助与反馈中重放，安卓在“我的”中重放。

## 社区服务端

只运行一套社区服务。`HXZ-Community-0.8.3-windows-x64.zip` 是完整包；`HXZ-Community-0.8.3-update.zip` 是后台签名更新载荷，不是第二个服务端。

升级时备份并保留原 `data` 和 `.env`，通过原服务管理程序执行更新。历史成绩、积分余额、物品、委托和 LINKING 数据不能用空目录覆盖。重启前通知正在进行联机小游戏的玩家先结算；未提交的在线局不会跨服务重启保留。

Minecraft 游戏服务端桥沿用已发布的 0.8.0 MCDR / NeoForge 文件，没有新增安装要求。LINKING 不发布新剧情，也不重置音乐外观的任务门槛。

## 界面与验证

卡片的尺寸、自动高度和滚动边界规则记录在 [UI 卡片规范](UI卡片规范.md)。下载源用途、取样结果和重试边界记录在 [下载源与恢复](0.8.3下载源与恢复.md)。

本轮对安装参数、下载挂起与切源、散列校验、旧版运行时、游戏规则与服务端结算、登录门控、功能引导和卡片布局进行定向回归。桌面与手机浏览器截图使用隔离桥接数据，不是真实登录与 Android 实机验收。发布验收记录会区分原生构建、浏览器回归、真实设备和线上升级结果；不把编译通过视为所有设备都不会崩溃。
