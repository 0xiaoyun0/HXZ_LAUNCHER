# 0.7.3 部署与验收

## 升级

安装版使用已签名更新；便携版退出后覆盖程序并保留 profile、launcher-cache、游戏目录和 Java。新构建位于 release/0.7.3，按 windows-x64、windows-ia32、android、server、updates、source 分组。不要用新的空数据目录替换线上数据。

社区更新前备份现有 data（包含 SQLite、附件及相关状态）与 .env。后台自动更新使用 community-update.json 和 update.zip；首次部署 Windows 使用完整服务端包，两者选其一。数据迁移仅增加反馈版本、平台和操作审计字段，不清空排行榜、钱包、背包或委托。

反向代理继续放行 /ws 和 /lobby-signal 的 WebSocket Upgrade。联机信令只做授权与协商，不转发游戏流量。P2P 受双方 NAT、UDP、防火墙和运营商环境影响，不能保证所有网络均可连通；可切换公网地址、端口映射或已有虚拟局域网。

邀请携带本次房间凭据，请私发。新格式为 hxz-room://join/…，有效内容放在路径里，避免浏览器改写大小写。旧 HXZROOM 邀请仍可粘贴；已经被其他软件改坏的内容需重新复制。

加入会核对版本、加载器版本及启用模组的 SHA-256 摘要。默认服从社区管理员配置地址安装，下载后再次核对；自定义含模组的房间若无可信整包来源，要求先导入房主提供的整包。不会猜测模组或使用邀请提供的任意下载脚本。

默认快捷键为 Ctrl+Alt+Shift+C（游戏内聊天）、V（退出语音）、M（停止音乐）、L（收回歌词）。设置中可修改或禁用，占用时提示冲突。全屏独占游戏可能遮住系统覆盖窗口，使用无边框或窗口模式。

## 已完成的针对性检查

- 复现并修复同一网络包连续发送 READY 与协商消息时丢包；旧格式、新格式、大小写、结尾斜线及带说明文字的邀请解析通过。
- Windows x64 和 ia32 原生 Electron：两个客人同时连接，每个 2 MiB 校验回传，包含慢读端背压。
- 原生覆盖：真实 contextBridge/IPC 传递普通消息快照、两类窗口显示、聊天发送、快捷键暂停与恢复、隐藏和退出频道清理通过。
- 游戏目录：中文目录实例识别、模组变化识别、导入旧 gameDir 的 HXZUP 配置纠正；PCP 编解码和响应归属校验。
- 隔离社区：反馈提交、诊断脱敏、权限隔离、并发修改冲突、回复后重开、归档、删除；新游戏规则回放、结算和排行榜入口。
- 桌面截图：三款游戏普通/专注，反馈详情与提交，浅色及 1024×768 大字号暗色；手机模拟 390px、横屏游戏、320px 反馈与处理流程、卡牌操作，联机页面与安装确认弹窗。修正暗色手牌对比度与专注背景；截图保存在本机 .runtime/review073/screens。

## 验证范围

上述联机测试在本机隔离服务上完成，并非跨运营商、对称 NAT 实测。PCP/路由器映射已校验协议与错误处理，本机未有所有协议路由器实机。Android 目前完成网页模拟与 APK 构建检查，不冒充实体手机验收；ia32 在 64 位 Windows 上运行，不代表实体 Windows 7 已验收。未操作线上社区数据库或真实玩家文件。

Android 社区版本号 70300；本轮没有修改独立的 Minecraft 运行组件，继续使用已签名 70003 引擎及其下载地址，避免强制重复下载引擎。
