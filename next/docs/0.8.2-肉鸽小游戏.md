# 0.8.2 肉鸽小游戏

新增两个独立机制的游戏，目录总计 20 款，新增「肉鸽探险」筛选共 5 款。PC 和 Android 使用同一确定性规则与控制器，不另存一套手游规则。

- 19「骰光远征」：12 场遭遇。选择骰面后分配攻击、护盾、修复或蓄能，读取敌方下一回合意图；每回合一次重掷、一次修复。8 类可叠加或相互配合的遗物。
- 20「风帆补给线」：12 站航行。5 类航线、3 种天气、15 个事件选项、8 类改装；船体、燃料、食物和金币决定可行路线。成本和风险提前显示，补给不足会明确提示额外损伤。
- 原有怪潮与地牢增加冰霜减速、贯穿、连锁、受击反伤、周期回复、处决构筑；卡牌增加反伤、格挡保留、群体毒伤、战斗强化、盾击和连奏，共 16 张卡。

## 接入与兼容

规则入口：`server/shared/arcade-engine.mjs`；新增回合游戏规则 `arcade-tactics.mjs`，渲染与触控为 `packages/games/arcade-tactics-renderer.mjs`。`scripts/sync-games.mjs` 同步社区服务及 Android 共享模块。新增 WebP 封面位于 `public/media/games` 与 `mobile/web/public/media/games`。

新客户端请求规则版本 8，旧版本 7 的引擎及肉鸽规则冻结保存，老客户端仍可提交原规则成绩。排行榜、年度积分和用户余额不迁移、不重置。服务端只接受种子与合法操作序列，重放后算分，不信任客户端分数；继续使用已有每周、长期榜和周积分结算。
