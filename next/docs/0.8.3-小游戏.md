# 0.8.3 小游戏

目录仍为 20 款：16 款单机挑战、3 款棋类和狼人杀。肉鸽筛选仍为 5 款。本次没有新增游戏，也没有重置历史成绩、周榜、长期榜或积分。

## 本次调整

- **骰光远征**：第 3 场起可能出现可预判的蓄势，第 5 场起可能出现汲取生命。蓄势当回合不造成伤害，下一回合显示重击数值；汲取只按实际穿过护盾的伤害恢复生命。双响铃与蓄能同时持有时，偶数攻击骰得到额外联动伤害，控制区显示结算前数值。早期仍保留原有攻击、穿透和护甲意图，避免开局突然增加负担。
- **风帆补给线**：船体降至 10、燃料降至 4 或补给降至 4 时，途中事件的第三个选项变成「应急停泊」。选择后恢复船体、燃料和补给，放弃该站的基础事件分数，为资源决策失误提供恢复选择。航路的成本、损伤范围与原有事件选择仍提前显示。
- 两款继续采用不同的决策：骰子读敌方意图并分配四枚骰子；航路在天气、航线、补给和事件间取舍。怪潮、卡牌、地牢及其它阶段挑战保留各自的既有机制。本次没有把 0.8.2 已有的 16 张卡、遗物、怪潮构筑和 12 场/站设计算作新内容。

## 规则与成绩兼容

0.8.2 已发布的规则版本 8 已复制成固定的 `arcade-*-v8.mjs` 规则依赖图；这些模块仍引用未改动的 `contra/core.mjs`。新版客户端请求规则版本 9。服务端按照每局开局时的版本，用种子和合法操作序列重放计分。主动结束本局仍能提交当前进度，客户端提供的分数不会入榜；旧 v8 客户端和 v7 及更早规则继续保留。结算后重复请求返回同一结果，不再重复记分。

## 验证与限制

- 真实本地 HTTP 与 SQLite：v8 和 v9 的 16 款单机小游戏逐一开局、结算，服务端分数与对应规则重放一致；v9 航路另完成开局、检查点、完整结算和重试。旧规则与棋桌、周积分、长期分数相关回归共 27 项通过。
- 骰子和航路各用谨慎、机会、冒进三种自动策略跑 24 个种子，完成局与分段重放均一致。骰子通关分别为 24/24、18/24、1/24；航路分别为 24/24、0/24、0/24。后两种航路策略没有主动使用应急选项，暴露了资源管理对这类固定策略的影响。**这些是自动策略探针，不代表真人难度或留存结论。**
- 桌面实际 React 页面与手机实际 Vue 页面已截图检查普通、专注、320/390px、22px 大字、航路事件与骰子升级弹窗，截图及页面夹具位于 `.runtime/review083/games/`。夹具不连接公网社区；真实 HTTP/SQLite 另行验证。未做 Android 真机触控和真人平衡测试。
- 仅共享 JavaScript 规则、控制器和网页资源发生变化。已运行共享文件同步、TypeScript 类型检查、桌面 Vite 构建及手机 Web 构建；无需 Java 编译或 Android 资源构建。
