# 幻想镇 NEXT 0.9.0

0.9.0 将丢包恢复、联机诊断和小游戏目录整理合并到同一个交付版本，并保持 0.8.8 的覆盖升级路径。

## 联机与传输

- 三个默认服务器沿用 HXZ UP 的更新配置，并增加可选的 `hxzre` 前向纠错边缘端。社区服务端升级后会自动生成持久 token、启动三个 origin 并下发配置，不需要再编辑后台或修改客户端。
- 桌面启动器设置中提供“启用上传前向纠错补偿”开关。打开时只对已配置 origin 的服务器启动本地 FEC edge；关闭或 edge 启动失败时自动回到原服务器地址。
- 社区服务端附带 `resources/hxzre` 与 `fec-origin.mjs`，默认 origin 使用启动器内置的三个目标端口；自定义部署可通过 `.env` 覆盖。FEC 仍保持普通 TCP Minecraft 服务端兼容。
- 联机大厅加入“测试本机 P2P”，会通过社区信令建立一次本机回环数据通道并显示延迟，帮助玩家选择 P2P、直连或中继。
- 社区中继作为认证后的备用通道接入大厅，默认开启。管理员可通过 `/api/admin/lobby/relay` 关闭或调整每房间带宽上限；客户端设置也可关闭中继回退。
- 联机邀请继续使用短时效、房间密钥和证书指纹。中继只允许已登记房主的房间，不接受任意目标地址。

## 小游戏与界面

- 桌面和移动端共用稳定的小游戏目录，固定排序、连续编号和封面路径，避免服务端返回顺序变化造成卡片乱序。
- 所有小游戏封面使用统一的安全裁切比例、懒加载和版本查询参数，保持桌面卡片与移动卡片的留白、编号和操作位置一致。
- 联机大厅、设置页和移动端页面沿用现有按钮、开关、卡片和状态提示样式；P2P 测试入口在有连接检查结果时仍保持可见。
- 清理实际前端入口中的历史重定向与失效功能引用，保留历史文档和存档数据以便追溯。

## 发布与升级

- 桌面版本：`0.9.0`，同时生成 Windows x64 与 Windows ia32 包。
- Android 版本：`0.9.0`，versionCode `90000`，沿用 arm64-v8a 运行模块校验和覆盖安装策略。
- 0.8.8 及更早桌面版本可通过原有更新清单升级到 0.9.0；Android 覆盖安装会保留账号、设置和游戏资源缓存。

- 桌面网页、Electron 主进程、社区服务端、Windows x64/ia32 包和 Android release APK 构建。
