# 幻想镇 NEXT 卡片界面规范

适用版本：0.5.2-air 及后续功能。2026-09-29。用户已确认当前灰蓝、柔和、轻缓的卡片设计语言；新增功能继续使用此体系。此文在音乐播放器开发前建立。

## 组件与职责

- 页面功能区域统一使用 `CardBoard`，每个 `CardSpec` 必须有稳定且唯一的 id、简短标题、最小宽度及业务内容。禁止用数组序号作为可变列表的业务 id。
- 设置分组使用 `FormCards`；固定组合可使用 `PanelGroup`，显式提供 `data-card`，防止插入新功能后旧布局错配。
- 商品、作品、歌曲等数据集合使用 `CardCollection` 与 `ContentCard`，按容器实际宽度换列。集合属于一块功能区域，逐条内容不必成为独立桌面挂件。
- 按钮组使用 `CardActions`；按钮、选择器、对话框、开关使用 `ui.tsx`。不要另建原生 select、浏览器 alert 或带独立主题的弹窗。
- 页面只负责内容与业务状态；拖动、尺寸、锁定、显隐和持久化由 CardBoard 管理。不要在业务组件中复制网格算法。

## 尺寸与排列

1. 默认按内容自动计算高度；宽度维持 12 列网格，松手自动对齐。每卡菜单可切换自动或固定尺寸，手动拉伸进入固定尺寸；拖动不关闭自动尺寸。最小宽高由控件的固有尺寸和内容测量决定，并保留业务指定下限；固定尺寸也不得小于可用下限。长列表测量最小高度时保留可滚动视窗，不要求整个历史全部展开。
2. 长消息、日志、文件列表有视口高度上限并在内部滚动，不能随记录量无限撑大。内容变化可增高也可缩短，ResizeObserver 必须释放，测量不得产生自激增长。
3. 隐藏保留配置；锁定暂停自动改变位置与尺寸；切换窄/宽布局各自保存。撤销应同时恢复尺寸模式。
4. 新卡片不可覆盖已存的其他卡片配置。自动测量不向磁盘逐帧写入，只在用户操作时持久化。
5. 栅格子元素及文字容器必须 `min-width:0`；集合用 `repeat(auto-fit,minmax(min(100%,260px),1fr))` 或模板默认值，不用固定三列挤压窄窗口。
6. 内容区使用 16–20 px 内边距，组间 16–24 px，相关操作间 8–12 px。禁止依赖大量空行、负 margin 或固定高度撑版面。
7. 临时内容测量必须保留内部消息、日志等滚动区域的位置；不能因一次输入或打开菜单回到列表顶部。表情、菜单等浮层放在 Portal 中，不参与卡片内容最小尺寸的计算。

## 字体、按钮与媒体

- 标题、正文、提示分别继承统一字阶与主题色；不要给正文添加发光或渐变。长标题允许换行；长路径/链接可折行并提供完整 title。
- 主要操作至少 36 px 高，按钮不被价格或描述挤扁；操作区可换行，不能覆盖正文。商品价格与兑换按钮置于独立底部区。
- 下拉触发器保留原有外观和表单整行宽度，不为修复菜单而缩小选择框。展开菜单至少容纳触发器，按最长选项取宽，超视口时换行并滚动。勾选标记不得挤掉文本。
- 媒体封面有明确比例、裁剪方式和加载失败占位。播放器采用紧凑封面，不用大幅装饰图挤占控制区。
- 弹窗保持实色、可滚动且关闭按钮可见；卡片不透明度不得低于 20%。
- “主要面板”与“卡片不透明度”是同一项偏好的两个入口，不叠乘；主导航、底部状态栏各自独立，不得展示不生效的设置。弹窗保持实色。
- 改变卡片宽高后，内部文字折行、按钮换行、输入框伸缩、媒体等比缩放；保留列表内部滚动。不能仅缩小外框，留下溢出的内容。

## 状态与动效

- 必须设计空、载入、失败、断网、无权限、禁用和成功状态；错误说明原因和可执行操作，禁止无响应按钮。
- 读取响应式状态必须通过当前组件快照。渲染使用 `selected(snapshot)`、`account(snapshot)`、`cfg(id,snapshot)`；事件处理器按需读取最新状态，避免保存成功界面未更新。
- 进度只呈现真实计数、字节和事件。总量未知显示进行中；当前步骤百分比不得冒充整包百分比。失败不能显示成功或自动填到 100%。
- 默认短距离、低幅度动效；继承 `--duration` 和系统减弱动态效果。拖拽过程不延迟，关闭动画后菜单、页面、卡片均停用动效。
- 音频状态独立于路由，切页不停止播放；进入一起听前需用户主动选择，离房不残留远端播放控制。

## 可整理导航

- 新增页面仍采用功能卡片；入口在统一路由清单中定义，不能直接在标题栏散加按钮。“更多 → 整理主导航”负责固定/收回，设置按稳定路由标识持久化，后端只接受允许的标识。
- 固定与显隐分别管理：隐藏的功能不因固定而重新出现；重新显示后恢复固定偏好。Linking 继续遵循发现和显隐设置。
- 根据实际可用宽度与字体测量决定是否只显示图标；图标始终具有可访问名称与悬浮名称，不能让导航挤占窗口按钮。商城等子入口被固定时，只高亮匹配的栏目。
- 验证放出、收回、重启、窄窗口、多个入口同时固定，以及设置页入口和右键入口。原有未保存更改提示必须保留。

## 新功能模板

```tsx
const cards: CardSpec[] = [
  {id:'player',title:'正在播放',w:5,minW:4,content:<PlayerControls/>},
  {id:'queue',title:'播放队列',w:7,minW:5,content:<MusicQueue/>},
];
return <CardBoard id="music" cards={cards}/>;
```

集合示例：`<CardCollection><ContentCard title={item.title} media={...} footer={<Button>操作</Button>}>描述</ContentCard></CardCollection>`。

## 最小验收

用户最新要求：每次 UI 改动都要自己截图并查看，验证相关页面全流程设计与功能；不能只用 DOM 数值或构建成功代替视觉检查。基础卡片或导航修改影响多个页面时，要扩大到受影响页面。新增或改动的页面检查 1360×880、1024×768 以及 22 px 字号；浅/暗主题、关闭动画各抽查一次。验证长标题、空列表、多条记录、失败提示、下拉、弹窗、拉伸、收起与恢复。真实接口操作与模拟状态必须在报告中分开注明；本地夹具不冒充公网验收。

## Android 0.6.0 卡片约束

- 手机使用单列内容卡片与最多五个主导航入口；发现页可使用两列入口卡。平板按内容扩展，不能直接压缩桌面网格。
- 按钮主要触控区至少 44px；文字列使用 min-width:0，标签与操作按钮按语义换行，禁止逐字挤压。
- 同一页面保留一个主滚动容器，固定导航不参与页面进出变换。棋盘保持比例，内容过高允许页面滚动。
- 卡片透明度最低 20%，弹窗保持实色；弹窗与选择器共享组件，不能直接复用原生 select 破坏样式。
- 共享组件的 scoped 样式必须同步检查；根主题选择器不能假定覆盖其高权重布局。
- 新增页面验证 320px、390px、横屏与平板，截图查看按钮、弹窗和真实有数据状态；模拟桥接检查须与原生实机验收区分。

## 独立歌词窗口（0.6.2）

桌面歌词属于独立原生透明窗口，不得加入主页面 Grid 行或改变卡片、正文、状态栏尺寸及透明度。拖动与锁定在原生窗口处理；文字不使用页面卡片背景。关闭主窗口继续播放是默认关闭的独立偏好，托盘必须提供恢复、解锁和彻底退出。浏览器预览回退使用 body Portal，文字点击穿透，只有控制区接收鼠标。其动效同样遵循关闭动画。栏目切换仅重置外层页面滚动，不重置聊天历史等内部容器。
