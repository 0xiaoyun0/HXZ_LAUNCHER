# 音乐播放器与卡片修复

版本：0.5.2-air，2026-09-29。本地验收，不上传 GitHub，不修改公网服务。

## 界面规范先行

先建立 [UI 卡片规范](UI卡片规范.md)，再制作播放器。`CardBoard` 负责可编辑功能卡片，`CardCollection` / `ContentCard` / `CardActions` 负责内容集合与操作区。商城已使用集合模板，不再把商品、价格和按钮挤在固定列中。

所有布局卡片默认持续按内容调整高度，同时维持网格宽度；每卡菜单有“按内容自动调整”开关。手动拉伸会切到固定尺寸，拖动不会关闭自动调整。长列表有视口上限、内部滚动；锁定暂停自动尺寸。页面卡片面板可全部恢复自动尺寸。自动测量不会逐帧写盘。

## 功能修复

- 实例切换原因为渲染时从可变状态直接读取选中实例，遗漏响应式订阅。保存成功仍显示旧实例。现在首页、实例管理、账号卡片和游戏库通过快照读取，切换后立即同步。
- 安装任务改为当前步骤百分比、完成数量/字节、速度、接收流量、耗时、阶段历史、正在处理文件与可检索日志。阶段切换保留旧统计，停止变化提示与失败步骤单独显示。总量未知时不伪造百分比。
- 修复部分单文件下载把每个网络块当作累计下载量，以及采样时间被普通状态消息干扰的问题。
- 下拉触发器按最新反馈保留原外观和表单整行宽度；仅展开菜单按实际选项取宽，至少与触发器一样宽，长项可换行并受视口约束。

PCL 调研参考其[任务管理实现](https://github.com/Meloong-Git/PCL/blob/main/Plain%20Craft%20Launcher%202/Pages/PageSpeedLeft.xaml.vb)：状态摘要与任务步骤分开显示。NEXT 使用自身安装事件和计数，未复制其 UI 代码。

## 音乐使用

“更多 → 音乐播放器”，或设置的外观页入口。四张功能卡片可拖动、缩放、显隐：正在播放、我的音乐、网易云、一起听。

- 本地导入复制到本程序 profile/media，不移动或修改原文件。最多 500 首、一次 50 个文件、单文件 256 MB；分块处理，避免把大文件全部读入内存。
- 播放/暂停、前后曲、拖动进度、音量、列表循环/单曲循环/随机播放。切换页面继续播放，底栏保留小播放器。原背景音乐迁入音乐库，不再开机自动发声。
- 网易云按歌名/歌手搜索或添加歌曲链接。只使用可用外链；不能播放的会员或受限曲目给出错误，不宣称突破权限。音频先在本机准备，在线缓存设 256 MB 上限；移除曲目只清除启动器副本。
- “我的音乐 → 导入歌单”接受公开网易云歌单链接或 ID，批量加入音乐库并去重，展示新增/重复/受限/容量限制数量。只导入歌曲信息，点击播放时才准备音频；私密或受限歌单不能保证可读。以官方公开歌单 3778678 验证 200 首导入、再次导入 200 首去重。接口事实参考 [网易云 API 文档](https://binaryify.github.io/NeteaseCloudMusicApi/) 并核验公开接口；没有部署额外第三方音乐服务。
- 一起听复用现有社区语音房间及 ws-opus-v1。加入收听默认无麦克风采集；主动分享后发送播放器音频，同房间成员直接听到。接收端无需安装新服务器；旧客户端只需加入同一语音频道。共享音频而非跨客户端队列同步，没有上传原音乐文件、房间持久歌单或独立音乐房间管理。
- 麦克风静音和按键说话仍只控制麦克风；分享音乐不会暗中开麦。离房/断线清掉分享状态，播放器仍可本地继续。

## 文件兼容边界

| 文件 | 状态 |
| --- | --- |
| 三个平台导出的普通 MP3 / FLAC / WAV / OGG / Opus / AAC / M4A | 按音频签名识别并导入，实际解码取决于运行时支持 |
| 网易云 NCM | 支持带完整内部音频密钥的常见格式，边界检查及分块处理 |
| QQ 旧 QMC0 / QMC2 / QMC3 / QMCFLAC / QMCOGG | 支持静态密钥的旧版 QMC v1；扩展名相同但算法不同的文件可能不支持 |
| QQ MFLAC / MGG 等新版加密文件 | 当前不解密，提示从原客户端导出通用音频 |
| 汽水专有加密缓存 | 没有用户样本及配套播放密钥，当前不解密；普通音频可以导入 |

不能将“支持某个平台导出的普通音频”解释成“支持该平台所有缓存版本”。没有检索用户账号数据库或提取客户端密钥。

格式调研：NCM 字段及算法核对[文件解析实现](https://github.com/rio4raki/NCMdump/blob/main/ncm_converter.py)；QMC v1 的格式常数及边界核对[解析实现](https://github.com/bczhc/qmc-decode/blob/main/QMC2-decoder/qmcflac.cpp)。新版 QMC 存在需要外部 EKey 的变体，见[支持格式说明](https://github.com/bczhc/qmc-decode)。汽水的音频信息与解密流程依赖额外字段，见[实现说明](https://github.com/guowenye/qishui-api)。这些来源仅用于格式与事实核对，未引入对应软件作为依赖。

## 已做验证

实例切换有修复前失败、修复后成功的真实服务层 UI 复现。卡片增长/缩短、固定模式重载、直接拖拽/撤销/拉伸/锁定、间距检查通过。商城 1360 和 1024 宽度、不同长度菜单与精确阶段百分比已检查并查看截图。

本地自制 WAV / NCM / QMC 夹具验证导入、跨加密块、中文路径、损坏文件拒绝和原文件保留。网易云真实搜索返回 25 项，一首外链音频成功取得；不代表所有曲目可用。两浏览器端实际 Opus 编解码验证分享音频到接收端、不开麦、切页播放及离房清理。转发使用本地协议夹具，公网多人音质仍需用户验收。原语音/聊天九项相关检查通过。

类型检查和桌面生产构建通过。x64、ia32 原生运行验证了设置与收藏并发落盘、默认实例删除保护、中文实例、File 路径回退、本地音乐实际解码和切页继续播放。原生测试暴露并修复了内部 hxz-media 协议缺少 CORS 声明的问题；仅对受路径校验的内部媒体启用，不关闭浏览器安全设置。没有做实体 Windows 7 或 Android 验收。

脚本位于 `.runtime`：`repro-instance-switch.mjs`、`verify-card-auto.mjs`、`verify-direct-cards.cjs`、`verify-new-ui.mjs`、`verify-music-files.mjs`、`verify-music-room.mjs`、`verify-native-music.cjs`。所有测试使用独立 profile 或本地协议夹具，未操作真实账号、购买商品或向公网语音房间发送音乐。
