# 0.7.0 下载与 Android 运行引擎

2026-10-12。以维护者源码、官方元数据和镜像运营者文档核对。本文记录 0.7.0 的实际实现和验证边界。

## 已复现的启动失败

Minecraft 26.2 元数据中的日志为 client-1.21.2.xml，SHA1 39384bd14c0606d812afec88d8aff595b2587dd9；1.21.1 为 client-1.12.xml，SHA1 bd65e7d2e3c237be76cfbef4c2405033d7f91521。实测两份文件在 piston-data.mojang.com 和 launcher.mojang.com 的对应 v1/objects 路径均返回正确文件，原 BMCLAPI 对应路径均为 404。

0.7.0 内置这两份已按元数据散列校验的安全日志配置，匹配散列时直接使用，避免一份 1 KB 文件阻塞启动。未知版本仍获取元数据指定配置，失败时仅对 log4j2 类型回退到本地 Console/File 配置，保留 latest.log 与禁用消息查找。取消或本机文件权限错误不能伪报安装成功。

下载器已增加单节点暂时错误最多五次尝试、404 等永久错误在本次文件任务中跳过；低速不强等五次。保留每个来源独立的断点文件、内容校验和原子替换。原版依赖镜像应为 BMCLAPI /libraries，Forge/Fabric 等为 /maven，不能混用。Node 与 Java 安装器均已同步；Java 8 客户端组件重新编译。并发 32、官方优先，按文件种类选择适用的备用源。

分段最后一块失败时保留其余块，继续下载剩余部分，已有进度会重置等待预算。针对性验证覆盖五次失败后下一次成功、只重试尾块而不重下首块、慢速源切换、取消及日志回退。无法访问的永久错误不会无限重试；连续没有进展最终保留下载状态并给出继续操作，避免无期限占用任务。

新增适用的 Mojang 官方备用域名、Maven Central、阿里云 Maven、华为云 Maven。只在对应文件类型中使用，不把 Maven 仓库伪装成 MC 本体或 Modrinth 镜像。保留 BMCLAPI 与 MCIM；未验证的网上地址不加入自动下载。

依据：[Mojang 版本清单](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json)、[阿里云 Maven](https://developer.aliyun.com/mirror/maven)、[华为云镜像说明](https://support.huaweicloud.com/usermanual-mirrors/mirrors_hlp_0001.html)、[MCIM 运营文档](https://docs.mcimirror.top/)。

## FCL

[FoldCraftLauncher](https://github.com/FCL-Team/FoldCraftLauncher) 调研固定于 efe4dcc5dbc78c55be177c330239e12845ae7ccf。当前是 Android Java 游戏运行环境，具有安装器、Java 8/17/21/25、Forge/NeoForge/Fabric/Quilt、触屏控制、渲染器与配置；原生后端 Amethyst，非普通 WebView。当前根源码 GPL-3.0，与幻想镇社区的许可分别保留。运行组件应隔离进程与依赖，避免游戏崩溃带走语音或社区账户。

Manifest 的现成导入入口只接收 ZIP/MRPACK，不提供一个能直接完成幻想镇登录、HXZUP 安装和启动的通用公开 Intent。0.7.0 因此制作独立的 top.hxzmc.gameengine 组件，使用同签名权限保护本地调用：HxzBridgeActivity 接收一次性任务，HxzRunner 调用 GameBuilder、安装加载器与 Fabric API，再执行 AndroidPack 的 HXZUP 映射和皮肤站外置登录。运行令牌只驻留内存。

原始下载配置改为官方优先、32 并发，保留 BMCLAPI 回退；游戏目录、Java、触控和渲染器由引擎管理。社区端可配置内存、启动前更新、自动进服及仅安装。HXZUP 跳过桌面运行库和版本元数据，保护存档与截图。私有签名不包含在源码中。已构建 ARM64 Release 组件，并检查包身份与签名；实际手机 GPU、加载器、大型模组和三服进服仍待实机验证，功能标为实验性。

构建使用 Gradle 8.14.4、JDK 21、SDK 35、NDK 30、CMake 3.31.6；详情与对应源码一起交付。社区本体仍支持 Android 10 及以后版本，不强制安装游戏组件。

源码、调用边界与对应许可将随运行组件保存；不使用上游仓库内的签名私钥，不沿用上游应用身份发布修改版。
