# 幻想镇 0.8.5

## 游玩日历与在线周榜

游戏主页新增热力日历，按北京时间显示每日、每周、每月时长。选择「本机游玩」查看这台设备实际运行游戏的记录；选择「服务器在线」查看可信默认游戏服核验的记录。点击日期查看详情，宽窗口可切换半年与全年，手机自动采用紧凑范围。

每周在线时长榜支持管理员配置奖励开关、最低有效分钟、每日最多计入分钟及各名次积分。规则按周保存，修改在下周生效；周一结算，重复运行或服务重启不会重复发奖。奖励计入到账周的积分账户并发送收件箱通知；历史名次和奖励保留。

只有经过社区授权的游戏桥核验在线状态能参与周榜，跨服和多设备重叠时段合并。客户端上报运行时长不能换取积分。网络中断不会补记未经确认的时段。在线不等于实际活跃，无法识别全部挂机；默认每日计入上限8小时、最低每周30分钟，管理员可调整。

## 所见即启动

每个实例右侧独立提供启动或安装并启动按钮，直接针对该实例操作。选择实例仍可查看其配置，右键管理功能继续保留。原开始游戏卡片改为实例详情，显示版本、Java、内存、更新方式和运行状态；运行期间可停止游戏。

## Android

80500覆盖安装保留账号、游戏与设置，日历和周榜与桌面端一致。沿用80420修复及运行模块，保留可选交换内存扩展预算，默认关闭。交换空间不能替代物理内存，提高上限可能增加卡顿。

## 升级与统计边界

- Windows安装版、Android与社区后台继续使用签名更新通道。便携版使用完整包升级并保留profile。
- 社区服务端更新前备份数据库、配置和上传文件；使用后台更新或解压到新目录后迁移data、uploads及.env，不能删除旧数据。
- 服务器在线统计从0.8.5接收可信游戏桥连续报告后开始，不捏造旧版在线历史。游戏服需部署现有游戏桥并在后台授权；只有客户端升级不会产生可信服务器在线数据。
- 本机计时保存最近365天，运行时约30秒落盘一次；异常退出只保留最后一次已落盘记录，不把离线间隔算作游玩。准备资源时间不计入。
- Android大型整合包和部分GPU仍可能低帧率或不兼容。已确认小米平板旧构建进入模组一服；不代表所有手机、图形效果或性能均已实机通过。
