# 0.5.2-air 功能排查报告

日期：2026-09-29。范围：E:/hxz_next 的 Windows 桌面启动器，64 位为基准，共享到 32 位。修复已写入源码与两个本地发布目录，未上传 GitHub，未部署或修改线上服务。

## 本轮修复

| 问题 | 原因与修复 | 验证方式 |
| --- | --- | --- |
| 已安装的本地实例显示“安装并开始”，目录按钮不可点 | 本地扫描缺少 installed 字段；扫描结果现在明确区分已安装与异常实例 | 实际中文实例元数据 → 服务层 → 首页按钮；两种发布包分别验证 |
| 首页目录入口点击失败 | instance.folder 调用缺少 kind，已明确打开 versions 目录 | 浏览器通过真实服务层检查目标路径 |
| 视频头图编辑时预览失效 | 编辑器统一使用 img；视频改用 video，恢复默认时采用用户设置的默认头图 | 真实配置读取与编辑器标签、位置参数检查；本轮不把标签检查当成视频解码验收 |
| 长聊天消息、论坛回复提交失败 | 输入框分别允许 2000 / 8000 字符，超过服务端 1000 / 5000 上限；现已统一，插入颜文字也遵守消息上限 | 客户端消息校验与输入框限制；实际论坛提交 |
| 游戏任务期间调整卡片或语音设置被拒绝 | 两层操作锁的允许范围不一致；统一允许不影响游戏文件的外观、卡片、声音和聊天偏好 | 在实际服务操作未结束时修改安全偏好成功；游戏目录修改仍被阻止 |
| 布局与收藏同时保存后，其中一项丢失 | 多个写入者各自保存旧的设置快照；现统一排队写入，包括安装结束时的实例配置 | 阻塞第一次文件写入，交错触发收藏，验证磁盘和内存都保留两项变化；两架构发布包检查 |
| 蓝图“等待审核”看不到待审作品 | 界面发送 scope=pending，服务端要求 scope=review；已更正 | 使用现有社区服务端源码启动本机隔离数据库，提交有效 NBT，再用新界面查看、审核并发布 |
| 修改反馈状态失败时产生未处理异常 | 通用选择器没有接住异步回调失败；选择器与开关统一使用页面错误提示 | 实际反馈界面注入一次 HTTP 503，确认显示错误且无未处理异常 |
| 社区节点异常时只提示 JSON 解析错误 | 反向代理的 HTML 错误页被直接当作 JSON 解析；现提供 HTTP 状态与重试提示 | 本地 HTTP 502 页面，确认显示 502 而非 Unexpected token |

本轮共 59 项自动化功能检查通过，另在 x64 与 ia32 实际发布程序各执行一组原生调用检查；83 处静态字符串调用全部对应已实现入口。类型检查和正式构建通过。

- 19 项服务与存储检查：收藏、并发设置、无效设置不落盘、默认实例保护、逻辑删除/恢复、物理删除不动共享存档、中文目录、MOD 启停、安装暂停/恢复/发布、替换中断还原、旧安装记录恢复、路径边界、Java 要求与发行版/位数筛选、下载校验/重试/取消、HXZUP 备用源与维护状态。
- 18 项迁移契约检查：四种整合包格式、模组依赖与版本筛选、蓝图实际写入和另存、同名蓝图不覆盖、Create 元数据识别、Forge 参数去重、Java/内存策略、论坛全量排序分页、流式与分段下载、安装事务，以及真实 Java 执行导出包中的 HXZUP。未更新的包不等待失联的可选更新日志，也有实际 JAR 启动检查。
- 7 项界面到真实引擎检查：首页状态/目录、清理安装、视频预览类型、聊天与回复长度限制、页面异常。
- 9 项社区连接检查：设备聚合、连续发言与焦点、聊天返回位置、代理错误提示、真实浏览器麦克风对象、静音/停止收听、按键说话释放与失焦、断线停止采集并重连、退出登录后阻止写入。使用本地 WebSocket，麦克风使用浏览器提供的测试媒体。
- 6 项真实社区接口检查：待审筛选、审核发布、论坛回复/点赞/删除、商城库存及单次订单、反馈错误处理、五子棋机器人创建与合法落子。使用已有服务端源码、本机回环地址和全新的数据库；测试身份由本地注入，不使用真实账号。
- 发布程序检查：两架构均能显示本地已安装游戏，真实 IPC 保存设置与收藏、保护默认实例、处理无磁盘路径的拖入 File；未发生页面异常。32 位另有独立启动退出检查，返回 NEXT_CHECK_RENDERER_READY。

自动化工具的 Electron 22 窗口接管和新版 CDP 下载管理命令不兼容；32 位最终改为直接连接页面调试协议，执行同一组实际界面与 IPC 断言后通过。这个工具限制没有通过修改产品程序来绕过。

## 验证边界

这些检查不能证明任意整合包、任意网络环境都没有问题。本轮没有安装几千个文件的完整线上整合包，没有使用真实账号购买商品或发送社区消息，没有在真实双人设备上验收语音音质和公网抖动，也没有实际加入游戏服务器。完整 Minecraft 图形启动、第三方模组兼容、皮肤站真实认证仍需玩家环境验收。

32 位程序在当前 64 位 Windows 下验证，不等于实体 Windows 7 验收。Android 和官网本轮未改。小游戏六项街机和三项棋类的布局、操作、暂停等检查沿用上轮 UI/本机玩法记录；本轮额外验证真实服务端机器人接口，未改排行榜和玩法规则。

NEXT 尚无上线发布通道，启动器自身的自动替换仍按独立验收版策略停用；游戏与 HXZUP 更新不受影响。构建仍有主前端块超过 500 kB 的体积提示，未把它隐藏或宣称已消除。
