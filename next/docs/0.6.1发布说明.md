# 幻想镇 0.6.1

本版更新 Windows 64 位、32 位、Android 社区客户端及完整社区服务端。

- 新增收件箱：文字聊天提及、论坛回复与评论、点赞、收藏和管理员站内信都能收到提醒。输入 `@` 才出现成员候选；管理员可提及全体成员。
- 管理后台可创建自定义内容、指定有效期、每位成员限领一次的活动兑换码，沿用现有积分余额与排行榜规则。
- 联机大厅支持选择已有虚拟局域网适配器。优先连接房主，无法直连时可使用社区限速中继，默认每房间双向合计 256 KB/s，管理员可调整或关闭。
- 新增三个默认服务器的在线人数与玩家样本名单，查询地址可在管理后台分别配置。
- 音乐播放器新增同步歌词卡片，可跨页面显示和收回。管理员可授权玩家使用自己的网易云账号；登录前说明风险，登录状态保存在玩家设备中，播放受账号、会员与版权权限限制。
- 修复社区头像显示、实例头图恢复默认；HXZ UP 更新弹窗采用统一的卡片样式，并可切换到任务详情。
- 优化聊天新消息动效和手机、平板布局；关闭动效设置继续生效。
- 桌面歌词栏可拖动并自动贴靠顶部或底部，记住位置；正文自动让位，长歌词不再把面板撑高或遮挡输入框。也可用方向按钮调整并一键收回。

## 更新与部署

安装版可从更新通道升级。便携版请退出程序后更新完整程序目录，保留 `profile`；不要只复制 exe。

社区服务端仅需一个完整包。先停止旧服务、备份整个 `data` 和 `.env`，用新程序加载原数据。数据库采用增量建表，既有积分、周榜、帖子及活动进度不需要清空。反向代理需要将 `/lobby-relay` 的 WebSocket 转发到同一个社区服务端；仓库示例已包含所需设置。

Android 最低支持 Android 10，内部版本 60101，沿用原签名覆盖安装。32 位版沿用 Electron 22，旧系统兼容性不代表所有 Minecraft 和 Java 版本都能运行。

公网多地游戏联机、用户个人网易云账号及 Android 真机音频/覆盖安装仍需实际环境验收；本机隔离检查与浏览器截图不代表这些场景已经验证。
