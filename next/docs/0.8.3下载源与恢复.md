# 0.8.3 下载源与恢复

2026-10-20。本轮对安装边界、超时恢复、文件校验和来源用途进行了验证。下述实测不能推广为所有地区、运营商、设备都快或可靠。

## 原版安装故障

界面发送 `loader: vanilla`，原 services.installGame 只允许空字符串或四种加载器，因此纯原版在任何网络请求前就被拒绝为「游戏或加载器版本无效」。同一请求还可能携带上次选择留下的 loaderVersion。

先运行 `node --test packages/engine/test/download-recovery-083.test.mjs`，已看到三项红色失败：真实 service.invoke 原版安装停在版本校验；实际 HTTP 挂起文件在 1.5 秒保护预算内未切源；含 token 的 URL 被复制给镜像。修复后同一命令 7 项通过，约 1 秒，不是静态源码断言。

installationRequest 在服务边界把 vanilla/空加载器统一为 `{type:'',version:''}`，真实加载器仍校验版本。测试实际调用 game.install，检查安装事务，并确认继续进入版本清单查询；不存在的版本仍失败。Java GameInstaller 同样接受历史 vanilla 标识。`scripts/tests/install-recovery083.mjs` 则启动真实 Java LauncherInstall，以本地 HTTP 的元数据、本体、库、资源 fixture 完成中文目录纯原版安装和缓存复用；fixture 本体为测试内容，不冒充 Minecraft 公网完整安装。

## 来源用途与依据

默认保持官方优先、连接预算 32；未重写用户的下载模式、并发、速度、目录或卡片设置。Maven Central 增加 repo1 官方备用域名；Android 按文件种类扩展 Mojang、BMCL、Maven 候选，去掉把 Fabric/Forge 专用坐标无条件发往 Central 的旧做法。并非每个文件都访问下面全部节点。

- [Mojang 版本清单](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json) 提供游戏元数据 URL 和 SHA1；Node 新增对应 SHA1 检查，二进制仍按 metadata 的哈希、size 校验。
- [BMCLAPI 运营文档](https://bmclapidoc.bangbang93.com/) 将 libraries.minecraft.net 映射到 `/maven`。本轮据当前文档统一 Node、Java、Android 库路径，历史 0.7.0 笔记中的 `/libraries` 说法不作为本版依据。资源使用 `/assets`，Fabric 元数据使用 `/fabric-meta`。未知互联网地址不猜镜像。
- [Fabric 官方端点说明](https://wiki.fabricmc.net/documentation:modpack_related_endpoints) 列出 Fabric Maven 与版本元数据；专用加载器仓库和 Central 不是任意可替代关系。
- [阿里云 Maven](https://developer.aliyun.com/mirror/maven) 的 public 仓库和 [华为云 Maven](https://support.huaweicloud.com/usermanual-mirrors/mirrors_hlp_0001.html) 的 maven 仓库只用于相应 Maven 内容，不用于游戏本体或资源对象。
- [MCIM 运营文档](https://docs.mcimirror.top/) 明确 Modrinth API、Modrinth CDN、CurseForge 文件域名的映射；不向其发送皮肤站、社区登录或私有更新地址。

## 实际文件与可信哈希

从 1.21.1 官方 metadata 取得 Gson 2.10.1：`com/google/code/gson/gson/2.10.1/gson-2.10.1.jar`，283367 字节，SHA1 `b3add478d4382b78ea20b1671390a858002feb6c`。本机分别从 Minecraft 官方库、Maven Central、阿里云、华为云下载，四份均匹配该官方哈希。BMCL `/libraries` 与 `/maven` 样本都在 6 秒超时，不能据此宣称任一路可用，也不能仅凭超时判定全球失效。结果在 `artifact-probes.json`；官方 metadata/index URL 与哈希在 `official-sample.json`。

资源样本 panorama_overlay.png 的 SHA1 为 `9dd32387135eefa7ab95996d52a5ca4cec8a3b30`、86 字节，地址由该版本真实 asset index 导出。

## 恢复与安全边界

- Node/Java 连接或无进度超时后直接换下一个适用候选，不对同一挂起源连续等五轮。408/429/5xx 保留有限重试、退避与 Retry-After；永久错误跳过，错误哈希不发布文件。
- 整文件与分段保留可信内容身份下的断点，最终完整校验再提交。有效目标直接复用；已收完但提交中断的完整 partial 可先验哈希再复用；416 过期断点会丢弃旧片段并重下。
- 分段校验精确 Content-Range；Java 整文件续传补全总长、起点检查。跨源拼接不绕过最终哈希。Java cancelActive 不再进入长期重试；Node 等待连接、退避、冷却均可取消。
- 签名查询、URL 用户信息、自定义端口和未知域名不自动扩散。跨 origin 显式备用和 HTTP 重定向只保留公开表示相关头，Authorization、Cookie、自定义 API 密钥不会泄漏。认证 JSON 不扩展镜像，非 GET 继续禁止重定向。
- 发布前复核发现并修复 Java 失败日志拼接原始签名 URL：统一 safeURL 去掉 userinfo/query/fragment，并复制、脱敏嵌套 cause 与 suppressed 异常，保留 HTTP 状态、超时类型和重试语义。真实 HTTP 403、返回包含私有 URL 的无效 JSON、下载 stderr 均检查不含三个测试 secret。AndroidPack 的 Fabric API 文件也走统一候选函数，不再手动把带签名 CDN 地址改写成 MCIM。
- 冷却等待改成可唤醒等待，cancelActive 无需依靠外层 shutdownNow。Android SHA1 桥传入实际 FileDownloadTask.isCancelled，50 ms 轮询取消所属线程的文件状态，仍共用 32 连接预算，不误取消其它文件。真实 Retry-After=1800 秒的官方/竞速模式、Android 桥活动传输/冷却，均在置位取消后 1 秒内退出。
- 共享 Java Network 用于桌面安装器、HXZUP 和 Android 有 SHA1 的下载桥。无 SHA1 的 Android 上游下载仍走 FCL 原流程，不能称全部网络都接入新引擎。
