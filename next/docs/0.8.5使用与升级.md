# 0.8.5 使用与升级

## 玩家

Windows 安装版通过启动器内置更新升级，安卓覆盖安装构建 80500；不要先卸载。便携版解压到新目录后，迁移原来的 `profile`，不要覆盖或删除游戏目录。

游戏主页每个实例右侧可以直接「启动」或「安装并启动」。点击实例名称仅切换当前选择；其 Java、内存、更新方式和目录入口显示在「实例详情」卡片，右键实例仍能管理模组、资源包等。

「游玩日历」有两种来源：

- 本机游玩：记录这台设备真正运行游戏的时间，准备、下载和安装不计入。异常退出只保留最近一次落盘的记录。
- 服务器在线：社区授权游戏桥连续核验的在线时间，跨服同时在线合并。点击日期查看当天会话起止时间、总在线时间与计入周榜的时间。

「每周时长榜」显示本周预计奖励与历史已结算奖励。北京时间周一自动结算上周，积分和通知发到社区账号；只有服务器核验的记录参加奖励。本地旧记录不会转为可领奖时长，也不会补造升级前的在线历史。

## 管理员

先备份社区的数据库、上传目录和配置，再通过后台签名更新或使用服务端更新包升级。新部署使用完整服务端包；已有部署保留 `data`、`uploads` 和 `.env`，不要用发布包覆盖运行数据。安卓运行模块沿用 0.8.4 / 80400，通过新签名描述关联原发布文件，无需再次安装独立引擎。

后台「活动与积分 → 游玩日历与周榜」可设置奖励开关、最低周时长、每日计入上限和各名次积分。规则修改从下周生效，当前周按已经保存的规则结算；重复结算不会重复发奖。默认最低每周 30 分钟、每日最多计入 480 分钟。

服务器在线记录需要默认游戏服部署并授权游戏桥，客户端升级本身不能代替服务端核验。部署路径、接口、令牌边界及备份说明见 [游玩时长与周榜](0.8.5-游玩时长与周榜.md)。没有可信在线记录时显示空日历，不使用客户端自报时长发放积分。

在线状态无法完全识别挂机，管理员应结合每日上限和服务器管理规则使用奖励。手机交换内存预算默认关闭；它不能替代物理内存，也不能保证高帧率。
