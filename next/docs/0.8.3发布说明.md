# 幻想镇 0.8.3

本次重点改善第一次登录、安装游戏和查看实例的流程，保留已有账号、游戏、卡片布局及活动进度。

## 下载与安装

- 修复纯原版安装被误判为“游戏或加载器版本无效”；切换加载器后遗留的参数会按当前选择规范化。
- 按文件类型补充官方和公共镜像来源，包括 Minecraft 文件、Maven 依赖与加载器元数据；默认官方优先、32 并发。
- 资源页新增“下载节点”卡片，显示节点用途、最近请求状态、检测延迟与失败原因，可手动检测或停止检测。
- 无响应连接、长期没有数据和不可用节点会退出当前尝试并切换适用来源。保留文件校验、断点续传、取消与重试能力。
- 安卓游戏运行组件同步下载修复，版本更新为 0.8.3 / 80300。

节点数量不代表任何地区都能高速访问。带签名的私有下载地址不会被转发到无关镜像，第三方节点暂时不可用也会如实显示。

## 登录与引导

- 未登录皮肤站时显示覆盖整个启动器的登录页，注册直接打开皮肤站注册页面。电脑和安卓使用一致的视觉方向，适配窄屏和输入法。
- 保留已登录账号的缓存；社区暂时断线不会让用户退出启动器。窗口控制与应用更新仍可正常工作。
- 重做功能引导，可从目录选择功能、进入真实页面、收起提示或跳过；设置和安卓“我的”中可以重新查看。管理员会看到额外的管理说明。

## 卡片与小游戏

- 修复游戏实例卡片只显示部分内容、固定高度产生双层滚动、跨页卡片高度传递，以及普通设置卡片被错误限制高度的问题。
- 长标题、大字号、窄窗口和展开内容会重新计算高度；固定高度下的长列表保留可达的滚动区域和底部操作。
- 小游戏规则升级为 v9，冻结旧版 v8 的完整规则依赖，避免旧客户端结算受新规则影响。
- 增加骰光远征的敌人意图与构筑联动，扩展风帆补给线的风险及恢复选择；具体规则和验证范围见 [小游戏说明](0.8.3-小游戏.md)。

本轮保持 20 款小游戏。已有 LINKING 章节、任务、音乐外观解锁条件和奖励不变。

## 升级

Windows x64、Windows ia32、Android 社区客户端均为 0.8.3；安装版可通过内置更新获取。Android 社区应用与可选的游戏运行组件是两个用途不同的 APK，请同时更新运行组件后再重试游戏安装。

社区后台支持签名更新。升级前备份 `data` 和 `.env`，不要用新数据覆盖原目录；服务重启会中断尚未提交的联机小游戏局，历史成绩、积分和任务进度保留。详情见 [使用与升级](0.8.3使用与升级.md)。
