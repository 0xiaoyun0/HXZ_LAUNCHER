# 0.6.4 卡片视觉打磨 · 本地验收

2026-10-08。源码与本地预览已完成本轮视觉修订。用户随后要求替换 GitHub 上现有的 0.6.4：Windows 保留版本号，Android 构建号递增至 60402。发布结果以 Release 和本地 release/0.6.4/发布信息.json 为准；不修改用户 profile 或生产社区数据库。

## 设计边界

保留可整理的卡片工作台、现有 H 图标、导航结构、游戏规则与用户保存的布局。视觉方向是轻量、清晰的灰蓝桌面工作台：可读性优先，强调色用于选择与动作，层次来自排版、间距与轻阴影。没有增加装饰文案、远程字体、动画依赖或持续运行的全屏特效。

参考 [Webby 官方评审标准](https://www.webbyawards.com/judging-criteria/)中导航清晰、功能可靠、视觉适合内容和整体体验一致的要求，以及 [Awwwards 获奖案例的设计、可用性、创意与内容评分维度](https://www.awwwards.com/sites/aro)。Awwwards / Webby / FWA 是用户指定的品质目标，不表示本项目获得认证或奖项；FWA 页面本次未返回可读正文，没有据此编造评分标准。

## 八项自检

| 维度 | 调整与复核 |
| --- | --- |
| 排版 | 正文 14px、标签 13px、卡片标题 15px（随全局字号缩放）；提升聊天正文、实例元信息、菜单与表单可读性。标题与操作区各自保留空间。 |
| 留白 | 统一内容内边距、按钮间距和标题区；快捷入口改成更紧凑的横向图文按钮；语音房间成员区保留一致基线。 |
| 层级 | 游戏启动维持唯一主要操作，当前实例有选中底色；卡片标题、辅助信息、集合操作采用统一规则。 |
| 色彩 | 浅色与深色分别设置文字、边线与表面色；主题色派生选中底色和边线，深色主题单独提高强调文字亮度。修复外观预览中的硬编码深色文字。 |
| 动效 | 保留轻缓切页；补齐封面微缩放、下拉箭头展开、按钮按压与卡片聚焦反馈。拖动期间不增加延迟。关闭动画与系统减弱动态效果继续生效。 |
| 微交互 | 键盘焦点、选中、禁用和输入聚焦状态一致；修复菜单关闭过程中停用动画会残留菜单的问题。封面失败统一回退图标。 |
| 响应式 | 桌面 1360×880、1024×768 / 22px；手机 320、390、横屏 844×390、平板 768×1024。修复手机横屏最后一个导航按钮被裁切。 |
| 原创性 | 保留幻想镇 H、灰蓝卡片与原有作品封面体系，没有照搬评奖网站页面或交互动线。 |

## 维护入口

- 桌面 `apps/desktop/src/card-finish.css`：语义组件的最终视觉层；布局算法与保存逻辑继续归属 `CardBoard.tsx` / `air.css`。
- 移动 `mobile/web/src/card-finish.css`：同一视觉语言的触屏适配。
- `Shell.tsx` 与移动 `App.vue`：主题色派生值，兼容 Chromium 108，不依赖 `color-mix()`。
- `ui.tsx` 的 `CoverImage`：加载失败占位，供整合包目录与蓝图库复用。

后续视觉调整应在这两个视觉层更新语义组件，避免在业务页面散加同类覆盖规则。卡片位置、宽高、锁定、隐藏与保存的约束仍以《UI卡片规范.md》为准。
