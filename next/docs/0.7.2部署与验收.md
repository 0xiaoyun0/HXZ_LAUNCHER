# 0.7.2 部署与验收

## 升级顺序与数据

先备份社区服务端完整 data 目录及 .env，再更新社区服务端，最后更新客户端。不要删除 community.sqlite。背包、限购、邮件、临时权限和聊天附件表自动创建；原账号、积分余额、榜单、永久授权、委托与 LINKING 记录保留。旧主线记录仅作为历史兼容，不再向玩家展示主线/支线分类。

已有 0.7.0 或更新版本的服务端可以在后台使用签名更新。完整服务端包只需部署一个；update.zip 是后台更新程序使用的包，玩家无需下载。跨版本回退前须恢复对应数据库备份，不能只替换旧程序文件。

图片/GIF 位于社区 data 下的 chat-media 目录，需随数据库一同备份。聊天附件发送 30 天后失效；被收藏为表情的文件保留，但旧消息不会因收藏继续公开图片。取消收藏后，没有有效引用的文件会被定时清理。使用 Nginx 时，将 client_max_body_size 至少设为 12m，8 MB 图片的 JSON/base64 请求会超过 8m；应用仍有每张 8 MB 和像素/帧数校验。

## 规则

商城限购按北京时间周一换周，自然月换月。使用凭证才开始计时；联机为 72 小时，音乐为一个自然月，月底按目标月末调整。续用在现有到期时间后顺延。购买扣款与入背包同一事务完成；使用过的凭证不能按普通订单直接退款。

玩家积分委托只转移余额，不重复产生榜单积分；管理员选择协会发放时计入当周积分。背包材料先托管，通过验收后邮寄给接取人；撤销/拒绝审核时退回。游戏内承诺道具不能由启动器凭空发放：委托人标记交付，接取人确认收货后才完成。

管理员 → 物品与背包可定义物品、限时权限、兑换码与邮寄。管理员 → 积分商城可关联道具、配置周库存和个人周/月限购。已有默认商品若被管理员调整，不在每次重启时覆盖。

## 验证边界

功能使用本地隔离社区，未修改线上数据库或用户档案。包含购买/限购/余额、重复请求、权限到期与永久授权、退款、委托补交/验收/双方收货、图片生命周期、下载断流恢复与摘要校验。受影响 UI 在桌面、窄屏/大字号、手机模拟视口、主题和独立原生窗口中截图检查。

手机浏览器模拟不等于 Android 实机验收，Windows ia32 构建也不等于实体 Windows 7 验收。本轮不重复完整大模组包的手机安装压测。新原生悬浮权限在 Android 上需要用户主动允许；拒绝不会影响普通聊天和语音。
