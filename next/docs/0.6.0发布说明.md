# 幻想镇 0.6.0

## Windows

- 全新的可整理卡片工作台，按内容调整尺寸，支持直接拖动、缩放、自动对齐、锁定、隐藏和恢复。
- 整合实例、下载进度、任务日志、社区、账号积分和游戏入口；修复实例切换、目录即时生效与下拉菜单适配。
- 统一背景、透明度、字号和动效，修复状态栏透明度、商城内容挤压、聊天表情后滚动错位与语音设备引发的页面异常。
- 音乐播放器支持本地常见音频、NCM／旧 QMC、公开网易云歌单与同房一起听；坏曲目自动跳过。
- MC 直连联机大厅支持权限验证、网络预检、自动尝试映射、邀请与当前房间卡片，游戏流量直连房主。

Windows x64 与 ia32 共享业务代码，同时提供安装器和便携包。安装器支持选择目录和快捷方式，保留正式版身份、账号及设置；接入签名更新，旧正式 0.5.2 可自动升级。便携版仍为手动完整包升级。游戏、Java 与 HXZ UP 更新按原设置运行。

## Android

- 0.6.0（60001），Android 10 及以上，沿用原应用身份和签名。
- 新社区卡片界面、手机五项导航与平板侧栏，适配小屏、横屏和大字号。
- 保留完整社区功能，增加音乐播放器、公开歌单、同房分享和直连房间目录。
- 修复积分异常响应、商城按钮、小游戏封面和音乐控件在窄屏下的排布。
- 不包含 Minecraft 安装或运行；应用选择弹层统一，权限和安装确认由 Android 系统负责。

## 服务端与数据

只需一个完整社区服务端包，内含网页后台、全部既有社区业务及直连大厅权限、目录和探测。网页后台新增「联机大厅」授权管理。升级先停服，备份并完整保留 data 与 .env；不清空论坛、账号、积分和排行榜。未自动部署线上服务。

## 验证范围

安装器载荷在两架构运行验证旧账号加密数据、设置备份、中文路径和更新页面；沿用旧安装身份，未对真实用户安装目录做无人值守覆盖测试。隔离社区从旧版升级后 29 张原业务表记录保留，网页后台授权与撤销通过。通过两架构桌面原生调用与媒体检查、卡片及主要页面截图、隔离社区业务检查、本机双端音频与加密直连；Android 通过签名构建、Lint、响应式截图、触摸滚动、原生导入及关键业务检查。

仍需实机验收：Android 麦克风／耳机／后台通话与覆盖安装、实体 Windows 7、两处公网直连及完整大型整合包。直连要求可入站 IPv6 或可自动映射的公网 IPv4；不具备条件时会预先提示，不能保证所有运营商网络无需配置就可直连。
