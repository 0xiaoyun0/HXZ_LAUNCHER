# 0.8.4 开发状态

更新：2026-10-21。**0.8.4 预发布已公开；正在交付安卓 80401 修订，Android 尚未实机验收。** 不要把历史 0.8.3 APK 或本轮废弃的嵌入方案产物当作 0.8.4。

## 最新约束

- FCL 仅作为功能与行为研究对象；本版本不复制、翻译、改名包装或静态嵌入 FCL 启动器代码。
- 专用运行引擎的宿主、安装计划、账号交接、触控和窗口生命周期独立实现。底层 Java、图形等第三方依赖须从真实上游建立源码、补丁、构建、许可与散列清单。
- 社区应用与游戏能力同包；游戏运行资源按需下载，不安装第二个 APK。
- 用户要求暂不操作平板；完成真正可用的 APK 后，由用户手动实机验收。编译、浏览器和协议测试不能冒充设备游戏运行结果。
- 官方源优先；只有能提供同一目标文件的镜像才能作为备用。断网、全面阻断或上游删除无法保证下载成功，必须保留进度和可继续状态。

## 已实现与检查

1. 34 个文件来源与 5 个元数据来源分开登记。32 个文件样本在本机探测可达；NeoForge 超时、MCIM 503 如实显示。同一 Gson 依赖 20 个候选完整散列一致。详见 [下载节点](0.8.4下载节点.md)。
2. 首页实例卡片内列表随卡片增长，移除原 340px 限制；下载节点卡片同步改为可伸展列表并保存滚动位置。真实页面夹具、截图与宽窄布局检查见 `.runtime/review084/cards`、`downloads`。
3. 自行编写的 Android 联机服务、TLS 邀请校验、WebRTC 帧流量控制和 PC 协议已接入。Java/Node 双向 600KB、实际帧处理器 1.2MB 与背压检查通过。未验证真实 ICE、AndroidKeyStore 或 Minecraft 跨端游戏。
4. 同包运行资源下载/签名验证/解压框架已编写。实际 Java ZIP 测试 13 项通过，覆盖签名外层 `moduleSha256` 与 ZIP 原始清单绑定、坏散列、缺文件、清单外文件、取消及重复激活；保留旧模块和清理临时目录。高频状态检查不逐文件散列，激活与启动前全量校验。
5. Android 独立游戏 Activity、原生子进程与 GLFW 3.4 公开 ABI 适配已实现，NDK 链接和 Java host 定向编译通过；尚未用设备证明能启动 Minecraft。移动网页构建与 320/390px 交互夹具通过。PC Java 安装器/HXZUP JAR 已重新编译，Node 下载恢复与跨端兼容边界检查通过。
6. 本地 `release/0.8.4` 已构建 Windows x64/ia32 便携版和安装器、Windows x64 服务端 ZIP、Android 80400 签名 APK、独立运行模块及更新签名元数据。设备验收由用户手动进行，当前不自动推进稳定更新通道。
7. 安卓启动链加入独立的客户端模组兼容检查。两服本地实际清单只读扫描 225/261 个 JAR，各匹配一个有官方证据、精确散列的 IMBlocker 文件，未改动本地整合包。自动适配保留原件及事务记录，HXZUP 更新前恢复、更新后重新检查；未知版本和有依赖风险的模组保持原状。运行故障按明确日志证据分类，不因未知崩溃擅自禁用内容模组。元数据检查不代表设备已经成功入服。

## 已撤回

宿主 Gradle 不再引用 FCL、hxzRuntime、Terracotta、ZipFileSystem 或生成的 vendor AAR；CommunityApp 仍为本项目 Application。旧嵌入准备脚本和资源打包入口已禁用。历史独立 FCL 包的发布脚本拒绝 0.8.4 及以后版本，防止误发布。历史版本源码、用户数据和已发布包未删除。

GameEngine 的目标入口为自行实现的 `top.hxzmc.community.game.GameRuntimeActivity`；它由单独的原生可执行进程承载 JVM、经私有 IPC 传入输入与帧。静态构建成功不等于游戏实机可运行，旧 FCL Activity 不会成为回退入口。

## 稳定发布前的验收范围

- 独立上游运行依赖已锁定并构建：Java 21/25、LWJGL、JNA、FreeType、OpenAL、Mesa softpipe/Zink。对应源码、许可与模块附件已公开发布；模块清单匿名请求及真实文件分段下载已核验。
- 在实际 ARM64 设备上证明 JVM、游戏窗口/输入/音频、安装器进程与退出恢复均可运行 Minecraft；不能仅以 JNI 编译成功作结论。
- 在实际三服资源和房间中验收安装、HXZUP、账号、最终实例指纹与 ready/退出回报；当前静态链路与夹具不能替代实机结果。
- 独立模块已生成，719 个文件的实际解压及全量散列校验通过；模块签名使用社区 APK 身份。已禁用的旧嵌入资产脚本不会用于交付。
- Android 80400 签名 APK 已构建，证书与旧社区应用一致；当前没有进行设备验收。先提供预发布供用户手测，不推动最新稳定版本自动更新。完整检查与交付范围见 [使用与升级](0.8.4使用与升级.md)。

独立架构、来源边界与技术风险详见 [安卓独立运行架构研究](0.8.4安卓独立运行架构研究.md)。

## 80401 收尾修复

- HXZUP 本地完整性独立于自动更新开关；真实子 JVM 回归覆盖首次同步失败、同版本损坏修复、维护竞态与完成记录保护。
- 修复合法 GLFW 窗口操作触发 Minecraft 初始化错误回调的问题，并补手机文字输入、角色选择门禁和模块错误定位。
- 运行资源包不变；社区 APK 修订不要求重复下载完整模块。模组一服客户端仍保留 Sable/航空学；Android 本地运行其物理世界存在 glibc/bionic 缺口，远程进服待手动验收。
