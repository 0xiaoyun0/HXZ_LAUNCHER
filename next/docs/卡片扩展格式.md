# 声明式卡片扩展

卡片整理 → 添加通用卡片 → 导入卡片扩展。选择 JSON 后先显示作者、内容数量和外部链接域名；确认后成为普通 CardBoard 卡片，支持拖动、跨页、尺寸、显隐、锁定和持久化。卡片标题只能在编辑模式修改；清单勾选属于日常使用。

参考同目录的「卡片扩展示例.json」。文件最多 64 KB、12 个内容块。不执行 JavaScript、HTML、系统命令，不支持后台请求或自动下载。作者文本仅为署名，不代表已验证身份。旧布局导出功能保留扩展定义，不分享清单勾选状态。

内容类型：

- `text`：纯文本 `text`，最多 2000 字。
- `metric`：只读 `instance` 当前实例、`community` 连接状态、`clock` 本机时间，可设置 `label`。
- `check`：稳定且唯一的 `id`、`label`，勾选保存在本机。
- `link`：`label` 和内置 `page`，或 `url`（HTTPS）。仅在用户点击后打开。

内置页面：home、chat、voice、inbox、games、music、account、guild、multiplayer、install、hub。扩展不能读取账号凭据、本地文件或未公开的社区内容。未知类型拒绝导入；已有设置中的坏扩展隔离丢弃，不妨碍启动器启动。
