# 0.6.3 验证记录

Windows x64、Java 21，官方来源、32 并行。Java 安装辅助程序按 Java 8 字节码编译，同时更新游戏安装器和内置 HXZ UP。

## 下载

- 隔离 HTTP：同目标并发合并；取消单个消费者不影响其他消费者；立即恢复取消任务；精确 Range 与最终哈希；跨进程保留已完成分块；缓存重装不重复下载资产。
- 复现并修复正常传输超过重试预算后无法重试的问题。持续 20 KB/s 的尾文件夹具中，Java、Node 均换源并校验完成。
- 最后一个关键文件失败时，前面已校验的文件在重试时复用，未提交半成品。
- 实际模组二服使用独立中文测试目录，未接触玩家实例。首次复现官方文件中断失败；第二次复现 3942/3943 项时单文件持续低速。最终续装完成游戏、NeoForge 及 1686 个 HXZ UP 文件，约 223 秒。此轮复用了之前的游戏资产，不是全新安装基准，也不能推广为所有网络的耗时。
- 本地小文件吞吐无明显变化；20 MiB 分块夹具约从 757 ms 到 626 ms，不能作为公网提速百分比。

## 界面与游戏

- 桌面宽窄窗口、浅暗主题、大字号及弹窗流程共 133 张检查截图，无页面脚本错误、水平溢出或检测到的卡片裁切；另检查任务错误操作区和新游戏运行截图。
- 手机 320/390、横屏及平板尺寸检查；统一 SVG 按钮，触控区至少 44 px，按下/松开驱动移动、跳跃、开火，失焦释放。
- 狼人杀隔离检查六人身份保密、无权访问、过期行动、讨论、完整结算及机器人练习不发联机积分。真实本地 HTTP 检查创建、发言、开始、日夜转换及退出。
- 新街机使用确定性输入重放，与旧规则版本并存，不清空社区数据。

移动浏览器检查使用原生桥接替身，不能替代 Android 真机语音和触控体验验收；ia32 在本机兼容环境检查，不代表实体 Windows 7 验收。未使用真实账号进入公共游戏服务器。构建、签名与发布状态以最终交付清单为准。
