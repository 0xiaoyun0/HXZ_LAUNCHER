# 0.5.2-air 卡片修复与 UI 巡检

日期：2026-09-29。代码与发布包：E:/hxz_next。未上传、未部署，没有操作真实社区账号或已有游戏数据。

## 修复内容

- 语音：原生 MediaDeviceInfo 被响应式代理后读取属性抛 Illegal invocation，已先映射为普通对象。同一脚本修复前崩溃、修复后通过。加入设备容错、重复入房保护和明确的麦克风错误提示。
- 卡片：直接拖动与缩放、自动对齐保存、撤销、锁定、隐藏恢复、适应内容、同排等高。修复间距放大高度、反复适配增长、异步保存覆盖其他页面布局。
- 默认排布：首页快捷入口与易找到的启动操作；实例概览缩短空白；设置按内容高度排列，统一字段和弹窗间距。
- 聊天与语音：小窗口输入区保持可见；房间、通话控制、设备成卡片；头像保持正方形。
- 游戏：九张封面、分类/收藏/最近游玩、局内状态与操作区。修复画布比例、跑酷绘制插值不匹配；移除无变化的升级选项仍引发的高频刷新。评分公式、录像校验及线上榜单不变。
- Linking：修复容器高度为零造成空白，保留活动内容与解锁流程。
- 页面异常：错误隔离、重开/复制诊断；桌面日志脱敏并限制大小，保存在 profile/logs。
