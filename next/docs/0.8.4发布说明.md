# 幻想镇 0.8.4

本次基于 0.8.3，重点修复下载恢复、实例列表布局，并引入幻想镇自己的安卓游戏运行宿主。

## 安卓修订 80407

- 修复 NeoForge 补丁已经处理完成，却一直停留在“等待处理器退出”的问题。
- 对同步完成的 NeoForge BinaryPatcher 安装子进程使用 Java 正常退出流程，避免未关闭的 LZMA 解压线程一直阻止退出；游戏及其他处理器保持原有生命周期。
- 安装异常仍判定为失败，继续校验处理器产物的声明散列，不以进度到达末尾或文件存在代替完整性验证。
- 已使用真实补丁包在本机重现线程残留，并完成定向退出验证；Android 实机安装、启动和进服仍需用户验收。覆盖安装保留现有账号、下载与存档。

## 安卓修订 80406

- 接入 NeoForge 补丁工具的真实进度，显示当前阶段、处理数量、耗时及最新日志，不再只显示 `binarypatcher.ConsoleTool`。
- 区分读取补丁、应用补丁、写入新文件、等待处理器退出及产物校验；不将单个类的补丁序号当作总百分比。
- 安装进行中也可复制当前诊断。长时间无新日志会如实提示，不据此假定卡死或强制退出。
- 安卓当前构建为 80406，覆盖安装保留已下载文件及此前兼容修复。

## 安卓修订 80405

- 修复 Android 堆指针标签与内置 Java 原生运行环境不兼容时，NeoForge 安装处理器在 `MERGE_MAPPING` 等阶段以代码 134 退出的问题。
- 安装处理器和游戏共用的独立执行进程在加载 Java、渲染库前启用并验证内存兼容模式；不改变社区及语音进程的保护设置。
- 系统拒绝兼容设置时提前给出具体原因，不继续加载 Java 导致同样的原生崩溃；已下载文件和未完成安装可继续使用。
- 安卓当前构建为 80405，直接覆盖安装；运行资源不变，无需重新下载整个游戏模块。

## 安卓修订 80404

- 修复 Forge / NeoForge 安装参数解析时的 `PatternSyntaxException`，补全 Android ICU 要求的大括号转义。
- 同步修复游戏启动参数中的同类正则，避免安装完成后又在启动阶段遇到相同问题。
- 补充 ICU 正则编译及真实安装参数、启动参数、重试流程的针对性回归验证；覆盖安装保留已有资源与存档。

## 安卓修订 80403

- 修复游戏准备阶段把 Android 系统 `/data/user/0` 目录别名当作资源符号链接拒绝的问题。
- 先解析系统提供的应用私有目录，再创建游戏、实例和日志目录；保留资源子目录的链接及越界检查。
- 覆盖安装保留账号、已下载运行模块、实例与存档，无需重新下载运行模块。

## 安卓修订 80402

- 修复运行模块重试后仍复用旧失败缓存，导致完整资源无法启用的问题。
- 兼容安卓应用目录的系统路径别名，仍严格限制资源位于应用专用目录。
- 损坏的解压目录使用已校验下载包自动重建；替换失败保留原目录，重试不影响账号及游戏存档。
- 已完整下载的资源包和已校验的解压目录可直接复用；同版本资源损坏也可修复。
- 启用失败保留具体原因，避免只提示“未能完整启用，请重试”。

安卓当前构建为 80407，覆盖安装即可；Windows、服务端及运行资源版本不变。

## 安卓修订 80401

- 修复 Minecraft 的合法窗口尺寸限制被误报为不支持、进而中断初始化的问题，完善窗口状态、上下文解绑和退出唤醒。
- 关闭自动更新仍核验本地 HXZUP 包；首次同步失败和同版本文件损坏不会再被当成完整安装。
- 加入手机输入法入口，支持中文聊天、命令及游戏文本输入；触控布局根据可用画面计算边界。
- 角色管理直接接入社区角色选择，未选角色时给出明确入口；模块下载失败展示节点及具体失败类型。
- 安卓构建号由 80400 升至 80401，可覆盖安装；运行资源不变，沿用已签名模块。Windows 和社区服务端沿用 0.8.4 首批构建。

本修订仍供手动实机验收。模组一服 Sable 物理库的 Android 本地世界兼容尚未完成，此类房主使用 PC；内容模组不会因此被擅自禁用。

## 下载与安装

- 登记 34 个文件来源，另列 5 个元数据来源；在下载节点页面区分官方和镜像，显示本机检测结果。
- 默认保持官方源优先、32 并发。同一文件失败后，依次尝试能提供相同版本、路径和校验值的备用来源。
- 修复官方源受其他任务的临时冷却影响而被错误后移的问题；扩大 Maven、加载器及公开发布文件的适用备用范围。
- 保留校验、断点、取消和重试机制。下载服务不可达时提示具体节点，不把单个服务失败误报成本地断网。

34 个来源分别覆盖不同资源，不代表每个文件都有 34 份副本。节点状态随地区和时间变化；全部来源失效、资源删除或权限不足仍会如实提示。

## 桌面布局

- 首页实例列表随卡片高度扩展，拉长卡片后可以显示更多实例，不再固定约五行。
- 下载节点列表同步适配卡片大小，保持滚动位置。
- 补充卡片容器与内容同步伸缩的开发约定。

## 安卓游戏运行

- 社区 APK 内含自行实现的游戏准备、账号交接、窗口和触控宿主；首次玩游戏时在应用内下载运行资源，无需另装游戏引擎 APK。
- 支持按默认服务器配置准备游戏、加载器与 HXZUP 更新；社区选中的皮肤站角色直接传入游戏。
- Java 21/25 按游戏元数据选择；运行模块、文件清单及资源散列经过签名验证，下载中断可以继续。
- 提供内存、图形渲染、下载并发、触控大小、分辨率及灵敏度设置。Minecraft 26.2 使用 OpenGL 游戏后端。
- 接入与桌面大厅兼容的公网直连和 P2P 协议、实例核对及房间生命周期；游戏流量不经社区中继。
- 完整本地整合包在非强制更新且更新服务暂时不可达时可继续使用；不忽略缺文件、损坏、未完成事务或鉴权失败。
- 启动前核对客户端模组适配：仅对已核实的桌面专用客户端模组按文件散列隔离，保留原件及原因。HXZUP 更新前恢复原件参与校验，更新后重新检查，不删除服务端要求的内容模组。
- 游戏诊断区分有明确证据的内存不足、电脑架构库、图形接口、Java 版本及服务器模组不匹配；未知错误保留日志，不靠猜测自动删模组。

这是独立安卓宿主的首次验收版本。已做编译、协议和依赖检查；按用户安排，尚未进行设备上的安装、画面、音频、触控、三服连接及跨端联机验收，不能把这些检查等同于实机成功。

当前游戏模块要求 Android 10 或以上、ARM64、4 KiB 系统内存页。16 KiB 页设备会在下载前提示暂不兼容；社区功能不受此限制。大型整合包和电脑专用模组仍受设备内存、驱动与模组兼容性限制。

新引擎使用社区应用自己的游戏目录；旧版独立引擎中的存档不会自动迁移或删除。卸载社区应用前须先备份其游戏存档。

## 更新与数据

- Windows 64 位、32 位、安卓社区和服务端版本统一为 0.8.4。
- 社区服务端更新包不包含用户数据库、上传文件或运行配置。
- 第三方运行依赖附来源、散列、许可及对应源码信息。独立宿主未嵌入或改名包装其他启动器的代码。
