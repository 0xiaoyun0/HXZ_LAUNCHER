# 官网部署与内容管理

此目录是独立官网，默认仅监听本机，没有部署到 www.hxzmc.top。不要把客户端的 profile 或官网的 data 公开到静态目录。

## 运行

需要 Node.js 22.12 或更新版本。在官网发布目录执行 `npm install --omit=dev`，然后 `npm start`。默认 http://127.0.0.1:4332，后台 /admin/。

完整源码目录的运行方式是 `npm ci` 后 `npm run website:build`、`npm run website:start`。修改内容不需要重新构建前端。

首次启动会在 data/首次登录.txt 生成本机管理员账号与随机密码。登录后台后可修改密码；不要公开此文件。更新程序时保留整个 data 目录，包含管理员密码、已发布内容、草稿、历史版本和上传图片。其他服务器应自行安装 sharp 对应平台的依赖，不能直接搬运 Windows 的 node_modules。

后台支持站点名称及链接、首页文案与图片、三个服务器的名称、玩法、版本、地址、状态、周目及特色；可以上传图片、预览草稿、发布内容，并恢复最近的历史版本。编辑默认只保存到草稿，发布后才影响访客。操作使用登录会话和 CSRF 验证。

## 正式域名

使用 Nginx 或现有反向代理，将 https://www.hxzmc.top 转发到 127.0.0.1:4332。启动进程设置 `PUBLIC_ORIGIN=https://www.hxzmc.top`；转发 Host 头为原始 Host。无需对公网直接开放 Node 端口。

可用环境变量：

- `PORT`：监听端口，默认 4332。
- `HOST`：监听地址，默认 127.0.0.1。
- `PUBLIC_ORIGIN`：后台写入请求允许的正式来源。
- `HXZ_NEXT_WEB_DATA`：数据目录的绝对路径，默认程序 data 文件夹。

社区论坛和蓝图内容来自现有 qqbot.hxzmc.top 的公开接口；网络失败显示失败状态或明确的缓存状态。下载页读取正式启动器 Release，NEXT 未发布时不会伪装成已经可在线下载的新版本。

现有服务器主题图片是占位插画，不当作真实服务器截图。管理员可在后台替换为实际建筑、风景与活动照片。尚未进行公网部署、多人社区或真实服务器环境的验收。
