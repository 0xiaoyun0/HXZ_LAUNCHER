# 幻想镇 0.8.6

本次更新修复日历越界，调整游玩时长奖励，并优化安卓原生绘制与小游戏。

- **游玩日历**：电脑和安卓共享网格随卡片宽度缩放，修复最右侧选中日期、键盘焦点描边超出边界。在线详情和每周时长榜保留。
- **游玩积分**：每累计 24 小时经游戏服务器核验的在线时长获得 5 积分，余数跨日、跨周和服务重启保留。排名用于展示，不再按名次发奖。旧已结算周期不会重复发奖；管理员可以暂停发放，期间时长继续累计。
- **奖励进度**：服务器在线日历与周榜显示已获得积分、距下次奖励的时长。电脑、安卓与管理后台使用相同规则。
- **安卓渲染**：缓存重复的 GL 函数查找，相同实际索引内容复用绘制缓冲，减少 CPU 工作和重复数据上传。保留此前水体、基顶点和纹理边界兼容修复，扩展内存默认关闭。
- **内存预算回退修复**：关闭扩展预算时，自动分配恢复按当前可用物理内存计算；修复开关加入后关闭路径也提高内存上限的问题。下次启动游戏生效。
- **棋类与小游戏**：沿用车万女仆开源引擎，控制棋类响应等待；检查随机关卡的可解性和操作逻辑，修复发现的问题。具体验证见随版本发布的小游戏说明。

Android 应用构建号 **80600**，可以覆盖安装。Windows 安装版、Android 和社区后台支持原有内置更新；便携版保留 profile 后手动替换程序。社区服务端需同步更新才能使用新奖励规则。

安卓运行模块继续复用 0.8.4 / 80400 的已签名资源，性能修复位于本次 APK 的原生适配器内，无需额外安装引擎 APK。游戏服务端桥继续兼容 0.8.0。

本轮安卓帧率由用户手动实测；本地绘制计数回归不等同于设备 FPS 测量，尚不能确认所有设备或大型整合包达到 60 FPS。服务端核验的是在线时长，不能完整识别挂机。详见 [安卓性能](0.8.6-安卓性能.md) 与 [奖励规则及迁移](0.8.6-游玩时长奖励.md)。
