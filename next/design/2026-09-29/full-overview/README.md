## 范围

1. 游戏与实例：8 张。开始游戏、实例库、实例概览、独立配置、模组、任务、诊断、删除与恢复。
2. 下载与资源：9 张。Minecraft 安装、整合包与详情、模组、资源包、光影、数据包、导入、导出。
3. 社区与监控：10 张。文字、语音、论坛、帖子、编辑器、蓝图库、蓝图详情及导入、上传审核、分服公告、监控。
4. 账号与商城：6 张。登录、角色账号、皮肤站容器、积分明细、卡片商城、商品兑换。
5. 小游戏与排行：12 张。大厅、榜单、9 款独立游戏画面及棋局观战。
6. 设置与活动：10 张。外观卡片、背景裁剪音乐、Java、下载更新、语音社区、反馈、管理台、关于、原版活动嵌入和通用弹窗。

同一套布局中的排序、筛选、标签和开关没有穷举所有取值组合；弹窗中包含主要异常与确认状态。游戏场景为固定比例设计示意，没有替换当前游戏实现。

## 设计约束

- 沿用用户本轮认可的灰蓝配色、卡片分区与启动操作路径，参考常见启动器操作方式，独立绘制具体视觉。
- 全部数据、账号、商城、帖子、资源内容均为设计样例；标题页明确标识，不是实时服务数据。首页为此前可交互预览的截图，其中监控数值只反映截图时刻。
- Linking 载入既有 public/arcana/index.html，仅展示原版入口的嵌入容器。不触发活动解锁、不修改卡牌内容或规则，也不提供演示账号。
- 皮肤站页面只画内嵌容器与角色管理示意，不冒充已抓取的皮肤站真实后台。
- 管理工作台展示权限入口和设计方向，不声称其管理功能已经迁入新产品。
- 长表单在内容卡片区域滚动，保存区保持独立；游戏棋盘保持比例。
- 图片由 HTML/CSS/SVG 在本机 Edge 渲染，使用现有主题插画，不冒充服务器实景。

只进行了生成设计图所必需的渲染、脚本错误与明显排布检查，没有运行产品测试、打包或发布。所有修改限制在 design/2026-09-29/full-overview 和开发记录。
