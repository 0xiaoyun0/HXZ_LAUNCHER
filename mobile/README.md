# 幻想镇社区 · Android 0.4.2

独立移动端，仅提供社区功能，不包含游戏安装、启动或桌面自动更新。兼容现有 0.4.2 社区服务，不要求服务器增加接口或调整 CORS。

最低 Android 10（API 29），适配手机、平板、横竖屏。目标 API 35。网页使用 Vue，原生 Android 层负责 HTTPS、社区 WebSocket、加密凭据、文件选择及后台 Opus 语音。界面资源全部随 APK 打包，不加载远程可执行页面。

## 开发与构建

需要 Node.js 24、JDK 21、Android SDK 35 和 Gradle 8.7。

1. 在 web 目录执行 npm ci、npm run build。
2. 设置 ANDROID_HOME、JAVA_HOME，在 android 目录执行 gradle assembleDebug。
3. 测试包在 android/app/build/outputs/apk/debug。正式发布前使用固定的私人 Android 签名密钥构建 release，不将密钥提交仓库。

开发预览只有原生桥提示，不包含账号或生产测试凭据。实际登录、语音及文件操作在 APK 中运行。

## 当前任务约束

- 用户已验收主要功能，并授权完成统一弹窗和动效后发布到 GitHub 0.4.2。

## 数据与安全

密码只用于本次皮肤站登录；刷新令牌用 AndroidKeyStore 的 AES-GCM 加密保存。社区请求和语音共用现有 HTTPS/WSS 服务。切换服务、退出登录会离开语音并清除社区会话。语音不录音、不落盘，通知提供退出通话按钮。

## 功能

- 手机六栏底部导航（聊天、语音、论坛、蓝图、公告、我的），平板侧边导航，支持横竖屏、系统安全区与软键盘；浅色/深色/系统主题、14–22 px 字号、强调色。
- 皮肤站登录、角色选择、社区头像、网站账号管理；皮肤网站页面使用系统浏览器，首次网页管理仍需网站登录。
- 公共聊天、在线成员、颜文字/Emoji；聊天记录最多300条，连续发言保留输入焦点。
- 四个语音房间，每房20人。沿用现有 /ws 转发 Opus，进出提示、静音、收听开关、听筒/扬声器、按住说话；进入语音时申请权限并建立前台服务通知。
- 语音后台运行、短时断网退避重连。恢复连接后重新加入原房间；长时间无法恢复时结束后台通话。按住说话在应用失焦后立即停止发言。
- 论坛分类搜索、分页、发帖、评论与嵌套回复、帖子/评论点赞、作者删除和管理员管理。
- 蓝图分类/版本索引筛选、上传 NBT/封面、审核及驳回原因、下载到系统选择的位置；上传8 MB上限，下载校验 SHA-256，权限由原服务器验证。
- 三服公告与 HXZ UP 日志严格按 groupId 展示，管理员可发布/删除公告。
- “我的”页底部版本行连续点按七次进入隐藏活动，沿用原服务端解锁、剧情、进度和归档接口；移动端使用独立的卡片阅读界面。

## 验证与交付（2026-09-20）

已完成 Vue 生产构建、Android Debug/Release 编译和 Android Lint（无错误），无 Android 10 新 API 误用。已使用未修改的 0.4.2 服务端隔离实例，检查真实聊天发送/焦点、论坛发帖/嵌套回复/点赞、公告组区分；仅做了320/390/820宽度的溢出检查，未代替用户做全面 UI 测试。

音频检查：真实 Java Concentus 编码的数据经过原社区语音转发后由桌面 WebCodecs 解码；桌面编码的数据由 Java 解码，两方向均为960个有效采样的20 ms音频。该检查验证协议和编解码互通，不代表完成手机麦克风、扬声器或后台通话实测。

公网只读 /health 确认 https://qqbot.hxzmc.top 当前为0.4.2。没有使用玩家账号登录公网，没有改动服务器代码、部署或数据。

当前没有连接安卓真机。需要用户验收实际皮肤站登录、权限拒绝后恢复、手机与桌面通话、耳机路由、锁屏后台及切换网络。部分厂商的省电管理会限制后台应用，须按实际机型检查。

交付使用固定私人密钥签署的 release APK，非调试 APK。签名配置保存在发布机用户私有目录，不随源码分发。后续更新须沿用同一证书及增加 versionCode，不能重新生成密钥。发布在 GitHub v0.4.2 的 Android 附件中。

本轮 Lint 的 JavaScript 提示对应受本地 HTTPS 资源、CSP 和导航拦截限制的 Vue 容器；同步清除凭据用于确保退出登录持久生效。没有禁用 API 兼容性或错误检查。

复核命令：安装 server 依赖，设置 JAVA_HOME、PLAYWRIGHT_PATH（Playwright index.mjs 绝对路径），完成 debug 编译与 web 构建后执行 `node test/verify.mjs`。测试数据写入忽略的 `.test`，不访问生产账号。
