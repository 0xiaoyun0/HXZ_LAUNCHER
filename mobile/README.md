## 安卓滚动修复（40402）

0.4.4 的安卓修订包，沿用原签名证书，内部版本号提高至 40402，支持从 40401 自动检查更新。小游戏此前直接放在禁止溢出的工作区中，超出屏幕的卡片、排行和说明被裁掉；现使用独立、定高的纵向滚动容器，导航保持固定。俄罗斯方块画布允许纵向浏览，其他游戏的画布与按键保留操作手势。

针对性触摸回归检查覆盖列表、详情页、手机竖横屏、平板及俄罗斯方块画布。运行 mobile/web 开发预览后，设置 PLAYWRIGHT_PATH（Playwright 模块路径）和可选 MOBILE_PREVIEW_URL，执行 `node mobile/test/arcade-scroll.mjs`。Windows 客户端与社区服务端无需重新安装。

修订源码标签为 v0.4.4-android.40402；APK、签名更新清单及对应源码归档更新至原 v0.4.4 Release。

0.4.4（40401）增加独立小游戏页，复用 PC 版游戏组件和规则，适配触摸与手机尺寸；新增入口不改变隐藏活动。排行榜需要 0.4.4 社区服务端，旧服务器可练习，其余社区功能沿用原接口。构建时保留仓库的 client/src/components/ArcadeGames.vue、client/src/lib 的小游戏模块、client/src/css/arcade.css 以及 server/shared/arcade-engine.mjs。共享代码编译进 APK，不从公网加载。

底部主导航合并为聊天、社区、游戏、公告、我的五项。聊天顶部切换文字／语音，社区顶部切换论坛／机械动力蓝图，各自仍是独立页面；返回主分区时记住上次选择的子页。语音连接和新消息标记保留，切换页面不会退出通话。平板沿用五项侧边导航，PC 版不受移动端布局调整影响。

本轮40301：在线状态显示手机/电脑/双端；精简动效、固定导航；皮肤站内嵌管理及网站会话同步；更新对比多个签名清单、保留已知最新版本、下载失败两轮换源。新在线设备标识需配套0.4.3服务端，其余接口继续兼容0.4.2。下文0.4.2章节是历史交付记录。

最低 Android 10（API 29），适配手机、平板、横竖屏。目标 API 35。网页使用 Vue，原生 Android 层负责 HTTPS、社区 WebSocket、加密凭据、文件选择及后台 Opus 语音。界面资源全部随 APK 打包，不加载远程可执行页面。

## 开发与构建

需要 Node.js 24、JDK 21、Android SDK 35 和 Gradle 8.7。

1. 在 web 目录执行 npm ci、npm run build。
2. 设置 ANDROID_HOME、JAVA_HOME，在 android 目录执行 gradle assembleDebug。
3. 测试包在 android/app/build/outputs/apk/debug。正式发布前使用固定的私人 Android 签名密钥构建 release，不将密钥提交仓库。

开发预览只有原生桥提示，不包含账号或生产测试凭据。实际登录、语音及文件操作在 APK 中运行。

## 数据与安全

密码只用于本次皮肤站登录；刷新令牌用 AndroidKeyStore 的 AES-GCM 加密保存。社区请求和语音共用现有 HTTPS/WSS 服务。切换服务、退出登录会离开语音并清除社区会话。语音不录音、不落盘，通知提供退出通话按钮。

## 功能

- 手机六栏底部导航（聊天、语音、论坛、蓝图、公告、我的），平板侧边导航，支持横竖屏、系统安全区与软键盘；浅色/深色/系统主题、14–22 px 字号、强调色。
- 皮肤站登录、角色选择、社区头像、网站账号管理；皮肤网站页面在应用内显示；首次升级缺少网站会话或需要验证码时，在内嵌页面完成验证。
- 公共聊天、在线成员、颜文字/Emoji；聊天记录最多300条，连续发言保留输入焦点。
- 四个语音房间，每房20人。沿用现有 /ws 转发 Opus，进出提示、静音、收听开关、听筒/扬声器、按住说话；进入语音时申请权限并建立前台服务通知。
- 语音后台运行、短时断网退避重连。恢复连接后重新加入原房间；长时间无法恢复时结束后台通话。按住说话在应用失焦后立即停止发言。
- 论坛分类搜索、分页、发帖、评论与嵌套回复、帖子/评论点赞、作者删除和管理员管理。
- 蓝图分类/版本索引筛选、上传 NBT/封面、审核及驳回原因、下载到系统选择的位置；上传8 MB上限，下载校验 SHA-256，权限由原服务器验证。
- 三服公告与 HXZ UP 日志严格按 groupId 展示，管理员可发布/删除公告。
- “我的”页底部版本行连续点按七次进入隐藏活动，沿用原服务端解锁、剧情、进度和归档接口；移动端使用独立的卡片阅读界面。

### Android 发布维护

每次Android更新必须提高versionCode、沿用同一私有签名证书，给APK使用带构建号的唯一文件名，防止镜像缓存旧包。使用 `mobile/tools/SignAndroidUpdate.java` 签名更新清单，参数为 APK路径、内部版本号、版本名、GitHub release APK直链、更新说明文本、输出JSON。私有密钥路径/密码仅从 `HXZ_ANDROID_KEYSTORE` 和 `HXZ_ANDROID_STORE_PASSWORD` 环境变量读取；禁止提交密钥。

先上传APK，再上传签名清单 `android-latest.json` 到当前最新正式Release。之后若发布仅Windows更新的新正式Release，也必须将最新Android清单复制到该Release，否则 `/releases/latest/download/android-latest.json` 无法发现安卓更新。Android内部修订不移动原Windows标签；本轮源码标签 `v0.4.2-android.40204`。
